## 运行

`release/` 原安装器属于早期阶段，不会随源码自动更新。07 独立冻结安装版见 [冻结交付](docs/handoff/frozen07-release.md)，不得覆盖。10 的独立免安装候选位于 `output/release-audit10/win-unpacked`，当前 11 阅卷验证候选另存 `output/release-audit11/win-unpacked`；路径、C 盘验证副本及哈希见 [11 验收矩阵](docs/handoff/grading-acceptance.md)。运行时须保留整个 `win-unpacked` 目录，不能只复制 EXE。完整 NSIS 安装生命周期仍由 15 验收。

开发环境为 Node.js 24.14.0（24.x）和 npm。依赖以锁文件为准：

```powershell
rtk npm ci
rtk npm run dev
```

`dev` 构建并打开 Electron；`start` 直接打开已有构建。打包运行不依赖 Node、开发服务器或 localhost 端口。普通终端未安装 RTK 时，可使用对应的 `npm` 命令；RTK 是本开发环境的命令包装工具，不是客户端依赖。

## 当前功能

- 创建/重命名班级，新增/修改学生，转班、停用与恢复在籍，保留成员关系历史。
- 搜索、筛选、分页；空名册可载入 2 班、100 人的虚构样例。
- SQLite 保存与重开；受限桌面接口及独立工作线程。
- 包含受管合成附件的一致备份，校验预览后恢复，保留并可回退恢复前副本。
- 脱敏诊断、版本不兼容拒绝打开、坏备份拒绝及工作线程超时保护。
- DeepSeek 本地配置、文本/图像检查及调用账本；成绩导入、确定性统计、可追溯版本与解释草案。
- 座位编排、当期值日分组轮换、确认版本历史及分批打印。
- TXT/DOCX/PDF/JPG/PNG 资料导入、范围选择、结构化备课与冻结修订、同版可编辑 DOCX/PPTX 导出。
- 独立限权课堂展示、明确选择答案、单调计时与进度恢复、可配置目标日期及时区的倒计时。

## 限制

当前未配置代码签名，客户目标电脑、干净 Windows 环境的安装验收尚需完成；不要通过关闭安全防护安装。Linux/macOS 未验收。14–15 的外设契约与最终发布交接尚未整单完成。现有模拟和合成验证不证明真实教学成效。
