# 班级助手演示视频脚本

本脚本建议录制七分三十秒，使用合成学生和资料展示已实现流程。比赛要求视频不超过八分钟，配套提供完整源码和应用文档。模型生成片段应使用已授权账号，标明需要教师复核。

## 零分至四十五秒 项目与场景

展示班主任工作台，说明教师日常需要在名单、点名、成绩、座位和值日之间切换。

解说：我们把同一班级的学生资料集中保存，让日常工作直接选用，并用智能助手协助整理教学内容。

## 四十五秒至两分 统一导入

新建合成班级，选择名单和成绩文件。核对姓名、学号、科目满分，确认后进入工作台。展示名单人数和已保存考试。

解说：名单和成绩先核对再保存，后续点名和排班使用同一份名单。同名学生需要明确确认，不自动合并。

## 两分至三分十五秒 上课点名和档案

打开点名，记录到课、迟到和请假，核对后保存。回到学生档案，点击姓名，查看这次点名和考试成绩。

解说：没点到的学生保留未点名。保存后的记录可以从学生档案直接查看。

## 三分十五秒至四分十五秒 成绩与成长

展示第二次考试和可比较的成绩变化，选择已保存成绩作为成长总结依据。说明汇总成绩的分析边界。

解说：本机计算统计事实，只有科目和满分口径一致、成绩完整时才比较总分。模型建议仍需教师核实。

## 四分十五秒至五分四十五秒 备课与课堂

读取合成教材文件夹，选择资料、新建备课任务、填写课题。展示发送范围、生成草稿、教师编辑、保存版本和导出。打开课堂展示及倒计时。

解说：资料读取在本地完成，选择的内容经核对后用于在线生成。保存的课件版本可以用于课堂展示。

## 五分四十五秒至六分四十五秒 智能助手

打开右下角智能对话，演示查询已有班级资料。再展示一个受支持的修改方案，核对后确认。

解说：助手调用已实现的本地工具。正式修改由教师确认；模型账号需要交付人员配置。

## 六分四十五秒至七分三十秒 交付与反思

展示使用说明、源码和备份入口。说明验证使用合成数据，真实教学效果需要后续试用记录。

解说：交付包包含免安装程序、教师 Word 文档和完整源码。我们根据用户操作反馈持续简化入口，同时保留数据核对和更正历史。

录制时不要使用真实学生的姓名、联系方式或个人档案。没有实际记录的效率、使用人数和教学效果不要编入解说。
