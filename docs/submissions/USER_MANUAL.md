## 二、 智能业务对话（全能数字化助教）

“业务对话”是您的全能助手。您无需到处寻找功能按钮，直接输入普通话口语，智能体即可替您精准办理。

### 2.1 4 大高频日常锦囊（一键直达）
在主页中央，为您预置了 4 大日常高频业务锦囊卡片：
1. **📋 查班级学生名册**：点击快速核对学生学号、视力健康特征与在籍状况。
2. **🪑 教室智能调座**：点击即刻调出最新座位图，支持视力优先与同桌互助调配。
3. **📊 考生分段成绩分析**：一键掌握全班最新考试的平均分、及格率与薄弱名单。
4. **🧹 今日值日生查询**：即时显示今日轮值学生小组与负责的卫生包干区。

### 2.2 两阶段确认机制（放心使用，杜绝 AI 误操作）
智能体执行任何数据修改前，均严格遵守**“方案提议 -> 教师核对 -> 正式生效”**的安全机制：
1. 您在输入框提出需求（例如：“把李明和张华的座位对调一下”）；
2. 智能体在屏幕呈现排座调整预览方案，明确标注变更前后的位置对比；
3. **只有当您亲自点击【确认正式写入】后**，系统才会将改动写入本地数据库；若不满意，可点击【取消】或继续提要求，彻底避免误修改。

## 三、 班务管理常用操作

### 3.1 班级名册管理与示范样例
- **快速体验**：初次使用若名册为空，点击页面右上角的 **【载入示范样例】**，系统将即时生成“高一 1 班”、“高一 2 班”共 100 名样例学生的完整学籍档案，供您快速熟悉系统。
- **新增学生**：点击 **【新增学生】**，录入姓名、学号、性别、视力情况及监护人联系方式，点击保存。
- **状态维护**：学生休学或转学时，点击学生右侧的 **【停用】** 按钮即可；后续复学可一键 **【恢复】**，历史数据全程保留。

### 3.2 课堂考勤点名
- **开始点名**：进入 **【上课点名】**，系统默认全员处于“出勤”状态。
- **考勤登记**：若有学生请假或迟到，直接点击对应学生姓名切换状态（出勤 / 迟到 / 事假 / 病假 / 旷课）。
- **即时统计**：页面上方实时更新“今日实到人数”与“出勤率百分比”，点名结果自动计入成长档案。

### 3.3 智能座位编排与打印
- **智能生成**：进入 **【座位编排】**，选择行列规格（如 7 行 8 列）。可勾选多种约束条件：
  - *视力关爱*：中高度近视学生自动优先安排在前三排正中；
  - *互助互补*：成绩优势生与薄弱生自动同桌结对；
  - *男女分布*：自动保持各大组男女比例均衡。
- **手动微调**：点击任意两个座位，即可在界面上直观对调两名学生。
- **打印与导出**：点击 **【预览与打印】**，可选择生成带讲台视角的黑白打印排座表或彩色大字版，支持一键导出标准 PDF。

### 3.4 公平值日轮换表
- **自动编组**：进入 **【值日轮换】**，系统根据班级总人数智能划分每日值日小组（扫地、擦黑板、倒垃圾、图书整理）。
- **智能顺延**：遇到法定节假日或学校运动会，系统自动顺延轮换周期，确保每位同学值日频次绝对公平。
- **临时请假替换**：某同学当天生病请假时，点击其名字选择“临时替换”，系统推荐当天未排班同学替岗，并在历史台账中清晰记录。

## 四、 教学评价与学情辅导

### 4.1 成绩导入与多维智能学情诊断
- **考分录入**：在 **【成绩管理】** 中，支持一键粘贴或导入各科单选、多选与主观题汇总分。
- **科学指标计算**：系统自动在本地秒级计算总分、平均分、最高分、标准差、及格率、优秀率与试卷区分度，生成清晰的直方分布图。
- **大模型学情诊断（因材施教）**：
  1. 点击 **【智能学情诊断】**；
  2. 系统在本地进行安全脱敏后，调用国产大模型深度分析各分数段分布规律；
  3. 大模型输出包括：“班级整体知识掌握特征”、“高频失分薄弱模块预警”、“后进生分层辅导建议”以及“面向家长的沟通谈话指引”，助力教师精准开展靶向辅导。

### 4.2 智能备课与课件教案切片
- **资料解析**：在 **【资料备课】** 中上传教材电子版或教学大纲（支持 PDF / Word / TXT）；
- **重点提炼**：系统智能拆解段落，教师勾选目标教学章节，点击 **【生成教学方案】**；
- **成果导出**：智能体自动起草包含“教学目标、教学重点难点、课堂提问设计、随堂练习题”的结构化教案，支持一键导出为教师常用的 DOCX 教案与 PPTX 课件。

### 4.3 答卷批改建议与教师复核
- **主观题智能辅助**：在 **【答卷建议与复核】** 中，针对作文或综合论述题，AI 提供要点踩分建议与错因诊断；
- **教师逐题裁定**：教师在界面上对 AI 建议逐题核验，可直接修改采纳或驳回重评，保证成绩评定的公正性。

### 4.4 课堂专注倒计时
- **白板模式**：进入 **【课堂与倒计时】**，界面自动适配教室交互多媒体一体机（希沃、鸿合等大屏）；
- **多种计时模式**：支持自主设定课堂小测倒计时（如 10 分钟）、小组研讨倒计时（如 5 分钟），伴随醒目色彩与舒缓提示音，有效维持课堂专注节奏。

### 4.5 学生全景数字档案与期末评语生成
- **全息画像**：进入 **【成长档案】**，点击任意学生，即可查看其贯穿全学期的考勤出勤率、考试成绩走势雷达图、历次值日表现与教师日常表扬记录。
- **温情个性化评语一键起草**：
  1. 学期末点击 **【生成综合评语】**；
  2. 智能体结合该生全周期表现，自动起草一段富有鼓励性、具体生动、契合学生性格特征的评语初稿；
  3. 教师在此基础上进行润色修改，点击 **【正式归档】**，彻底告别千人一面的机械化评语。

## 五、 系统设置与数据安全

### 5.1 国产大模型配置与切换
进入 **【系统设置】 -> 【模型设置】**，您可以在 DeepSeek、豆包、Kimi 之间自由切换。只需填入相应的 API Key 并点击 **【保存并测试连通性】**。当图标显示绿色对勾时，说明连通成功。

### 5.2 本地数据一键备份与恢复
- **定期备份**：每周五放学后，建议进入 **【系统设置】 -> 【数据维护】**，点击 **【导出完整备份】**，将生成的 `.cmbackup` 文件保存在教师的 U 盘或移动硬盘中。
- **遇险恢复**：若电脑故障更换机器，在全新电脑上点击 **【从备份恢复】**，即可瞬间找回全部班级数据。

## 六、 高效自然语言指令推荐

在业务对话框中，您可以尝试像跟真人助教交谈一样输入如下指令：

| 业务场景 | 推荐教师指令示例 |
| :--- | :--- |
| **查寻名册** | “查一下我们班有没有叫李想的同学，学号和视力情况怎么样？” |
| **座位编排** | “有两位近视比较严重的同学（王磊、赵敏），帮我把他们安排在前两排正中。” |
| **值日调整** | “张伟同学今天感冒请假了，找一个今天没值日任务的同学临时替他一下。” |
| **成绩分析** | “这次期中考试数学整体考得怎么样？有哪些同学需要特别关注和辅导？” |
| **备课教案** | “根据我刚才上传的物理第三章资料，帮我设计一份 45 分钟的探究式教案大纲。” |
| **期末评语** | “帮陈晓萌同学写一段期末德育评语，肯定她热心班级事务，并鼓励她在数学上更自信。” |
