# 班级助手教师使用手册

本手册说明当前版本的日常操作。首次使用请先阅读《快速上手》。程序在 Windows 电脑上保存班级资料；模型生成需要已配置的在线服务。

## 找到要做的工作

侧栏有三个入口：教师备课、班主任管理、系统设置。智能对话从右下角胶囊打开。

打开班主任管理后，工作台直接提供上课点名、成绩分析、花名册、座次表、学生档案、成长记录、值日表和本地备课。页面上方可以切换班务功能；右上角可以切换当前班级。

首页人数、考试和点名提示读取本班已保存记录。今天没有点名时显示“还没有保存点名记录”，不会把全班自动算作到课。

## 创建班级和导入资料

本版新增“教师备课 → 班级教学工作台”，集中提供仪表盘、学生管理、成绩分析、违纪统计、作业管理、请假管理、工作留痕、谈话记录、排座位、家校沟通、班级活动、待办备忘十二个入口。上方选择班级，第一次使用点击加号建班；班级、名单、档案、考试、座位和值日资料与原功能共用，不必重复导入。

1. 点击工作台的“新建班级”，输入名称并保存。
2. 点击“导入资料”，选择学生名单、成绩表，或同时选择两份文件。
3. 检查核对页。如果文件有多张工作表，展开“查看列对应与工作表”，选择本次名单与成绩所在的表。
4. 导入成绩时，填写考试名称和日期，核对科目、满分及小数位。调整配置后点击“更新核对结果”。
5. 人数和成绩正确后，点击“确认保存并开始使用”。读取和核对阶段不会保存新资料。

文件支持 XLSX 或 UTF-8 CSV，每份最多 5 MiB。名单至少包含“姓名”或“学生姓名”；“学生编号”“学号”“编号”可选。学号应以文本填写，避免 001 被转换为 1。成绩表还需有科目列，可用“语文（150分）”标注满分。

有学号时优先按学号匹配；缺学号时仅本班唯一姓名可以自动匹配。遇到同名或未找到的学生，按提示选择已有学生、确认新增或跳过。缺少学号的新学生保存后会获得本地编号。保存失败会整批回滚，不留下半份名单或考试。

文件读不成功时，按提示重新保存为 XLSX，去掉多余空行，或另存为 UTF-8 CSV 再选择。不需要清空已有名单。预览保留十五分钟，换文件、名单变化或恢复备份后需要重新核对。

## 花名册和学生档案

“花名册”用于添加、编辑、转班、停用或恢复学生。批量只添加名单时，可点击“批量导入学生”；下载空白模板用于填写，已有文件则直接选择导入。

“学生档案”先显示本班名单，可以搜索姓名或学号。点击姓名或“档案”，在小窗中查看基本信息、考试成绩、点名记录和成长档案。关闭小窗或按 Esc 回到名单。名单旁的“编辑”修改姓名、学号和所属班级；档案中的“编辑学生信息”进入联系资料及教学关注编辑页。

学生档案与各业务共用同一学生身份。不要通过再次新增学生来修正旧成绩或改变班级归属。

## 上课点名

确认班级、日期和课程，逐人选择到课、迟到、请假或缺席，也可以切换到全班名单。初始状态为“未点名”；没有记录的学生不会自动算作到课或缺席。

点击“保存点名记录”，核对人数后点击“确认保存点名”。保存后可在历史记录查看；更正会保留旧版本。未保存时离开页面，软件会提示先保存或取消。

## 成绩分析

点击“新建考试导入”，按资料导入步骤添加新的考试。保存后在考试记录中打开考试，查看科目统计、分布、学生成绩和历史。

需要目标分或不同选科组合时，打开“更多考试设置 → 高级考试配置”。全班科目相同可保留默认分组；不需要的设置可以不填。

已有考试需要改分时，打开原考试并选择“更正本次考试”。更正保留旧版本；同班、同名且同日期的考试不能重复新建。

缺考、未录入和零分分别显示。部分科目有成绩时，总分注明不完整。学生档案只比较科目、满分和小数位一致且成绩完整的两次考试。

成绩解释需要在线模型。统计由本机计算，模型建议是供教师复核的草稿，仅凭汇总分数不能确定具体知识点的失分原因。

## 座次表和值日表

座次表使用本班名单。选择行列和所需条件，生成方案后核对、调整并确认保存；可查看历史和打印。

值日表先准备分组、岗位和轮换规则，再生成并确认计划。周卡片显示成员、岗位和完成情况；可以切换周次或调整当天安排。已完成的日期保留原安排，更改会保存新版本。临时活动或节假日请按实际日期调整。

## 成长记录

选择学生后，可新增表扬、提醒或跟进事实，填写发生日期、内容和来源。需要阶段总结时，选择时间范围和可用事实，也可关联已保存成绩。

总结可以手写，也可以请助手生成。在线生成前核对发送范围，生成后编辑并复核，再确认入档。资料不足时先补充事实，不要把推测作为正式记录。

## 本地备课和课堂

进入“教师备课 → 本地备课”，上传教材文件或点击“选择本地文件夹”。核对文件清单后勾选资料，点击“读取选中资料”。需要子目录时，勾选“包含子文件夹”后重新扫描。

支持 TXT、DOCX、PDF、PNG、JPG，每份最多 10 MiB，PDF 最多 20 页；一次读取最多 25 份资料。成功读取的资料保存在资料库，原文件保留在原处。读取本身不会上传模型。

新建备课任务，填写课题、学科、年级和课时，选择参考片段或图片。教学要求可以用一句话描述学生基础、重点或活动；没有额外要求可留空。下一步核对发送内容后再生成，编辑完成后保存课件版本，可导出 Word 或 PPT。

进入“课堂与倒计时”，选择课件、班级和已保存的版本，打开独立展示窗口授课。活动计时可以开始、暂停、继续和重置。结束后先保存课堂进度。活动倒计时不跨重启保留。

“答卷建议与复核”用于教师检查评分建议。读取答卷图片，设置评分细则，逐题核对或修改；正式入分前检查学生、考试、科目和分数差异。

## 智能对话和外部平台

右下角打开智能对话小窗，选择班级和学生，输入需求。输入框左下角可以上传文件；“查看全部与管理”打开历史会话。收起小窗后可以继续使用业务页面，模型执行的数据修改仍需核对确认。

关闭软件前完成或取消正在执行的任务。重新启动后保留已保存历史和草稿，附件需要重新上传，未完成任务不能直接恢复执行。

资源平台和江西班务入口会打开默认浏览器。平台账号在官网登录，网站入口不会替代平台业务或自动提交。

## 班级教学工作台的日常操作

在“学生管理”点击“批量导入”，选择名单并核对后确认。点击姓名打开档案，填写家长联系方式、性别、身高、小组等资料；下方查看考试和日常记录。名单中的铅笔按钮修改姓名与学号。Word 档案包含联系资料、教学记录和考试分数；名册可导出 Word 或 Excel。

在“成绩分析”点击“新增考试与录入”，填写考试名称、日期、科目和满分，再逐人录分。允许最多两位小数；空白表示缺失，缺考须填“缺考”，零分填“0”。确认保存后查看统计；已有成绩可更正，旧版本保留。“文件导入”支持 XLSX、CSV。“归档”只隐藏考试，查看已归档后可恢复。

违纪、请假、留痕、谈话分别点击“新增”登记，通过搜索、类型和日期筛选找到记录，点击“编辑”更正。作业点击“编辑 / 收交”，勾选已交学生。请假可更新为批准、未批准或已销假，并导出凭证。

“排座位”先选择行列并开始编排，再随机编排或调整座位，核对后确认。按身高编排和男女交错要求先补齐对应学生资料。可以拖动、点击空位分配、双击清空座位，查看历史和导出 PNG。“值日轮换”沿用本班已保存计划。

“家校沟通”提供联系台账、家访、家长会和群通知草稿。通知只保存在本机，当前没有实际群发送渠道，不会显示已发送。“班级活动”保存主题班会、活动照片和荣誉。照片支持 PNG、JPG、WebP，单张不超过 10 MiB，每项活动最多 30 张。

“待办备忘”保存待办、提醒和班级备忘。填写提醒时间后，程序运行或最小化时显示 Windows 系统通知，使用系统通知声音；勾选完成停止提醒。退出后不提醒，重新打开只显示逾期事项。本页可分别选择系统通知和提示音；Windows 勿扰或静音也可能影响提醒。

## 连接 WorkBuddy

智能对话小窗和教学工作台下方均有“前往 WorkBuddy”“连接 WorkBuddy”。前往按钮打开官网，MCP 连接用于让已登录的 WorkBuddy 查询本机资料。

1. 保持工作台运行，点击“连接 WorkBuddy”，点击配置文本框后按 Ctrl+C 复制。
2. 在 WorkBuddy 的 MCP 配置中添加该配置并保存，使用自己的 WorkBuddy 账号。
3. 请 WorkBuddy 查询班级、学生、考试、点名、座位和值日，或提出新增备忘、作业等修改方案。
4. 点击工作台中的“待确认方案”，核对班级、学生和修改前后内容，再“确认执行”或“拒绝”。查询可直接返回，修改未经本机确认不会写入。

方案三十分钟过期；恢复备份后旧方案不能执行。关闭软件时桥接停止，未处理方案不保留。更换程序位置或电脑后，重新复制连接配置。配置引用本机连接文件，不含模型 API Key；不要把本机连接文件发给其他人。

WorkBuddy 的额度和模型服务由该平台账号决定，MCP 连接不会获得额外免费额度。本工作台自己的在线生成仍使用已配置的模型服务。

## 备份和常见问题

到“系统设置 → 数据与备份”导出 .cmbackup 文件。恢复前先核对备份预览；恢复后可以回退到恢复前副本。备份不包含模型密钥，换电脑后由交付人员重新配置。

模型提示未连接或 HTTP 401 时，联系交付人员检查账号；重复发送问题不能修复账号错误。操作按钮被禁用时，先查看是否有未保存内容或正在执行的任务。

需要排查时，在数据与备份页导出诊断，将错误编号和复现步骤交给维护人员。不要为排查问题直接删除数据库。
