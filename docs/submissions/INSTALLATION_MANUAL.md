# 班级助手免安装使用说明

这份说明用于教师启动、升级和迁移免安装版本。程序适用于 Windows 10 或 Windows 11 的 64 位系统，已包含运行环境，不需要安装 Node.js 或在电脑上部署模型。

## 第一次启动

1. 把交付 ZIP 完整解压到本机普通文件夹，例如 C:\ClassManager。不要在压缩包中运行，也不要只复制一个 EXE。
2. 双击根目录的“启动工作台.cmd”。也可以进入“程序”文件夹，双击 Class Manager.exe。
3. 首次进入工作台，创建班级并导入学生名单。步骤见“使用说明”中的《快速上手》。

班级名单、点名和成绩统计不要求配置模型。需要智能生成时，模型账号由交付人员准备；教师只需确认页面提示的发送范围。

程序正常退出时直接关闭窗口。关闭前先保存当前工作，完成或取消智能助手正在执行的任务。

## 更新版本

免安装版首次运行会为系统提醒创建“Class Manager 教师提醒”开始菜单快捷方式，不需要安装程序。提醒须保持软件运行；系统勿扰和静音设置可能影响显示及声音。

先在旧版“系统设置 → 数据与备份”导出备份，再保存并退出旧版。将新包解压到另一个文件夹，启动新版。不要覆盖运行中的程序目录。

同一 Windows 用户默认使用同一个应用数据目录。程序包换位置不会自动搬动数据库，也不会清空已有班级；旧版仍在运行时，先退出旧版再开新版。数据库升级后，不要直接用更早版本打开。

## 换电脑

在旧电脑导出 .cmbackup，复制到新电脑。启动新版后到数据与备份页选择文件，核对预览并确认恢复。模型密钥不在备份中，需要交付人员在新电脑重新配置。

实际数据目录显示在“系统设置 → 数据与备份”。程序目录与业务数据目录分开，不要靠删除程序文件夹来清空测试数据。需要纯净测试环境时，先备份，再由维护人员设置独立的数据目录。

## 打不开时

确认已经完整解压，且系统为 Windows x64。学校电脑如有权限限制，请让管理员核对软件来源和系统提示。本包未添加代码签名，不要求关闭系统保护。

软件能打开但智能助手不能使用时，请联系交付人员检查网络和模型账号。本地管理功能可继续使用。Word 和 PPT 文件生成不要求安装 Office，打开文件需要兼容的办公软件。
