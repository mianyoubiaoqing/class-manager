# 班级助手项目说明

班级助手是面向中小学教师的 Windows 本地工作台，集中管理学生名单、点名、考试、座位、值日和成长记录，并提供教学资料读取、备课、课堂展示及智能助手。

## 教师怎样使用

先创建班级，导入名单和成绩。日常从班主任工作台选择要做的工作，各页面使用同一批学生。学生档案汇集基本信息、成绩、点名和成长记录。

教师备课用于整理资料、编写教案课件和课堂展示。右下角智能对话理解需求并调用已实现的业务工具；涉及资料修改时，教师核对后确认。模型生成结果需要教师复核。

## 当前能力

班务包括名册维护、XLSX 或 CSV 导入、点名记录、座位编排、值日轮换、成绩统计与更正历史、学生资料和成长记录。教学包括 TXT、DOCX、PDF 和图片读取、本地文件夹批量读取、备课任务、Word 与 PPT 导出、课堂展示、倒计时和答卷建议复核。

系统提供模型连接、业务备份恢复、诊断和外设接入状态。国产模型供应商包括 DeepSeek、Kimi 和豆包，实际可用模型取决于账号权限；网页资源入口与模型 API 配置是不同功能。

## 技术实现

Electron 提供桌面程序；React 和 TypeScript 实现界面。主进程、预加载接口与工作线程分工处理文件访问和业务请求，SQLite 保存业务记录。

本地统计由程序计算，模型根据选定内容生成草稿。凭据按本机保护机制保存；业务数据库存放在本地，并不因此等同于整个数据库已经加密。模型请求可能发送教师选定的资料，使用前需核对发送范围。

## 交付与验证

免安装包包含运行程序、教师 Word 文档、比赛报告、演示脚本和完整源码。自动化及桌面测试使用合成数据；真实课堂效果、教师节省时间和学生表现需要在实际使用中另外记录。

本项目不承诺所有自然语言请求都能执行，不提供无需账号的无限免费模型，也不自动办理外部教育平台业务。教学工作台现已支持教师登记作业收交情况；学生自主提交、课间巡查和手机同步尚未实现。群通知仅保存草稿；WorkBuddy 通过本机 MCP 查询资料或提交须教师本地确认的修改方案。
