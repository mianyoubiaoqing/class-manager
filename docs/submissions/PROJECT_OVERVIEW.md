# 班级管理本地智能体（Class Manager Agent）项目总说明文档

**面向赛项**：AI 教育实践应用专项 · 教育智能体设计与应用  
**系统名称**：班级管理本地智能体（Class Manager Agent）  
**适用对象**：中小学班主任、科任教师、教研组长、学校教务管理人员  
**技术底座**：国产生成式大模型集群（DeepSeek-V3 / 豆包 Doubao-pro / 月之暗面 Kimi） + Electron 端侧运行时 + 离线优先 SQLite 本地加密引擎  
**发布版本**：v1.0 交付版（Production Ready）  

---

## 一、 系统定位与设计理念

### 1.1 核心定位
“班级管理本地智能体（Class Manager Agent）”是专为基础教育教师研发的**新一代端侧离线优先、多模型智能协同的班务管理与数字化教学工作台**。系统将大语言模型的自然语言理解与推理生成能力，与桌面级软件的严谨确定性逻辑深度结合，构建了一个具备教育情境感知、任务拆解、自主工具调用以及严格隐私防线的教学助理智能体。

### 1.2 三大核心设计理念
1. **教师在环（Teacher-in-the-Loop）**：智能体只作为“高能参谋与高效秘书”，涉及排座、值日、调分、档案等关键教育决策，必须经由教师核对确认，AI 绝不越俎代庖。
2. **端侧隐私计算与数据零出站**：学生真实姓名、学号、家庭住址、健康档案等核心敏感信息全部保存在本地 SQLite 数据库中。调用云端大模型前在本地执行哈希脱敏，大模型只处理抽象学情特征，确保符合《个人信息保护法》与教育数据安全规范。
3. **确定性工具链（Deterministic Tooling）**：大模型的输出通过结构化 Function Call 转换为本地强类型工具执行，彻底消除大模型的幻觉误操作，实现教育场景的绝对可靠。

## 二、 业务功能全景矩阵

智能体通过左侧现代导航架构划分四大业务域，全面覆盖 14 项核心教育教学场景：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       班级管理本地智能体 (Class Manager)                     │
├──────────────┬──────────────────┬──────────────────┬────────────────────────┤
│  🤖 智能中心  │   📋 班务管理     │   📊 教学评价     │      ⚙️ 系统设置       │
├──────────────┼──────────────────┼──────────────────┼────────────────────────┤
│ • 业务对话   │ • 班级名册管理   │ • 成绩综合管理   │ • 模型服务配置         │
│ • 会话流管理 │ • 课堂考勤点名   │ • 智能资料备课   │ • 数据备份与维护       │
│              │ • 智能座位编排   │ • 答卷建议与复核 │ • 智慧外设接口         │
│              │ • 公平值日轮换   │ • 课堂与倒计时   │                        │
│              │                  │ • 学生详细资料   │                        │
│              │                  │ • 综合成长档案   │                        │
└──────────────┴──────────────────┴──────────────────┴────────────────────────┘
```

### 2.1 智能中心（AI Copilot）
- **业务对话**：桌面全能自然语言入口，内置“查名册”、“智能调座”、“考分分析”、“今日值日”4 大高频锦囊，支持复杂复合指令理解与自动任务调度。
- **会话管理**：支持多会话上下文切换、历史会话树状分支回溯、对话归档与无损恢复。

### 2.2 班务管理（Class Administration）
- **班级名册**：班级创建/编辑、在籍学生生命周期管理（转入、转出、停用、恢复），支持字段级搜索与批量导入。
- **上课点名**：一键点名、病事假登记、迟到记录，即时统计课堂出勤率并同步沉淀至学生日常考勤库。
- **座位编排**：支持同桌互助平衡、视力/身高智能优先、男女比例均衡等复合约束算法，提供图形化拖拽调整与打印导出。
- **值日轮换**：公平轮替算法，自动跳过节假日，支持临时请假顶替与历史值日台账追溯。

### 2.3 教学评价（Assessment & Learning Support）
- **成绩管理**：多批次考分导入、确定性教育测量学指标统计（平均分、标准差、区分度、及格率、优秀率）、历次成绩对比。
- **资料备课**：支持 PDF/Word 教学材料解析，知识点智能切片，生成兼具三维教学目标的教案与课件大纲，支持导出 DOCX/PPTX。
- **答卷建议与复核**：针对主观题批阅提供 AI 评分参考细则与教师逐题复核确认，生成个性化错题讲评要点。
- **课堂与倒计时**：专注倒计时、随堂小测抢答器、课堂节奏提醒，专为多媒体白板大屏优化。
- **学生资料**：单人全景数字画像，汇聚健康特征、学科偏好、家校沟通记录。
- **成长档案**：过程性综合评价，自动汇总学期德智体美劳表现，生成富有鼓励性与温度的个性化期末评语初稿。

### 2.4 系统设置（Infrastructure）
- **模型设置**：DeepSeek、豆包、Kimi 等国产主流大模型 API Key 本地安全加密存储与双通道连通性测试。
- **数据与维护**：本地数据库完整性快照备份、防篡改校验还原、全流程诊断日志导出。
- **外设接口**：支持扩展教室分贝仪（噪声监测）与智能呼叫铃，守护课堂纪律。

## 三、 核心技术架构与安全机制

### 3.1 技术分层
```
[渲染进程 / Web UI]
  React 19 + TypeScript + Vite + Opus 5.5 陶土学术护眼设计系统
       │ (IPC 强类型通道 / Zod 校验)
[主进程 / Electron Main]
  生命周期调度 · 窗口管理 · 系统级安全沙箱
       │ (线程隔离通信 / Worker Channel)
[工作线程 / Worker Pipeline]
  确定性业务引擎 (排座 CSP / 考分计算 / 值日调度 / 资料切片)
       │ (SQLCipher 加密事务)
[存储与外联层]
  本地 SQLite 数据库 │ 国产大模型 API (DeepSeek/豆包/Kimi)
```

### 3.2 隐私安全保障体系
1. **脱敏网关（Redaction Gateway）**：在数据离开主进程内存前，强制经过脱敏管道，将学生姓名等隐私字段替换为虚拟标识符；
2. **凭据安全**：API Key 等敏感认证信息使用操作系统级 DPAPI / Credential Manager 加密存储，绝不明文写入磁盘；
3. **离线高可用**：所有 14 项业务的基础数据增删改查、排座计算、成绩统计完全在本地 CPU 离线计算，无网络环境下功能依然完整可用。
