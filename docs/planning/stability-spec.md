# 初版稳定性规格

日期：2026-09-29。状态：评审草案，以下均为待执行验收要求，不是通过报告。

## 1. 目标与阶段

交付可在 Windows 单机运行的班级管理客户端，使用合成材料验证功能正确性、数据持久化、异常恢复及可维护性。暂不开展真实教学、实际阅卷、学生通知或真实档案管理；本阶段的“确认”“入档”“发布”均针对测试数据。

八项软件功能保持已确认范围：座位、值日、成绩分析、成长档案、倒计时、备课、课堂辅助、普通题型图像阅卷。音量监测与呼叫仅交付可验证接口及明确未接入状态。仅能启动窗口不等于完成初版。

先后检查两个里程碑：M0 是安装启动、合成名册、数据保存重开和恢复的稳定底座；M1 是全部软件流程及真实模型接口的合成样本验证。M0 可独立演示，但不能冒充八项功能已交付。正式业务启用、真实试点及报告视频另立后续验收，不自动随 M1 启用。

## 2. 合成数据与输入默认值

- 基准测试集为 2 个虚构班级、每班 50 名学生、3 次考试，包含常用科目、不同满分、真实零分、缺考、未录入、重复及无效行。该规模是验证基线，不是最大容量承诺。
- 教案和课件以自行编写的普通教学材料测试；试卷采用印刷题干、手写选项或短句等合成图片，附人工答案及评分细则。不使用真实学生姓名、答卷、谈话或云盘资料。
- 初版导入格式默认：成绩为标准 XLSX 或 UTF-8 CSV；备课材料为 TXT、DOCX、PDF、JPG/PNG；阅卷材料为 JPG/PNG/PDF。不解析旧版 DOC/PPT、宏文档、加密 PDF 或任意嵌入对象。
- 导入保护的工程初值：每个文件至多 10 MiB，PDF 至多 20 页，单图至多 20 百万像素。超限明确拒绝或提示分拆，不静默截断。应用处理后请求还须满足服务商独立限制；参数可在性能验证后经评审调整并留记录。
- 已保存的成绩、教案、课件、档案和计划以本地数据库为准；测试替身不得在发布构建中伪装为在线模型成功。

## 3. 必须覆盖的工作流程

| 范围 | 正常流程 | 失败或恢复验证 |
| --- | --- | --- |
| 安装与名册 | 安装、启动、创建合成班级与学生、保存重开 | 无开发环境、中文路径、普通权限、重复启动、迁移失败不破坏旧数据 |
| 成绩分析 | 标准表预览确认、计算指标、关联 AI 解释草案 | 重名/重复编号、缺考与零分区分、纠错旧报告失效、离线仍可计算 |
| 座位 | 布局及不可用位置、锁定、随机安排、调整、保存与打印 | 容量不足、锁定冲突、重排保留锁定、不丢失学生 |
| 值日 | 当期分组、组间轮换、岗位配置、人工换人 | 空组、人数不足、岗位冲突、重分下一期不改历史 |
| 成长档案 | 事件与跟进、成绩关联、总结草稿经确认入档 | 无事实不编造、未确认不入档、源材料改变提示重核、模型失败仍可记录 |
| 备课与导出 | 上传合成资料、生成并保存教案课件、DOCX/PPTX 导出 | 无法解析、超限、不可信内容、保存取消、文件占用、保持可编辑与内容版本一致 |
| 课堂与倒计时 | 材料展示、环节切换、计时、进度保存、目标日期 | 离线展示、暂停重开、跨日与已到期状态、私有资料不投屏 |
| 图像阅卷 | 页序与学生对应、图像模型建议、纠错、确认成绩进入分析 | 模糊/缺页/不支持题型不计零、无效 JSON/题号/分数、取消重试不重复发布 |
| 设备预留 | 状态查询、请求契约和模拟接口测试 | 未接入不伪造数据或送达，模拟结果明确仅供测试 |
| 备份恢复 | 数据库及附件一致备份、验证后恢复 | 错包、缺附件、路径穿越、恢复中断、保留原数据、不包含密钥 |

## 4. 稳定性与发布门槛

- TypeScript 严格类型检查、静态检查、单元/应用接口测试和关键 E2E 均通过；检查脚本以实施后真实项目命令为准，不在尚无代码时写虚假命令。
- Windows 安装包在无开发工具条件下通过安装与启动检查；完成至少 10 次正常关闭重开，数据不丢失。中断写入、任务退出和恢复测试分别验证，不以正常退出代替崩溃验证。
- 在基准合成数据上完成一次至少 60 分钟交互与离线/故障混合测试，无未处理异常、无持续界面失去响应、无损坏或重复发布。循环故障使用测试替身，避免反复产生云端费用；记录设备和观测到的资源占用，不编造性能上限。
- DOCX/PPTX 既通过结构检查，也逐页渲染检查；至少在目标办公软件中修改文字或表格并保存重开。没有实际编辑验证时标记未验证，不能仅凭文件存在宣布可编辑合格。
- DeepSeek 文本和图像至少各完成一条真实接口合成样本验证，确认模型权限及响应结构；无 Key 或外部服务不可用时仍交付本地测试证据，但 M1 的在线能力标为未通过或受阻，不能用模拟结果补齐。
- 严重缺陷清零：启动失败、数据丢失、越权调用、密钥泄漏、崩溃、未审核正式写入、静默错误计分及伪造接口成功都阻断稳定版发布。较轻问题记录复现步骤、影响和临时处理方法，由验收者明确接受。
- 每个功能的通过证据标明构建版本、合成样本、执行环境及测试类型。文档核对、静态检查、模拟调用、真实模型调用和真实业务成效互不替代。

## 5. 当前与后续交付

当前交付候选包含 Windows 安装包、源码与锁文件、合成测试材料、检查结果、已知限制、架构/UML、规格工单以及用户与开发者交接文档。稳定性优先不代表取消注释、备份、安全或文档。

申报报告、演示视频和真实试用证据暂后置，日期未定。真实业务启用前重新评审数据授权、留存与删除、账号归属、可见范围、设备接入和普通题型效果。当前程序不主动发送学生通知，也不为测试去接入真实业务系统。
