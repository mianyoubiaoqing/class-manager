# 17 统一业务对话入口（历史策略）

2026-10-02：本文保留17阶段设计。用户已授权18新策略替代逐次外发预览与不带历史的限制，当前实现见[18说明](../handoff/agent-conversation.md)及[新流程图源](diagrams/agent-conversation.mmd)。

2026-10-02；实施中，尚未整单验收。16已通过，17固定基线`output/17-conversation-baseline-NBT3Qz`389文件。正式写入和外发前确认来自用户已明确范围，不扩展为任意系统Agent。

`ConversationRunner`持有会话令牌、确切外发、模型提议和执行回执，`conversation-intent.ts`生成最小输入及本地动作说明。Renderer只显示和确认，不提供通用IPC、SQL、文件、命令或模型工具参数。新增5个具名管理桥接，共129项；课堂投屏仍只有原3项。Schema/备份仍11，无新增业务表。

外发只含本次最多2000字输入及班级/学生“已选择”布尔标志，不自动带本地姓名、编号、ID、历史对话或查询结果。用户输入本身仍须逐次核对脱敏。先在本地查看供应商、型号、endpoint和确切JSON，确认token/hash后一次发送；沿用16固定协议和隔离凭据/账本，没有原生工具调用、自动重试或跨供应商回退。

模型输出严格校验一个具名动作；自由解释只显示为“模型提议”。所有实际对象ID/revision/epoch由本地显式选择产生，不能由模型填写。查询可读取名册、考试、座位历史、值日目录、备课目录、课堂目录、答卷目录、当前学生成长时间线、外设状态、倒计时，结果不外发。课堂前100条含总数，答卷各考试前50条，超20考试或显示128KiB明确要求原页面查看。

正式写入有限支持：创建/重命名班级、当前学生在籍变更、倒计时设置、新增成长事实。先显示对象、前后差异、全部写入内容，教师另行明确确认。复用原具名Worker操作/CAS/事务，成长事实复用requestId。成绩入分、总结入档、冻结、备份恢复、模型业务生成、课堂控制与导出/打印进入原页面继续原审核，不能通过新入口绕过。

当前来源指纹覆盖epoch、班级版本与所选班级名册，倒计时使用原revision。模型配置变化撤销准备/提议并取消网络；生成前后复核来源，旧结果不采用。Main独占槽保护动作提交，提交开始后取消不能回滚。10分钟令牌，20条Main会话任务；成功重复只返回原回执，失败/取消/回包不明不得重放副作用，先查询原任务/供应商账本/原业务。重开失效，会话正文不入业务备份、诊断或默认日志；正式结果按原业务持久保存。

UI提供对话历史、当前班级/学生、供应商/型号、任务状态、两次确认及回执查询。名册/考试/设备/倒计时本地快捷查询不需要模型，未配置、离线、不支持意图及未接入设备明确显示。原页面和未保存改动的导航保护继续可用。

当前测试全部合成数据/确定性Fetch替身；真实自然语言理解质量和用户实际账号能力未验证，不冒称已经开通。整单还须实际Main/Worker、教师界面、取消故障、窄窗、独立包及Standards/Spec两轴验收；17通过前不进入15。
