# DeepSeek 初版接入方案

更新日期与资料核对日期：2026-09-29。

状态：用户已选定 DeepSeek 为初版服务商，并表示已有 API Key。本轮仅查阅公开文档，未索取、读取、保存或使用密钥，未调用付费推理接口，也未验证该账号的模型权限、余额和图像阅卷质量。

## 1. 已核实能力与设计默认值

| 项目 | 公开文档事实 | 本项目选择 |
| --- | --- | --- |
| 接入地址 | 基础地址为 `https://api.deepseek.com`，提供 Chat Completions 接口。[S1、S3] | 初版使用官方地址，由应用侧 DeepSeek Adapter 调用 `POST /chat/completions`，不通过第三方转发 |
| 模型 | 当前模型页列出 `deepseek-flash` 与 `deepseek-v4-pro`；前者对应 DeepSeek-V4.1-Flash，后者对应 DeepSeek-V4-Pro-0813。[S2] | 建议 `deepseek-flash` 作为初版统一默认模型，服务商已确认，具体账号可用性仍待测试 |
| 图像输入 | `deepseek-flash` 支持 Vision，`deepseek-v4-pro` 标为不支持；图像指南说明文字与图像可以同时输入。[S2、S4] | 普通图像阅卷以 Flash 多模态为当前设计默认；保留独立 OCR 接口，但不要求本次再接一家 OCR 服务商 |
| 结构化输出 | JSON Output 使用 `response_format` 的 `json_object` 类型，提示词须明确要求 JSON，文档同时提示可能出现空内容或截断。[S5] | 教案、课件与逐题建议请求 JSON；应用自行校验结构、题目标识、分数及来源，JSON 可解析不等于业务正确 |
| 思考模式 | 官方文档说明默认开启思考模式，可用 `thinking.type` 的 `enabled` 或 `disabled` 明确控制。[S6] | 初版先以明确关闭思考模式作为成本和延迟验证起点，效果不达标再比较；模式写入任务配置，不依赖服务商默认值 |

以上能力是模型级别的，不是“所有 DeepSeek 模型都支持图像”。不能把 `deepseek-v4-pro` 自动作为图像调用的替代模型。官方已建议使用 `deepseek-flash` 名称，旧 Flash 名称虽然可能被接受，但其请求会映射到当前 Flash 模型；不把旧别名当作稳定版本锁定。[S1、S2]

模型名与能力配置集中管理，不散落在成绩、备课和阅卷的业务代码中。保留请求模型名、服务返回的模型标识（如有）、调用参数和提示词版本；服务商可能更新别名指向，不能仅凭同名承诺结果完全可复现。

## 2. 功能分工与数据流

- 备课：已确认由教师输入课题并上传教材或参考资料，初版不内置整套教材库。仅将本次选定且允许处理的课题、学科、课时及资料片段发送给 DeepSeek，返回带来源关联的教案与课件结构草稿；教师保存后，本地程序完成 Word/PPTX 导出。模型补充内容不伪称教材原文。
- 成绩分析与成长总结：程序先计算指标，模型只接收经过授权的最少必要事实，生成解释或待审核总结；数值统计和正式写入不由模型控制。
- 阅卷：本地读取和预览图像/PDF，确认材料角色与学生对应，生成经检查的去标识化页面；向 Flash 发送必要页面或题目区域及确认的评分细则，返回逐题建议。原图对照、人工纠错、分数校验和发布规则沿用 `paper-grading-design.md`。
- 座位、值日、倒计时及已保存课堂材料的使用不依赖 DeepSeek 在线。调用失败只影响相关生成任务，不阻断本地基础功能。
- 服务商输出和导入材料都是数据，不自动执行模型建议的命令、外链或任意工具。将来需要模型驱动业务工具时，仍通过已授权的应用操作及教师审核，不把密钥或系统能力交给提示词控制。

建议第一版只集成一个真实 DeepSeek Adapter，应用模块通过明确的文本生成及图像理解接口调用；保留替换服务商的接口，不建设多服务商自动路由平台。密钥失败、余额不足或能力不匹配时不得静默改用其他厂商。

## 3. 图像传输与阅卷限制

- 官方 Vision 指南支持 JPEG、PNG、GIF、WebP，以及内联 base64 等传输方式；内联编码计入请求体大小。当前公开上限包括 48 MiB 请求体，实际图片还受到独立尺寸限制。[S4]
- 产品初版仍按 JPG/PNG/PDF 的材料范围规划，PDF 在本地按页转为图像。选择内联图像传输，不要求把学生试卷放到公开 URL，也不引入长期 Files API 上传存储作为默认流程。
- 必须在请求组装后检查编码、文本和图片合计大小，不能仅检查原始文件。产品的单文件、页数、像素及批次限制应低于供应商上限，并在目标机器样本验证后确定；不以供应商最大限额作为产品默认批次。
- 图像放入普通用户消息的允许字段，不向只接收文字的模型发送图片路径或 base64 长字符串冒充视觉输入。保持题目文字可读，不能为降低费用盲目缩小整页图像。
- 图像云处理的具体许可和服务商数据保留条件仍需确认。有 Key 不等于获得任意学生材料的处理授权；未经确认使用合成或许可测试材料。
- 不支持的复杂题型仍转人工，识别不清不补零，模型评分必须教师复核。具备 Vision 能力不构成对手写识别或教学评分准确性的保证。

## 4. API Key 与账号交接

- 用户在客户端设置页输入 Key，表单只作短暂输入，经专用受控桌面调用交给应用进程后清空；不得留在 Renderer 的长期状态或浏览器存储。后续读取只返回已配置状态或掩码，不向 Renderer 回传完整密钥。
- 密钥不写入源码、安装包、普通 SQLite 字段、日志、导出文件或通用备份；不共享开发者个人 Key 给其他使用者。初版没有远程服务器，客户端不能把内置共享 Key 伪装成不可提取的秘密。
- Electron 推荐方案通过独立凭据接口使用系统保护的存储能力；若选用 `safeStorage`，按实际锁定的 Electron 版本验证其 API，不照搬过时方法。官方说明 Windows 使用 DPAPI，但不能防止同一用户权限下的其他程序取得数据；Linux 的 `basic_text` 后端不能作为安全保存方式。[S8]
- 系统安全存储不可用时，明确说明无法持久保存，不静默改用明文。换机、跨平台恢复或切换账号需要重新配置凭据，不把凭据随业务备份迁移。
- 设置页提供保存、更换、删除及显式连接检查。连接检查使用很小的合成请求，标注可能产生调用费用；不借检查上传真实学生资料。图像能力用独立合成图片验证，文本成功不能自动标记图像已验证。
- 开发者现有账号仅记录为可供后续配置。建议正式交付时由客户提供并承担自己的服务账号，七天维护结束前完成更换与说明；最终费用及账号归属尚未确认。

## 5. 失败、成本与验收

- 401 显示认证失败、402 显示余额不足、参数错误要求修正；这些不自动重试。429、500、503 及部分网络故障使用有限退避和取消机制，遵循可用的重试提示，达到上限后保留草稿并等待用户处理。[S7]
- 空内容、截断 JSON、格式不合要求或越界分数不写成成功结果；保持原始任务和已确认的内容版本，允许显式重试或人工处理。调用成功和业务审核完成是不同状态。
- 任务设置输出长度、处理批次和调用次数上限，避免默认使用模型最大上下文或输出额度。返回 usage 作为可观测用量依据；未返回的用量记为未知而非零。重试可能仍产生费用，不能声称本地取消必然免计费。
- 10 亿 token 是项目开发及调试总预算，应用账本仅覆盖它能观测的调用，不替代其他开发工具的用量统计。货币费用另有价格、缓存及计费时段因素，须以带核对日期的配置估算并与服务商账单核对，不能写死长期价格。
- 验收覆盖：纯文本生成、图像测试、JSON 校验、密钥不可用、余额不足、限流、超时、取消、断网后本地功能、重复发布保护与密钥不泄漏。将每个测试区分为测试替身、公开资料核对或真实接口验证。
- 真实推理、账号权限、性能、费用和普通题型样本验证都尚未执行；公开文档已核对不等于系统已接入。
