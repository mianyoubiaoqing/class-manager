- 已确认：Windows 单机、桌面封装、DeepSeek、八项软件功能、两项设备接口、可编辑 DOCX/PPTX、教师审核，以及暂不进入实际业务。

- 规划阶段的文档不作为运行证据；随后 M0 的源码、打包产物与测试另有记录，不能据此声称八项业务功能或真实应用成效已完成。
