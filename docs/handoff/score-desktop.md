# 成绩桌面接口交接

更新：2026-09-30。工单 04 的桌面接口已接入 Main、冻结 Preload 和实际 worker；后续教师页面已实现，见 [页面交接](score-ui.md)。本文的接口阶段验证不代表工单 04 整体验收。

## 具名接口

以下方法均通过 `window.classManager` 调用并返回统一 `Result`。没有任意 IPC、任意文件读取或任意 SQL 接口。

| 方法 | 输入和结果 |
| --- | --- |
| `previewScores` | 考试配置与可选文件令牌；返回带文件令牌的预览，选择框取消时为 `null` |
| `confirmScores` | epoch、预览令牌、原请求 ID、期望版本、更正原因；返回持久回执 |
| `cancelScorePreview` | epoch、可选 keepSelectedFile（默认 false）；撤销后台确认，默认同时丢弃文件缓存 |
| `listExams` | epoch、可选 classId；返回最新考试摘要 |
| `readScoreVersion` | epoch、versionId；返回版本数据、统计和陈旧标记 |
| `scoreHistory` | epoch、examId；返回版本历史 |
| `studentScoreHistory` | epoch、studentId、稳定 subjectId；返回历次记录与口径说明 |
| `exportScoreTemplate` | 考试配置、csv/xlsx 格式；返回保存回执，选择框取消时为 `null` |

输入类型在 `src/shared/score-commands.ts`，公开接口与白名单在 `src/shared/contracts.ts`，桥接在 `src/main/preload.ts`。后台行为详见 [确认与历史交接](score-confirmation.md)。

## 文件选择与重新预览

首次 `previewScores` 不传 `fileToken`，Main 打开本机选择框，检查扩展名、普通文件类型及 5 MiB 上限，用有界读取取得字节。实际格式和文件名由 Main 决定；Renderer 不能传路径、内容、文件名或格式冒充已选择的文件。

Windows 文件读取前先拒绝 UNC、设备路径和相对路径，再通过隐藏的异步 PowerShell `DriveInfo` 查询拒绝映射网络盘，并逐级检查父目录、拒绝目录链接。分类子进程限时 3 秒，无法分类时拒绝读取；不会修改执行策略。请先将文件复制到本地普通目录。3 秒仅是磁盘分类上限，不是整次文件读取的超时承诺。Linux/macOS 的本地路径适配尚未实现，当前明确拒绝，不能宣称跨平台文件导入已通过。

成功返回的 `fileToken` 只代表主进程内当前一份文件的缓存，不是持久路径。页面修改科目映射、排除原因等配置后，可以复用它重新预览。缓存固定为选择时的字节，外部修改原文件不会偷偷改变已显示的预览；要重新读磁盘应重新选择文件。

以下情况需要丢弃页面内的文件令牌：选择新文件、明确取消、成功确认、成功恢复、关闭程序。主进程最多缓存一份文件；伪造令牌、旧 epoch 或已经失效的令牌均被拒绝。选择框取消返回 `null`，不是导入成功。

每次重新预览会先撤销旧后台确认令牌。错误行预览仍可返回文件令牌，便于修正配置后重试，但只有 `canConfirm` 为真且确认令牌非空时才能启用确认。文件无法解析等硬错误没有可继续确认的后台内容。

撤销在单独确认 epoch 后、完整配置校验前发生；空考试名或超大配置同样不能保留旧确认。非法或过期 epoch 不得撤销其他工作区的操作；旧 epoch 的取消请求也不会清空当前文件缓存。

## 排队、取消与请求边界

Main 保持现有窗口身份校验、主 frame 校验和全局写锁。文件预览、模板导出和成绩确认属于独占工作区操作，不与恢复或名册写入重叠；模型连接检查仍使用独立任务机制。

worker 以 Promise 队列串行执行所有工作区命令，异步 XLSX 解析也必须等待后才处理下一条。不能把解析 Promise 直接作为结果发回，更不能在 await 期间允许恢复切换数据库。

取消接口不受 Main 的独占锁阻挡，会立即递增选择代次并丢弃文件缓存；原生选择框或解析迟到的结果不再成为可用预览。worker 中的取消按序生效，不承诺抢占正在执行的同步 CSV 运算。页面仍须用任务代次忽略迟到响应，并把“已取消”和“确认成功”分开处理。

第六阶段加入 `keepSelectedFile: true` 用于配置编辑：仍撤销确认令牌，但保留当前本地文件字节供重新预览。该参数不转发 worker。明确取消、离开页面仍使用默认清理行为；换文件清除页面原有映射和行排除，避免不同文件的行号串用。

原有 IPC 维持 16 KiB 输入上限，仅预览和模板配置允许 12 MiB，以容纳最多 10000 个计分组分配和显式排除原因。它不放宽确认、名册或其他接口限制；数据本身仍由后台严格校验。文件字节不由 Renderer 提交。

## 模板与恢复

模板从 `ScoreBook` 取得与预览相同的当前或历史应考名册，并保留文本编号。Main 打开保存框、阻止覆盖工作区目录，再原子发布文件；取消保存不写文件。没有伪装成 XLSX 的 CSV。

恢复确认框已显示考试数量和成绩版本数量。恢复发布后旧 `ScoreBook` 被释放，Main 文件令牌失效；页面应清除旧 epoch 下的预览、考试选择和确认命令，再加载新的名册与成绩。

## 页面接入要求

完整页面需包含考试配置、稳定科目目录与自定义科目、满分/精度/目标线、计分组及完整名册分配、模板导出、文件选择、分页错误预览、显式列映射与排除理由、差异确认、更正原因、版本/学生历史、统计与缺失状态。默认不公开排名，不根据数据缺口补零。

配置一经修改，必须立即禁用旧确认结果，重新预览后才允许确认。第一次确认前生成请求 UUID；网络桥接或进程响应不确定时复用原命令重试，不能不断换请求 ID。完整成绩 UI 仍需要独立组件、窄窗口检查和实际点击回归，不能用本阶段的程序化接口测试替代。
