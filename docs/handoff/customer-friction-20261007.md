## 悬浮对话

右下角固定胶囊打开页面上方的小窗，左侧智能对话入口打开同一会话。保留新对话、附件上传、历史管理、展开和收起。会话组件保持唯一实例；仅改变可见性不会取消模型任务。原有正式写入确认和本地版本核对继续生效。当前业务页仍有待保存内容或进行中的操作时，助手提议的执行会被阻挡并显示说明。

## 回归依据

`scripts/customer-friction-smoke.mjs` 使用真正的桌面接口复现空白模板覆盖既有合成名单，修复前报告原文件已改变，修复后验证拒绝覆盖且文件内容完全保留。脚本同时检查空班级导航、导入说明和考试的下一步入口。

`scripts/floating-assistant-smoke.mjs` 使用独立工作区和模拟传输验证附件及草稿保留、运行任务跨页不取消不重复请求、历史管理、401 单次停止、业务编辑保护、明确确认后仅写入一次，以及键盘收起和焦点恢复。检查 1440、1024、760、390 像素窗口及 640 × 500 矮窗口的大小窗布局。

这些测试不配置客户凭据，不请求真实供应商，不证明客户当前 API Key 有效。导航录像的原始锁定来源仍需当时状态或诊断记录确认。
