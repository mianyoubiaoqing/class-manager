# 教师成绩页面交接

日期：2026-09-30。对应工单 04；当前源码已接入教师操作页面，已安装旧客户端不会自动获得这些变更。仅使用合成学生资料验证，不代表真实班级试点或最终发布验收。

## 教师操作

1. 进入“成绩管理”，点击“新建考试导入”，选择应考班级，填写考试名称、日期、学年、学期和年级。应考范围为当前班级全部在籍学生，不等于文件实际上传的人数。
2. 将“分数口径”明确选为“原始分”。当前不支持赋分或转换分；不确认口径不能导出可用模板或完成预览。
3. 核对科目满分、小数位和可选目标分。起始配置不是学校统一规则。标准科目可增删；外语按具体语种选择。自定义科目按规范化后的名称识别，同名会沿用同一身份，不同科目不要共用名称。
4. 核对计分组内的科目；可新增组，使用“全班分配”或逐人下拉框分配。分组不同的原始总分不混排。有人使用的组不能直接删除，先重新分配学生。排名默认关闭。
5. 导出 CSV 或 XLSX 模板。保留学生编号的前导零。有效零分填 `0`，缺考填 `缺考`，未选考填 `未选考`，未录入可留空；空白不代表零分或未选考。所有分数必须在科目满分与精度内。
6. “选择成绩文件”打开本机选择框。只接受本地普通目录中的 UTF-8 CSV 或 XLSX，文件不超过 5 MiB、10000 个数据行；不执行公式，不接受宏、外链、多层或合并表头。网络共享、映射网络盘、目录链接须先复制到本地普通目录。
7. 查看分页预览和问题行。原表科目名不一致时选择“原始成绩列”和“映射目标科目”，应用列映射后重新预览。确需排除错误行时填写文件行号及原因，再重新预览；排除不删除学生，也不将该学生改为未选考。
8. 修改任何配置后旧确认立即失效。点击“重新预览”会复用已选择文件的缓存字节；外部修改了文件则必须重新选择。重新选择会清除之前的列映射与排除记录，需再次核对。
9. 核对有效、缺考、未录入、未选考人数、缺口学生及统计，填写导入原因后“确认入库”。没有错误不代表全班成绩完整，缺少科目时总分显示“不完整”。
10. 已有考试通过“查看”进入统计和版本页面，“更正本次考试”基于当时的应考名册，不把后来调班的学生自动加入。核对中文配置差异和逐项分数变化，填写更正原因后确认。
11. 版本选择框保留历史版本；旧版本有明确标记，不能直接从旧版本发起更正。先“查看最新版本”。完全相同的重导入不会产生新版本。
12. 在“学生历次成绩”选学生与科目查询。成绩、满分、得分率和版本一起展示，缺少记录不推断趋势；不同试卷和参照群体下的得分率变化不能直接等同于能力变化。

确认请求响应中断时，在当前页面使用“重试原确认请求”，不重新点击新建考试。该按钮复用原请求 ID。若已离开页面或重开程序，先查看考试记录及最新版本，核对是否已经保存。预览有效期 15 分钟；到期需重新预览。

取消文件选择、取消预览或离开成绩页不保存成绩。确认事务一旦提交，不因离开页面而撤销。备份会包含考试与全部成绩版本；恢复后重新读取，不沿用旧预览。

## 维护定位

| 文件 | 职责 |
| --- | --- |
| `src/renderer/ScorePage.tsx` | 页内状态、异步代次、持久确认重试、考试与版本导航 |
| `src/renderer/score-editor.ts` | 稳定科目目录、自定义名称身份、当前/历史草稿、差异中文描述 |
| `src/renderer/ScoreConfiguration.tsx` | 考试字段、科目、计分组和完整应考分配 |
| `src/renderer/ScorePreview.tsx` | 行问题、列映射、排除、分页差异 |
| `src/renderer/ScoreResults.tsx` | 确定性统计、分布和分页成绩明细 |
| `src/renderer/scores.css` | 成绩页布局与窄屏表格滚动 |
| `scripts/score-ui-smoke.mjs` | 实际页面点击回归；仅原生文件框使用测试替身 |

不得在 Renderer 重新计算正式统计、直接操作数据库、读取磁盘或接触 Key。统计来自后台，页面只做展示和录入。

标准科目 ID 是长期数据契约，不因改显示名称而修改。自定义 ID 使用命名空间 `class-manager:subject:v1:` 下 NFKC/trim 名称的 SHA-256 前 128 位，设置 UUID v8/variant 位；不要改规则，否则同一科目的新旧历史会断开。这是产品身份规则，不是全国科目编码。自定义科目名称与既有标准完全相同时沿用标准 ID。

配置修改调用 `cancelScorePreview({ epoch, keepSelectedFile: true })`，只保留 Main 缓存文件，后台确认令牌仍撤销。明确取消/卸载页面使用默认 `false`。Main 只向 worker 转发 epoch，不把缓存策略扩散到领域模块。

成绩页与名册刷新分别有异步请求。snapshot 变化时必须同时递增代次、清理草稿与令牌、释放页内 busy/locked；只忽略迟到响应却不复位 busy 会留下无法操作的页面。更正差异必须使用旧版本 baseline 解析已删除科目或计分组，不向教师展示 JSON/UUID。
