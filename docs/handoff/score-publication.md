## 当前行为

`ScoreBook.publication` 拥有单份入分预览、确认与持久事实查询。只接受当前 epoch、完整冻结复核 ID 和后台生成的 15 分钟预览令牌，不接受 Renderer 分数、成绩快照或任意来源。准备展示原分、新分、学生科目考试、答卷修订、细则及确切成绩父版；已有零分、有效分或缺考状态都要求明确替换确认。

新成绩从复核的确切父版复制，只替换该学生本科目，保留其他学生、科目、配置和原始文件来源。成绩 payload 的 `publication` 记录复核 ID 与父版 ID；通过复核可追溯原图、细则、答卷和教师修改。旧成绩和解释来源仍保留，旧版本读取显示过期；成长总结的来源提示在 13 落地。

确认在同一个 SQLite 事务中写新成绩版本和 `grading_publications` 操作凭据。复核 ID 是唯一幂等标识；重复确认、重开或回包丢失后查询返回同一原回执，不再改分，也不重新付费阅卷。未冻结、不完整、来源过期、预览到期、名册变化、旧 epoch 或成绩父版冲突都拒绝写入。

新增三个管理具名操作 `prepareScorePublication`、`confirmScorePublication`、`readScorePublication`，管理桥接当前 98 项。准备和确认参与 Main 的工作区独占协调；课堂展示桥接未增加这些权限。

## 操作和更正

“确认冻结复核”只保存不可变复核。教师在其下方点击“准备正式入分差异”，核对学生、考试、科目、原分/新分及展开的依据，填写说明并勾选正式写入；原成绩为有效分（包括零分）、缺考或未选考时还须勾选替换确认，随后点击“确认正式入分”。成绩管理的最新版本显示新统计及复核/父版来源。

响应中断时先“查询入分结果”。查到记录表示事务已提交，重复确认返回原回执；查不到表示尚未提交，可重新准备并核对，不需重新付费阅卷。过期或版本冲突须重新读取来源；不能通过反复点击覆盖新成绩。已经正式入分的复核不能原地再写一遍。更正可在成绩管理从最新版本走明确的表格更正流程，或从冻结复核创建修订草案，重新绑定最新成绩及适用细则、逐题复核并冻结后发布；历史复核、来源和旧成绩一直保留。
