启动默认进入“业务对话”，主导航首项固定为“业务对话”。输入消息，点击“发送”或按Enter；Shift+Enter换行。发送即授权本轮使用当前供应商/型号理解与回答，可能计费；只读工具不再要求逐个核对JSON和点击执行。正式写入仍展示真实对象、前后差异和完整内容，勾选后才提交。

助手可正常回答、追问，或连续调用具名只读工具（班级目录、名册、考试、座位、值日、备课、课堂、阅卷、成长、设备、倒计时）。查询完成后Main先清洗返回结构，再发送给模型继续回答。没有选择对象时可先发现班级；模型只使用本会话代号定位，原始ID不被接受。正式入分、确认总结、冻结、恢复及打印导出继续进入原页面审核。

`ConversationPrivacy`拥有代号与原对象映射。姓名、学号、已知班级名称和身份ID替换为稳定会话代号；嵌套结果统一处理。凭据、联系方式、路径、私有备注、附件/图像原稿及版本字段不回传。手机号、邮箱、常见密钥和Windows/常见Unix路径也在自由文字中遮蔽。用户输入中的已知身份做同样替换，减少手工编辑。未知自由文本中的姓名、隐含敏感事实及所有可能的秘密格式不能保证完整识别；使用真实资料前仍须留意输入和账号归属。

短学号按数字边界遮蔽，明确“学号/学生号/编号/学生”标签优先；日期与带单位的数值保留。单字姓名按已知文字保守遮蔽，可能连同同字普通词一起隐藏。歧义数值不能可靠区分身份和分数，提问时加“学号”能明确身份。

成长工具仅反馈事件日期、种类、跟进状态和`summaryFact`摘要；总结草稿仅反馈状态/复核/失效标记，正式确认条目可反馈脱敏内容。完整谈话、来源、行动、结果、未确认草稿、输入包及模型原稿不回传。可在成长页面查看完整本地资料。

模型可见的上下文与本地显示分开：Main保留脱敏的用户消息、模型动作及工具反馈；页面中的回答和正式写入预览可将代号还原为本地真实名称，还原内容不会再次回传。工具数据中的文字不构成系统指令。工具集有限，没有任意SQL、IPC、命令或文件访问。模型完成后若桌面回包丢失，自动回读或“查询原任务状态”可恢复已有答复；同一任务的回答、执行消息和导航只接纳一次，不再发起模型请求。
