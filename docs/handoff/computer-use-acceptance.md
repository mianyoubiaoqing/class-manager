## 开始条件

1. Computer Use 可以观察并控制测试桌面窗口。
2. 确认使用隔离的 Windows 测试环境或独立程序数据目录，界面中的名册与账号均属于测试环境。仅复制免安装程序不构成数据隔离，因为默认数据仍在当前 Windows 用户目录。
3. 使用明确标记为合成的班级、学生、成绩、材料及导出文件；恢复和删除只针对本轮测试资料。
4. Agent 实测需要测试环境中可用的模型账号。无账号、缺少 Office 或外设等前置条件必须分别记为未测/受阻，不计作通过。
