# 成绩文件预览交接

更新：2026-09-30。本文件记录工单 04 第二阶段的模板生成、文件解析与无副作用预览。后续后台确认事务与版本已实现，见 [确认与历史交接](score-confirmation.md)；IPC 和完整成绩界面仍待接入，不能宣称完整导入功能已交付。

## 模块职责

- `src/shared/score-import.ts` 定义上下文、预览结果与资源上限。
- `src/core/score-workbook-guard.ts` 在 ExcelJS 解析前检查 ZIP/XML 结构。
- `src/core/score-table.ts` 将有界 XLSX 或 UTF-8 CSV 转为保留位置的单元格表。
- `src/core/score-import.ts` 生成模板，并按名册、科目与显式映射生成预览；不读取或修改数据库。
- `tests/score-import.test.ts` 使用合成名册、内存工作簿和异常压缩包覆盖公开接口。

`previewScoreImport(bytes, format, context)` 返回文件 SHA-256、原始行号、逐行问题、全局问题、排除原因及缺失学生。仅当全局和未排除行均有效、且至少有一条可接受记录时，`canConfirm` 才为真并提供 `entries`。调用方不能将客户端传回的结果直接写库；后续确认事务必须验证预览上下文及数据版本，防止预览后名册变化或重复提交。

## 模板与身份

调用 `createScoreTemplate(context, 'csv' | 'xlsx')` 生成包含当前名册的空分数模板。固定列为学生编号、姓名、班级，后接科目列。学生编号是文本，保留前导零；Excel 中使用数值加显示格式模拟前导零会被拒绝。

导入必须有学生编号及全部预期科目。姓名和班级可省略，但填写时必须与已有名册相符。未知学生不会自动创建；同一学生出现多行时，两行都报错，教师可明确排除其中一行并填写原因。排除行不能绕过错误表头或未确认的原始分口径。

科目别名须通过显式 `columnMappings` 对应，不能靠模型猜测。赋分/等级转换列不作为原始分接受。成绩状态和统计口径见 [成绩核心](score-statistics.md)。

CSV 模板对可能触发表格公式的文本前缀添加单引号。回读时只对与已知名册或科目完全匹配的转义值恢复，不随意删除原本存在的单引号。XLSX 普通字符串与真实公式对象分开处理：普通姓名可含特殊前缀，但公式对象及其缓存值不能作为成绩。

## 资源与安全

当前硬限制：

| 项目 | 上限 |
| --- | --- |
| 输入文件 | 5 MiB |
| 数据行 / 列 | 10000 / 23，另允许一行表头 |
| 单元格文本 | 512 字符 |
| ZIP 条目 | 128 |
| 单个解压条目 / 总解压内容 | 16 MiB / 32 MiB |
| XML 节点 / 嵌套深度 | 1000000 / 128 |
| 预览问题数 | 2000，超限拒绝整次预览，不截断为成功 |

只接受单个可见工作表。不接受隐藏行列、合并单元格、宏、加密、外链、嵌入对象、DTD、复杂单元格等。预检拒绝越界行列范围、重复或错行的单元格坐标，并核对 ZIP 本地头与中央目录文件名，避免预检与解析器读取不同内容。所有失败都保持无写入。

10000 学生、20 科目、200000 个成绩项的 CSV 已完整处理，并核对无丢行、无缺失名单；测试输出记录当次耗时，不构成其他机器的性能保证。大 XLSX、进程级内存限制、取消及桌面交互响应仍须在接入 worker 后补测；当前硬限制不等同于操作系统级资源隔离。

## 维护与验证

运行 `npx vitest run tests/score-import.test.ts` 检查文件行为；运行 `npm run check` 检查全仓。当前 31 项导入测试、全仓 121 项测试通过，格式、类型、Lint 和构建通过。仅为核心阶段证据，未执行本阶段的桌面导入验收。

第二阶段 Standards/Spec 两路只读自审曾发现预检未限制合并及列范围、重复/错行坐标、普通文本误判公式，均已修复并添加回归。两路复审确认闭环，未发现新增明确阻塞；Spec 路另执行 11 项内存合成检查通过。此结论不覆盖尚未实现的持久化与界面。

解析依赖固定为 ExcelJS、csv-parse、yauzl 和 saxes；JSZip 仅用于测试构造异常包。`package.json` 对 ExcelJS 的 uuid 依赖做窄范围覆盖到 11.1.1，避免旧版传递依赖风险；ExcelJS 使用的 CommonJS `v4` 接口已验证。升级 ExcelJS、ZIP 或 XML 解析库时，必须重跑异常结构与模板往返测试，不应删除预检来修复兼容性。
