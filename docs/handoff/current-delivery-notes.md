# 当前交付版本说明

学生花名册、批量导入预览和统一资料导入预览按学校原表的18列顺序显示，重复的身份证与联系电话表头按学生、父亲、母亲分别保存。横向滚动时固定学号和姓名，Excel 导出采用同一字段顺序并使用住校/走读文字。兼容学校原表第2行表头、合并空白标题、公式已保存结果及末尾空行，无需改名或重新排列表格。

全零出生年月/日期文本作为未填写处理并提示，不生成错误日期，也不清除已有值。身份证号码文本允许原样保存并在导入时提示非标准格式，不补位、不宣称有效；学生档案编辑及附加记录使用一致的文本长度限制。可能已丢失精度的长数字编号仍阻止确认。

修复批量导入预览表格被旧兼容样式裁切的问题：明确开启横向和纵向滚动，窄窗口保留可读的列宽；支持鼠标滚轮和键盘滚动，表头在表格内保持可见，翻页及筛选时重置滚动位置。

批量名册导入出现问题行时，默认直接显示问题行，支持切换查看全部；确认按钮明确显示“修正 N 行后可导入”，同时说明修正、保存和重新选文件的步骤。避免错误行藏在后页、按钮禁用却不知道原因。整批保存仍要求全部行校验通过，不会自动跳过学生。

已放宽名册单元格格式：普通数字学号、明确的补零显示格式、富文本、Excel 日期、数字电话和短考籍号可以直接读取。住校支持是/否、住校/走读、√/×等明确写法。名册公式只取已保存结果并提示核对，链接只取显示文字；不执行公式或访问链接。错误值、无结果公式、含义不明的住校编码及可能丢失精度的数字长编号，会指出具体字段。成绩科目的公式限制保持不变。

已修复花名册空白列格式导致的“工作表列范围无效或超过限制”：Excel 将第19列至 XFD 列设置格式时，不再误判为实际数据超限。实际单元格、工作表数据范围和合并范围仍保留原有行列限制；不会截断超出的资料。

本版支持学校花名册18列完整资料导入，同时覆盖统一班级资料导入和名册批量导入。保留原有简单名单格式，兼容学校模板第2行表头和父母同名列。学生详细资料保存到本地档案和修订历史，重启及备份恢复后可读取。同班同学号、同姓名重复导入时更新非空字段，空白不覆盖；确认前直接核对18列。

教师备课区分“我的课件文件”和“课件文字提纲”：前者保存原始教学文件，后者编辑文字并导出 Word 提纲。文件副本保存方式保持不变。免安装包内附带的源码也使用脱敏版本，排除客户文件、日志、业务数据库、密钥和竞品材料。

教师备课直接打开客户提供的学科教学资源库。原完整教学工作台已迁入班主任管理，原班主任首页不再挂载，仪表盘作为唯一首页。智能对话仍从右下角胶囊打开。

## 教师备课

资源库保留十个学科、教材版本、教材卡片、章节目录、框题搜索、课件、教学设计和复习资料标签。每科使用对应教学目标与活动模板，缺少教材正文的章节明确提示补充；客户提供的通用版本目录提醒按实际教材核对，不宣称已内置全部正版教材。

模板编辑保存到本机 SQLite，重启和业务备份恢复后仍可读取。添加本地文件或选择文件夹后，实际读取所选资料并复制到现有附件库，绑定当前章节和资源类型。支持 PPT、PPTX、PDF、DOC、DOCX、KEY、MP4、TXT、PNG、JPG，单份不超过 32 MiB，每次最多 25 份，共享附件总容量 96 MiB。附件可交给本机对应软件打开副本，修改后应重新添加；移除仅解除关联。

DOCX 导出为真正的 Word 文档，包含当前编辑内容。课件页导出 Word 提纲；打印预览使用受控本地窗口，支持系统打印和 PDF 导出。学科网按课程搜索，赣教云及官方教材平台打开浏览器，平台登录和付费下载由平台处理。

资源平台、本地备课、课堂与倒计时、答卷建议与复核保留独立入口。本地备课的文本提取与模型生成继续使用原流程，资源库附件保存原始文件，两者用途在界面和手册中分别说明。

## 班主任管理

工作台保留仪表盘、学生管理、成绩分析、违纪、作业、请假、留痕、谈话、排座位、家校沟通、班级活动和待办；合并统一资料导入、名册与在籍状态、上课点名、学生详细资料、学生综合档案、成绩导入与历史、智能座位方案、值日轮换和成长档案。班级、学生和考试继续共用同一份资料。

待办和提醒在程序运行或最小化时使用 Windows 系统通知和提示音；退出后不提醒。群通知保存草稿并提供查询、修改接口，尚未接入实际发送渠道。

仪表盘最下部提供江西省高中生综合素质评价、江西省教育考试院入口，未创建班级时也可使用。

## WorkBuddy

点击“开始连接”检测默认目录、Windows 安装记录和运行中的 WorkBuddy 桌面端。自定义位置仍未被找到时，选择一次已安装的 WorkBuddy.exe，后续连接会记住位置。取消选择不会更改 MCP 配置。程序保留其他服务并注册当前用户的 MCP 配置，无需复制 JSON 或安装 Node。首次登录和第三方授权仍需在 WorkBuddy 完成；实际账号额度由平台决定。查询通过本机连接，新增或修改资料先形成方案，由教师在本地确认。恢复备份后旧方案失效。

## 使用和升级

交付根目录提供启动工作台.cmd。教师文档在“使用说明”，报告和演示脚本在“比赛材料”，源码及维护资料在“开发资料”，验收记录在“诊断记录”。本次同步更新 Word 使用手册、快速上手和维护说明。

旧版先备份、保存并退出，再完整解压新版。数据库升级到版本 14，新增资源文本、编辑历史和章节附件，纳入备份与恢复；迁移前保留本机副本。升级后的数据库不要用早期版本打开。客户数据、模型凭据和 WorkBuddy 令牌不进入交付包。

## 验证范围

使用隔离合成数据验证原班务流程、备课工具入口、学科模板、章节编辑、本地文件与目录读取、DOCX、打印预览、重启和备份恢复。真实平台登录、付费资源下载、客户账号额度和实际群通知发送不计为自动完成事项。
