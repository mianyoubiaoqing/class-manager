# 当前交付版本说明

点击“教师备课”直接进入客户提供的完整教学工作台。本地备课、资源平台、课堂与倒计时、答卷建议与复核统一放在工作台左侧导航。详细操作以《教师使用手册》为准，第一次使用先看《快速上手》。

## 界面调整

新增十二个入口：仪表盘、学生管理、成绩分析、违纪统计、作业管理、请假管理、工作留痕、谈话记录、排座位、家校沟通、班级活动、待办备忘。界面沿用客户的浅绿侧栏、浅色背景、卡片和表格布局，数据来自本机，不导入原型中的演示名单或分数。

班级、名单、档案、成绩、座位和值日与原功能共用。支持批量名单导入、逐人录分、考试更正与归档、作业收交、请假状态更新、家访及家长会、活动照片、荣誉、待办和备忘；可导出名册及成绩 Excel、学生档案及工作记录 Word、座位 PNG。

待办和提醒在程序运行或最小化时使用 Windows 系统通知和提示音；退出后不提醒，重新打开只显示逾期事项。群通知保存草稿并提供查询、草稿修改接口，尚未接入实际发送渠道。

## WorkBuddy 桥接

智能对话和教学工作台提供桌面端入口、自动注册和待确认方案。本机 MCP 支持班级、学生、教学记录、考试、点名、座位和值日查询；新增或修改教学记录、学生基本资料和在籍状态先形成方案，须教师本地确认。方案三十分钟过期，恢复备份后旧方案失效。

点击“开始连接”自动检测标准位置的 WorkBuddy 桌面端，将自带连接器注册到当前用户的 .workbuddy/mcp.json，并打开桌面端。其他 MCP 服务保留，修改前备份原配置，无需复制 JSON、安装 Node 或填写模型 API Key。首次需要使用客户自己的 WorkBuddy 账号登录，并在其 MCP 服务列表中授权 class-manager；若新服务未出现，保存工作后重新打开 WorkBuddy。界面区分已注册和已检测到本地连接，实际账号登录及授权未作为自动完成事项。平台额度由该账号决定，本项目不会额外提供免费额度。

## 既有入口

启动后进入班主任工作台。首页直接显示上课点名、成绩分析、花名册、座次表、学生档案、成长记录、值日表和本地备课。人数、考试及今日点名提示来自实际保存的资料。

班务功能可以从上方直接切换。学生档案先显示名单，点击姓名再打开详情小窗；高级考试配置移到“更多考试设置”。侧栏采用浅色背景，保留教师备课、班主任管理、系统设置三个主要入口；智能对话仍从右下角胶囊打开。

学生和成绩统一导入继续支持 XLSX、UTF-8 CSV、两文件和多工作表核对。身份匹配、确认保存、事务回滚及历史版本保留。

## 文件组织

交付根目录提供启动工作台.cmd。运行文件集中在“程序”，教师文档在“使用说明”，报告和演示脚本在“比赛材料”，源码和维护资料在“开发资料”，历史验收资料在“诊断记录”。

源码中的班主任首页、资料导入、学生名单和档案小窗集中到 src/renderer/features/homeroom。移除未被调用的旧班主任页面；其他模块保留现有接口。

## 测试范围

新版流程使用隔离的合成数据目录，验证资料导入、点名、学生成绩、第二次考试、成长依据选择、错误恢复和重启。既有成绩、座位、值日及备份流程继续回归。

新教学界面使用隔离合成资料验证空环境、学生导入与去重、档案、考试和跨页关联、日常记录、活动照片、导出、响应式布局以及 MCP 查询和本地确认。实际 WorkBuddy 账号登录、平台额度和真实群发送未作为已验收功能；课间巡查和局域网手机同步未新增。

## 升级

旧版先备份、保存并退出，再完整解压新版。客户数据库和模型凭据不进入交付包。数据仍保存在当前 Windows 用户的应用数据目录，实际路径以数据与备份页为准。

数据库升级到版本 13，新增教学记录、修改历史和提醒送达记录，纳入备份与恢复。升级后的数据库不要用更早版本打开。本机 MCP 连接文件也不进入交付包。
