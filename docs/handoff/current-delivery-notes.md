# 当前交付版本补充说明

## 班级资料共享新版

本次落实 Figma 中 37 至 42 号流程：统一导入、核对保存、文件恢复提示、班级总览、学生与成绩、学生匹配。班主任管理收拢为“班级总览、学生与成绩、上课与排班、成长记录”四组。学生信息与考试成绩可一起导入，也可先导入名单、以后继续添加考试。保存后，各功能读取同一班级的学生资料。

首次进入班主任管理，先创建班级，再选择学生信息或成绩文件。支持 XLSX、UTF-8 CSV，最多两份文件；多工作表须在核对页选择实际范围。考试名称、日期、科目、满分与小数位都可核对调整。更改配置后先更新核对结果，确认保存后才写入数据库。名单与成绩同时保存，失败时整批回滚。

编号优先用于匹配，缺号时仅本班唯一姓名自动匹配；同名或未找到的学生须明确选择已有学生、确认新增或跳过。缺考和未录入分别保留，部分成绩标记为部分总分。同名且同日期的考试不能重复新建；更正原考试请在“学生与成绩 → 全部考试与成绩统计”中操作。

学生详情汇集基本信息、考试成绩、点名记录和成长档案；已有成绩可选为成长总结依据，后续生成仍需核对外发范围。名册手动编辑、原有考试配置、座位、值日和江西班务服务入口继续保留。完整操作步骤见“新版教师工作台操作说明”的“学生与成绩统一导入”。

## 悬浮对话与名单导入更新

点击页面右下角“智能对话”胶囊，打开当前页面上方的业务助手小窗。小窗可以收起、展开，并使用上传文件、新对话和历史会话管理。收起及切换业务页面保留当前草稿、附件和任务，不会重复请求模型。需要修改本地资料时仍须核对并确认；当前业务页面有未保存内容或正在进行的操作时，先保存或取消后再执行助手提议。应用退出后历史与草稿按原规则保存，未完成任务和附件不承诺跨重启恢复。

名单导入中，“下载空白 XLSX 模板”和“下载空白 CSV 模板”只生成待填写文件，不会导入学生。已有名单应点击“选择名单文件”。空白名单模板及成绩模板不能覆盖已有文件，即使在系统保存窗口确认替换，也会要求改用新文件名。顶部步骤表示按顺序完成的进度；选择文件后自动显示核对结果，错误未修正前不能确认导入。

没有在籍学生时，默认考试导入进入统一导入页，可核对成绩表并同时建立学生名单；高级考试配置仍提供“先导入学生名单”。对话学生选择提示该班级尚无学生，并可打开名册。导航被未完成操作阻挡时会显示原因，并保留原内容。模型返回 HTTP 401 时明确提示身份验证失败，请交付人员核对当前供应商的 API Key。401 不属于工具传参错误，不会套用五次修正重试。

## 2026年10月新版界面与本地备课

本次进一步对齐了设计稿的智能对话、历史会话、本地备课、模型连接和名册布局；课堂、答卷、座位和其他子页面统一了卡片与空状态。原“你都有哪些能力？”悬浮大卡片已移除，班级、学生选择和模型设置移至简短工具栏。部分业务表单仍按真实工作流程呈现。

本地压力测试修复了五类问题：长标题撑开历史栏并遮挡按钮；快速切换未及时保存草稿；一份损坏记录阻断整个列表；连续点击新建产生多份空记录；顶部提示挤出输入框。另补充了新回复滚动跟随。测试使用独立的合成数据目录，未清空或修改原有用户数据库，也未调用真实模型服务。详细证据及范围见配套源码中的 docs/handoff/ui-stress-20261007.md。

本版采用浅色工作区与深绿色侧栏，侧栏入口统一为“教师备课、班主任管理、系统设置”，智能对话由右下角胶囊打开。历史会话合并到智能对话，点击“查看全部与管理”可搜索、继续、重命名或删除会话。旧稿中的“业务对话、资料备课、模型设置、数据与维护”分别对应新版的“智能对话、本地备课、模型连接、数据与备份”。原有业务、模型确认和诊断流程保留。

教师备课首页集中显示八个资源平台，新增江西省智慧教育平台和豆包。可添加、编辑、移除自定义网站入口；听课资料与公开课在本版保存为网站链接。班主任工作台增加江西省高中生综合素质评价和江西省教育考试院入口。点击后在默认浏览器打开官网，登录及对应平台业务由教师在官网完成；网站入口不等于接入其 API。

进入“教师备课 → 本地备课”，点击“选择本地文件夹”。默认仅扫描该目录；如需下级目录，勾选“包含子文件夹”后点击“重新扫描”。清单最多显示 500 个普通文件，每次勾选不超过 25 份再点击“读取选中资料”。支持 TXT、DOCX、PDF、PNG、JPG，每份最多 10 MiB，PDF 最多 20 页。不支持的格式、空文件、超限文件会在清单中标出；目录链接及网络目录不作为可读取来源。

资料在本机解析并保存至备课资料库；读取本身不会请求模型。原文件不修改，扫描后发生变化的文件会拒绝导入并提示重新扫描。可取消读取，已成功保存的资料会保留，结果逐份列出。之后在“已保存资料”中选择资料、核对片段和外发范围，再继续生成与导出。文件夹入口保留到当前应用退出；切换备课页面后可重新扫描找回本次选择，重启后需要重新选择。移除入口不会删除源文件或已保存资料。

本版依据原 Figma 设计稿实现，并在原文件补充 31 至 36 号可编辑流程设计。课堂、点名、值日布局进一步对齐；备课范围、考试导入、成长档案和名册导入提供新的引导。实际页面保留可编辑业务表单、既有确认弹窗及真实空状态，信息量会随资料变化。字体采用系统可用字体，窗口缩放、内容长度及部分业务表单布局与静态示例存在差异，不承诺逐像素一致。

免安装包使用文档目录保留六份仓库 Markdown 原稿，同时提供 DOCX 原稿版本、新版操作说明及当前补充说明。配套源码压缩包包含当前源码、脚本、测试、锁文件与文档。模型服务账号仍需交付方在客户实际使用的 Windows 账户下配置，本包不包含个人密钥或免费额度承诺。

## 教师使用

完整解压交付 ZIP，打开名称以 `Class-Manager` 开头的文件夹，双击其中的 `Class Manager.exe`。保留该文件夹内所有运行文件，不在压缩包内运行，不只复制 EXE。普通使用不需要安装 Node.js 或本地大模型。本包不包含 NSIS 安装程序。

切换版本前在旧程序中保存工作、导出备份并退出，再启动新程序。同一 Windows 用户下默认复用原有数据，不要同时运行不同版本，也不要用旧程序直接打开升级后的数据库。

云端智能体仍需要有效模型账号、联网和用量额度。本包不包含个人 API Key，不包含已配置的比赛账号，也没有部署模型中转服务。交付方可以在客户实际使用的 Windows 账户下代配置比赛专用账号；客户以后正常操作软件即可。密钥保存在 Windows 安全存储中，不写入源码和程序文件，不应复制开发电脑凭据目录到客户电脑。更换电脑或 Windows 用户后需重新配置模型凭据。

固定供应商入口为 DeepSeek、Kimi 和豆包。DeepSeek 当前预设型号为 `deepseek-flash`；Kimi 使用程序支持的型号；豆包使用账户实际已开通的接入点。不能以原稿中的旧型号名称代替当前设置。模型提供方的权限、额度与实际联网效果需要用比赛专用账户核对，本次打包不代表这些权限已经验证。

## 文件与诊断

2026-10-07 本次更新新增班级名册 XLSX 与 UTF-8 CSV 批量导入。先选班级和文件、逐行预览，再整批确认。重复或冲突编号会阻止保存；相同在籍学生跳过，不覆盖原有学生。课堂、点名、值日按设计稿调整，备课范围、考试导入与成长档案采用新的操作引导；完整步骤见“新版教师工作台操作说明”。原 Figma 文件新增 31 至 36 号可编辑流程设计。

智能对话输入框左下角可上传 XLSX、CSV、TXT、MD、PDF、DOCX。最多 6 个，每个不超过 5 MiB，解析文本合计不超过 96000 字符。上传用于模型阅读，不等同于正式成绩或名册导入。扫描图片型 PDF 不能依靠此入口自动完成 OCR；提取不到文本时会提示。附件解析内容暂存内存，重启后如需重新阅读，要移除旧附件并重新上传。

模型响应格式错误时，首次请求后最多再重试 5 次。连续失败后暂停并保留已经完成的业务操作，不重置业务数据库。认证、余额、限流、网络或结果不明的错误仍按原策略处理，不因为本次诊断增强而无限重发。

遇到问题进入“系统设置 → 数据与备份 → 导出诊断”。报告新增 `modelResponses`：每个供应商最多 30 条近期结构诊断，包括调用时间、调用及任务标识、当前响应重试序号、解析阶段、拒绝原因、字段路径与实际类型、已读取字节和帧数、结束标记及响应身份是否齐全。原始响应、模型推理、工具参数、学生姓名、学生编号、附件正文、完整路径和密钥不进入这些记录。

阶段与原因用于维护方定位协议问题。例如 `frame / field-validation` 表示流式帧字段校验失败；`completion / missing-completion` 表示响应结束条件不完整。看到 `done: false` 不表示已经完成的业务操作被撤销。没有记录供应商用量不等于没有产生费用。

这些字段从运行本版之后的新调用开始记录，不能还原此前已经丢失的原始响应。升级后若再次失败，导出诊断交给维护方即可；不要为获取证据直接分享密钥或真实学生材料。

## 数据与迁移

默认数据目录为 `%APPDATA%\Class Manager\workspace-data`；当前业务数据库位于其 `workspaces\<工作区标识>\data.sqlite`。模型账本位于 `%APPDATA%\Class Manager`，可见会话保存在该目录的加密 `conversation-history` 中。

换电脑应通过软件导出 `.cmbackup`，在目标电脑预览并确认恢复。业务备份不包含模型凭据，也不应作为完整会话与全部用户配置迁移的承诺。不要按旧稿描述直接复制某个 `database.sqlite`，也不要依赖不存在的“任意历史快照回退”入口；界面提供的“回退到恢复前”仅针对备份恢复流程。

## 源码复现

配套 `Class-Manager-Source.zip` 包含当前源码、锁文件、脚本、测试与文档。测试目录中的两份 `.sqlite` 是仓库自带的合成迁移夹具，不是客户数据库。解压源码到自己的工作目录，不必使用文档中的开发者 H 盘路径。

项目要求 Node.js `>=24.14.0 <25`，不支持按旧稿使用 Node.js 20。标准命令：

```powershell
npm ci
npm run typecheck
npm run lint
npm test
npm run build
npm start
```

构建免安装目录使用 `npm run pack`；生成 Windows 安装程序使用 `npm run dist:win`。项目没有 `npm run package` 或 `npm run clean`。`npm run dev` 会构建并启动，不承诺自动热更新。

如果本机 C 盘临时目录导致集成测试子进程报 `AccessDenied`，可先创建自己工作目录下的临时文件夹，将 `TEMP` 和 `TMP` 指向它后重试。不要删除已有业务数据来处理这一环境问题。
