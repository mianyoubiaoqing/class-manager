# 班主任资料共享设计落实记录

本次将 Figma 文件 W0PhQ2DCqW7St1H452LnDZ 中 37 至 42 号新版流程落实为 Electron 页面。目标是让教师先导入班级资料，再在点名、排班、成绩和成长档案中直接选择同一批学生。

## 已实现行为

班主任管理的一级标签为班级总览、学生与成绩、上课与排班、成长记录。学生与成绩保留原有名册编辑、学生资料和考试统计工具；上课与排班保留点名、座位和值日工具。江西班务服务在总览的折叠区域继续提供。

统一导入支持最多两份 XLSX 或 UTF-8 CSV 文件。读取、配置和确认分开执行；多工作表显式选择范围。编号优先匹配，缺编号时仅本班唯一姓名自动匹配；同名或未找到的学生需要人工核对。预览不写入数据库，确认用单个事务保存新增学生、在籍关系、考试及成绩版本。写入失败整批回滚，旧资料不覆盖。

学生详情汇集基本资料、最近考试、点名和成长记录。完整且分数口径相同的考试可比较总分；缺考、未录入与部分总分明确标注。成长总结可带入已保存的成绩版本与科目；后续模型调用继续使用原有外发确认流程。

## 验证与复现

新增 14 项核心集成测试，覆盖两文件、多工作表、编号及姓名关联、前导零、同名核对、重复考试、无效分数、显式排除、预览过期与名册变化、取消、恢复备份、重启以及事务回滚。运行 `npm test -- tests/class-data-import.test.ts`。

运行 `npm run build` 后执行 `node scripts/shared-class-data-smoke.mjs`，可在隔离 Electron 数据目录中完成两文件导入、预览无写入、确认保存、学生成绩、逐人点名、第二次考试、成长依据选入、旧工具入口、错误恢复、重名核对与重启。检查 1440、1280、900、390 像素窗口宽度下的整体水平溢出。测试报告与截图输出到 `output/playwright/shared-class-data`。

`node scripts/desktop-smoke.mjs` 验证既有成绩更正、历史与备份恢复、解释草稿、座位和值日，以及丢失回执和窄窗口。`node scripts/customer-friction-smoke.mjs` 验证下载模板不覆盖已有文件、空名单可导航、导入步骤说明与高级考试配置的空名单引导。

打包脚本在解压后的正式程序上运行基础免安装验收和新版资料共享流程；后者使用 `CLASS_MANAGER_SHARED_EXECUTABLE` 指定可执行文件。源码、文档哈希与程序内容在打包过程中核对，客户数据库和个人凭据不进入交付包。

## 实际边界

测试使用合成学生与本机真实 SQLite，测试进程中的系统文件选择窗口使用固定文件路径。新版资料共享测试没有访问真实模型；旧回归中的生成响应使用隔离模拟。结果不代表真实供应商在线质量、第三方官网登录或真实客户表格全部受支持。

预览有效期十五分钟，换文件、取消、名册变化或恢复备份后需重新核对。统一导入不会自动转班、恢复停用学生或覆盖旧考试。复杂选科分组、目标分、原成绩更正继续使用高级考试配置。其他学生资料列目前不自动写入联系信息或教学备注。

页面使用现有系统字体和交互控件，真实数据长度、错误提示和配置展开会增加页面高度；保留业务核对项，因此静态画稿与运行界面仍有局部差异。
