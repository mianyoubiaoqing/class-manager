# 班级助手快速上手

这份说明帮助教师完成第一次使用。日常操作的详细说明见《教师使用手册》。

## 启动工作台

完整解压交付包，双击“启动工作台.cmd”。进入班主任工作台后，先创建班级，再准备学生名单。

## 导入名单和成绩

1. 点击“新建班级”，填写班级名称并保存。
2. 点击“导入资料”，选择名单文件。成绩可以一起选择，也可以以后添加。
3. 检查姓名、学号和成绩；有同名学生时，按提示确认对应的人。
4. 有成绩时填写考试名称和日期，检查科目满分。
5. 点击“确认保存并开始使用”。保存后，点名、座位和值日都会使用这份名单。

支持 Excel 的 XLSX 文件和 UTF-8 CSV 文件。名单至少有“姓名”列；学号建议保存为文本。第一次不必设置模型账号。

## 开始一天的班级工作

在工作台点击“上课点名”。逐人选择到课、迟到、请假或缺席，检查人数后保存。没点到的学生保留“未点名”。

点击“成绩分析”查看考试；点击“学生档案”找到学生，打开档案查看基本资料、成绩、点名和成长记录。点击“座次表”或“值日表”安排本班学生。

## 备课和智能助手

点击“教师备课”直接进入完整教学工作台。左侧导航可打开资源平台，或在“本地备课”读取教材文件和资料文件夹，也可进入课堂与倒计时、答卷复核。需要模型生成时，软件会显示要发送的内容，请核对后继续。

右下角“智能对话”随时打开助手。模型账号未连接时，请联系交付人员；名册、点名和本地成绩统计仍可使用。

教师备课工作台中的学生和成绩与班主任管理共用：先导入学生，再录入或导入考试，之后各页面直接选择已有学生。作业、请假、家访、活动和待办都在这里登记。待办填写时间后，软件运行时会弹出系统通知；群通知目前只保存草稿。

需要 WorkBuddy 协助时，点击助手里的“开始连接”，软件自动检测桌面端并注册本机服务。首次需在 WorkBuddy 登录并授权 class-manager；服务未出现时，保存工作后重新打开 WorkBuddy。已连接后即可查询资料。WorkBuddy 提出的数据修改须在本工作台核对并确认。

## 退出和备份

先保存当前工作，再关闭窗口。定期到“系统设置 → 数据与备份”导出备份。换电脑或更新版本前也应先备份。
