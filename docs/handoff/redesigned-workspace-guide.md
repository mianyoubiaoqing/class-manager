# 新版教师工作台操作说明

本说明帮助教师使用新版工作台、批量导入名单，以及完成备课、课堂、点名、成绩、值日和成长档案操作。更新前请在旧版保存工作、导出业务备份并退出，再完整解压新免安装包，双击 Class Manager.exe。

## 三个侧栏入口与智能对话小窗

- 智能对话：点击右下角胶囊，在当前页面上方打开业务助手小窗。侧栏不再重复展示智能对话入口。可收起或展开大窗，点击“查看全部与管理”可查找、继续、重命名或删除记录。上传文件按钮在输入框左下角。
- 教师备课：资源工作台、本地备课、课堂与倒计时、答卷建议与复核。切换功能使用页面标题下方的按钮。
- 班主任管理：班级总览、学生与成绩、上课与排班、成长记录。名册、成绩统计和学生资料编辑放在“学生与成绩”中；点名、座位和值日放在“上课与排班”中。
- 系统设置：模型连接、数据与备份、外设接口。模型账号由交付方设置后，教师可以直接使用；模型未连接时，部分本地操作仍可使用。

## 教学资源与江西班务服务

智能对话已移除原悬浮大卡片。顶部选择当前班级和学生，点击右侧“···”打开本地快捷查询和模型设置；输入框左下角可展开“常用操作”。查看历史前会先保存草稿。遇到损坏记录会提示数量并保留原文件，其他正常会话仍可使用。

收起小窗和切换业务页面不会丢失当前草稿、附件或正在进行的任务，重新打开即可继续查看。小窗内按 Esc 可收起。新对话会开始另一段会话；有未完成任务时先完成或取消。正式修改资料仍须确认；当前业务页面有未保存内容时，先保存或取消，再执行助手提议。重启后保留已保存历史和草稿，附件需重新上传，未完成任务不能直接恢复执行。

学生下拉框提示“该班级还没有学生”时，点击“打开班级名册”添加或导入名单。遇到 HTTP 401，请让交付人员在“系统设置 → 模型连接”核对账号凭据；反复发送同一问题不能解决身份验证失败。

模型连接首页展示账号状态，交付人员点击“交付人员设置”配置账号。“检查连接”先打开检查页面，再由操作者确认请求。名册页选中一个班级后，可点击“编辑班级名称”。

教师备课首页提供八个常用平台官网入口，包括江西省智慧教育平台、豆包、国家中小学智慧教育平台、希沃、DeepSeek、Kimi、飞象老师和学科网。点击“打开官网”会在默认浏览器中打开网站，按平台要求自行登录。

点击“添加平台”填写名称、完整 HTTPS 网站地址和简短说明，保存后出现资源卡片。卡片右上角的更多按钮用于编辑或移除入口。听课资料和公开课区域同样支持保存网站链接。移除入口不影响外部平台内容。

班主任工作台提供江西省高中生综合素质评价和江西省教育考试院入口。本站不保存这些平台的登录密码，也不自动代办其提交操作。

## 读取本地资料文件夹

1. 打开“教师备课 → 本地备课”，点击“选择本地文件夹”。在 Windows 文件夹选择窗口中选择教材或教研资料所在目录。
2. 先核对文件清单。默认只列出该目录的文件；需要子目录时，勾选“包含子文件夹”，再点击“重新扫描”。清单中会标出可读取、不支持、空文件或超过大小限制的文件。
3. 勾选本次需要的文件，每次最多 25 份，点击“读取选中资料”。TXT、DOCX、PDF、PNG、JPG 在本机解析，每份最多 10 MiB，PDF 最多 20 页。
4. 查看成功与失败结果。成功的资料保存在本机资料库；失败文件可修正后重新扫描再读。点击“取消读取”停止尚未完成的工作，已经保存的资料继续保留。
5. 在下方“已保存资料”中选择一份资料，核对文字或图片片段。点击右侧“新建备课任务”，再选择本次备课使用的内容，填写课题和要求，核对外发范围后生成。点击“返回备课资料”可回到资料首页。

单独导入一个文件时，点击资料来源卡片上的“上传文件”，核对解析预览后确认保存。

原文件保留在原位置，读取本身不上传模型。文件在扫描后变化时需要重新扫描。目录链接和网络目录不作为资料来源；超过 500 个文件时请缩小目录范围。扫描型 PDF 保留为图像，不把无法识别的文字视为已提取教材正文。

文件夹入口在应用本次运行期间可重新扫描，重新启动后需要重新选择。移除入口只清除本页显示，不删除源文件或备课资料库中的已存内容。

## 批量导入班级名册

### 学生与成绩统一导入

第一次进入“班主任管理”，先点击“新建班级”填写班级名称，再点击“选择学生信息 / 成绩文件”。已有学生的班级可在“班级总览”点击“导入资料”。可以只选择名单、只选择成绩表，或同时选择两份文件；支持 XLSX 与 UTF-8 CSV，每份不超过 5 MiB。读取文件后先核对，确认前不会保存新资料。

名单至少需要“姓名”或“学生姓名”列，“学生编号”“学号”或“编号”可选。有编号时请保存为文本，以保留前导零。成绩表还应包含语文、数学、英语等科目列，表头可用“语文（150分）”标注满分。若有多张工作表，展开“查看列对应与工作表”，选择本次要导入的名单与成绩工作表；不要把总分、排名或联系方式作为科目。

成绩核对页填写考试名称、日期，并检查每个科目的满分和小数位。点击“修改科目与满分”可调整或排除不需要的列。更改配置后先点击“更新核对结果”，核对每页三行的预览与错误提示，再点击“确认保存并开始使用”。名单与考试成绩会作为一次操作保存，保存失败不会留下半份名单或考试。

匹配优先使用学生编号。缺少编号时，仅本班唯一姓名可以自动匹配；新增学生确认后生成本地编号。遇到同名或未找到的学生，逐行选择已有学生、明确确认新增，或跳过本次不需要的行。程序不会自动把同名学生合并。跳过的成绩行不会保存；请核对人数后再确认。

本班同名且同日期的考试不能重复创建。需要更正已有考试时，打开“学生与成绩 → 全部考试与成绩统计”，选择原考试更正，保留旧版本。缺考与未录入分别显示，不按零分处理；只有科目、满分、小数位一致且完整的两次考试才计算总分变化。

保存后自动进入班级总览。上课点名、座位和值日直接使用本班名单；“学生与成绩”可以搜索学生，切换基本信息、考试成绩、点名记录和成长档案。选择已有成绩后，点击“用这些成绩整理成长总结”进入成长总结流程，再核对模型外发范围。导入文件和查看本地成绩本身不请求模型。

预览有效期为十五分钟。换文件、名册发生变化、取消导入或恢复备份后需重新核对。统一导入不会覆盖已有学生资料，也不会自动转班或恢复停用学生。文件读取失败时，按页面提示重新保存为 XLSX、只保留实际数据，或另存为 UTF-8 CSV 后重选；不用清空名册。

### 原有名册导入工具

进入“班主任管理 → 学生与成绩 → 管理班级名册”，先创建班级，再点击“批量导入学生”。此工具适合只添加名单；也可下载 XLSX 或 CSV 空模板，填写“学生编号”和“姓名”两列。编号须以文本填写，保留 001 等前导零；CSV 须保存为 UTF-8。每次导入一个班级，文件不超过 5 MiB、10000 行，工作区学生总数不超过 10000 人。

点击“选择名单文件”后先查看预览。长名单每页显示 20 行；核对新增人数、跳过人数和错误行后，再点击“确认导入”。预览不会保存学生；确认时将学生与在籍关系整批保存。有任何错误都不能确认，不会只导入一部分。同班、同编号、同姓名的在籍学生会跳过；文件内重复编号、姓名不一致、其他班级占用编号或停用记录冲突，须回到原文件核对并修正。此入口不会自动覆盖、转班或恢复停用学生。

预览有效期为 15 分钟。预览后名册变化、换文件或恢复数据，须重新预览。取消选文件会清除旧预览。如果确认后响应中断，可在当前进程内用原预览重试，不会重复保存；重启后重新选择同一名单，已导入的相同学生会跳过。不要为处理导入问题清空原有名册。

## 本地备课的三个步骤

点击“新建备课任务”，按右侧“这节课准备怎么上？”的三个步骤操作。先填写课题、学科、年级和课时；教学要求只需说明学生基础、教学重点或活动想法，没有特别要求可留空。再打开左侧资料，勾选要参考的文字片段或图片，核对选择数量。未选择的内容不会发送。

最后点击“下一步：准备并核对外发范围”。这一步先准备并展示实际发送范围，不会立即生成。核对模型、发送内容和可能产生的费用后，再确认生成；生成结果仍为待教师编辑和复核的草稿。没有可用资料时，可先回资料库导入或读取本地文件夹。

## 课堂与倒计时

桌面窗口中，左侧为“课堂展示预览”，右侧为“课堂倒计时”。点击“选择课件”，在弹窗中选择授课班级、备课主题、确切冻结版本与所选范围，核对后创建课堂。预览显示真实课件内容；可打开独立全屏展示，切换页码、控制计时，并按需明确展示答案或问题。“继续已保存课堂”可读取此前课堂进度，后续修改的教案不会自动替换已选冻结版。

右侧活动倒计时可选择 5 或 10 分钟，也可填写 1 至 240 分钟。开始、暂停、继续和重置仅作用于当前控制页的活动倒计时；结束时有界面提示，声音在设备允许时播放。离开页面前请暂停；活动倒计时不跨重启保存。课件课堂计时仍保存进度并支持异常中断恢复。下方“高考倒计时”的日期设置单独展开，不会改动活动倒计时。

## 上课点名

先在“本次点名”确认班级、日期和课程，再在“点名名单”逐人点名或切换到全班名单。名册为空时可直接“前往名册”添加或批量导入学生。学生初始为“未点名”，不会自动计为缺席。选择到课、迟到、请假或缺席后，先核对人数和保存说明，再确认保存；更正保留原版本，可在更正历史查看。

## 成绩与值日

默认点击“新建考试导入”进入上文的学生与成绩统一导入。需要设置目标分或不同选科组合时，选择“高级考试配置”，按“考试信息、科目与满分、导入成绩文件”完成配置。只保留本次科目，目标分可空；全班考相同科目时保留默认全科组，不同科目组合才展开计分组。预览后确认入库，已有成绩更正与历史版本继续保留。

值日轮换以每周卡片显示周一至周五；计划包含周末时也会显示对应日期。每张卡片列出实际小组、岗位、成员及完成状态；可切换周次，点击日期卡片或展开“查看与调整当天岗位”调整名单、不可用成员和替换。已完成日期保持冻结，更改须确认并保存为新版本。没有计划时先设置分组、岗位和轮换规则，再生成草案并核对确认。

## 成长档案

选择学生后，概览显示实际事件、待跟进和正式总结数量。“成长时间线”查看事实与修订；“新增记录”填写发生日期、类型、本地事实、来源以及后续行动和结果。“给阶段总结用的一句话”可选，只写必要事实，不填姓名或联系方式。保存后可回时间线查看，更正会保留旧记录。

“阶段总结”按时间与依据、人工或助手草稿、教师复核入档三个阶段操作。先选时间范围与事实摘要，可关联确切成绩版本，再人工撰写或预览在线总结的发送内容。在线生成需要明确核对和模型确认，生成内容不会自动正式入档。教师编辑复核并确认确切来源后才能入档；原记录、来源更正提示和正式总结更正历史保留。切换档案内部标签不会丢失未保存的草稿，未保存内容会阻止切换学生或离开档案。

## 保存与交付

教案和课件生成后由教师核对，确认版本后可以导出 Word 或 PPTX。导出文件可用兼容的 Office 或 WPS 软件继续编辑，外部修改不会自动写回备课记录。

遇到模型问题，进入“系统设置 → 数据与备份 → 导出诊断”。换电脑前先导出业务备份，在新电脑预览并确认恢复；模型凭据需要重新配置。

本次界面与文件夹流程使用隔离合成资料验证，没有访问正式客户数据库，也没有为验收产生真实模型请求。实际模型服务的权限、网络及余额由交付方另行核对。

## 操作中的核对与提示

切换工作页面会回到页面顶部。保存学生资料、点名、冻结教案等需要确认时，核对区会自动进入视野；仍须亲自核对并确认。班级总览与学生详情的提示留在内容上方，避免遮挡标题；其他业务页面的提示在滚动时保持可见，均可关闭。

点名全部完成后，点击“保存点名记录”，核对人数再确认。最后一人的按钮只设置状态，不会暗示还有下一人。新建班级后，可直接按提示批量导入学生。

有效成绩文件默认显示关键问题和导入数量。需调整列映射、排除范围或查看入库前统计时，再展开对应选项；有阻断错误时先修正。确认保存后在考试详情查看正式统计。

成长总结需要勾选可用事实或关联成绩。记录没有可用摘要时，在“新增记录”或更正中补充“给阶段总结用的一句话”；没有依据时不能直接保存总结。

答卷处理点击“读取原图”后，可直接看见缩略预览；需要裁剪或遮盖时再展开对应选项。冻结后的正式入分先核对学生、科目、考试名称及原分到新分的差异，填写说明并确认。提交成功后会显示成绩修订号，内部记录编号在折叠项中保留。
