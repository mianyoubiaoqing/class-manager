# Windows 免安装版

此版本提供完整解压运行 ZIP，使用当前 Electron 桌面程序和生产后端。完整解压后双击 `Class Manager.exe`，无需安装向导、Node.js 或开发服务器。

## 使用、数据与更新

- 完整解压到本机普通目录，建议 C 盘。不能从压缩包浏览窗口直接运行，不能只复制 EXE。
- 数据仍由当前 Windows 用户的 `Class Manager` 应用数据目录管理。安装版与解压版在同机、同用户、默认配置下复用数据；切换前备份、保存并退出旧版本。
- 本版不将数据库放入程序目录，不实现数据随 U 盘移动。删除程序文件夹不会删除业务数据。
- 升级到另一个程序目录后重新运行。不能覆盖运行中的 DLL/ASAR；数据库迁移后不能通过更换旧 EXE 直接回退。
- 跨电脑通过应用内 `.cmbackup` 备份及预览恢复迁移业务数据；模型凭据不随业务备份迁移，在目标电脑重新配置。
- 无自动安装、卸载、桌面快捷方式或文件关联注册。可由用户手动创建快捷方式。
- 不携带 WPS/Office；既有教案/课件导出功能保留，打开及展示依赖本机兼容办公软件。

## 可重复打包

在 Windows 仓库中运行 `npm run dist:portable`（本环境通过 `rtk npm run dist:portable`）。脚本重新构建当前源代码，使用独立 C 盘目录打包，核对 ASAR、锁定依赖的已审核许可、ZIP CRC 和逐文件 SHA256，并从实际交付 ZIP 解压后运行验收。源文件在构建前后核对，变化会阻止发布成功指针。

默认许可清单来自 `output/release-audit18-reviewed/third-party-notices-reviewed`；可通过 `npm run dist:portable -- --notices <已审核许可目录>` 指定。清单必须包含与包内依赖名称、版本、位置和文件哈希一致的 `packages.json`，缺失或不匹配即停止，不能以历史依赖数量代替核对。

每次输出独立目录，保留历史包。ZIP 和外部 `.sha256` 放入当前用户的 `ClassManagerDeliveries`；详细证据位于仓库 `output/playwright/portable`。`output/current-portable-delivery.json` 仅在本轮全部验收通过后更新，安装版交付指针独立保留。

## 本版发布验收

验收脚本使用独立合成数据目录，实际运行从交付 ZIP 提取的生产程序：

1. 中文及空格路径首次启动，对话首页、受限 Preload 与窗口安全配置。
2. 程序 PATH 限制为 Windows System32，工作目录独立于仓库；不通过开发服务器或系统 Node 启动应用。
3. 两份程序对相同数据目录启动，检查第二实例退出且仅保留一个窗口。
4. 通过真实业务 IPC 写入学生及附件、创建并冻结本地课时，实际生成并核对 DOCX/PPTX。
5. 退出后在另一份程序目录重开，检查学生标识、附件和冻结版本持久化。
6. 备份、修改、预览并恢复，再重启核对数据。
7. 程序目录文件在上述操作后保持一致；检查渲染错误和模型网络调用计数。

文件选择对话框使用验收替身，SQLite、Main/Worker 与 Office 文件生成采用实际实现。验收不会打开、迁移、恢复或替换客户现有数据库，也不调用真实付费模型。具体通过情况以本包旁的 `release-report.json` 及其指向的本轮证据为准。

此流程不重复全仓测试，也不将旧版本测试结论算作新包结果。本机验收不等于无开发工具的全新电脑、所有 Windows 版本、只读目录、网络共享、FAT/exFAT U 盘或 WPS/Office 展示兼容性验收；这些未纳入本次发布检查。当前可执行文件没有增加代码签名。
