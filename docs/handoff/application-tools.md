# 对话系统应用权限扩展

2026-10-04 后续：正常功能提问的消息容量修复见[对话容量修复](conversation-context-limit.md)。保留 v7 协议，最新交付按该文档记录。

2026-10-03 后续：当前协议 `business-agent-v7`，每次成功确认后自动继续原任务，见[确认后自动继续](conversation-continuation.md)。同轮多工具按顺序执行、正式操作逐项确认，见[批量调用修复](conversation-batch.md)。自然正文、流式工具及教学内容交互见[对应说明](conversation-streaming.md)。以下保留业务权限扩展背景；87项业务工具继续复用原接口与确认规则。

来源：用户 2026-10-03 本地测试反馈，要求对话系统了解整个应用并读取所有脱敏后的业务数据。本轮交付使用新的安装器与 ZIP，先前 UI 安装器不包含此扩展。

对话协议更新为 `business-agent-v4`。首页与侧栏布局沿用现有前端优化。助手可先读取功能目录，再获取具体工具参数，随后发现记录并读取详情。接入 11 个功能模块：名册、成绩、座位、值日、备课、课堂、阅卷、成长、外设、维护、模型设置。`src/shared/application-tools.ts` 是具名可调用工具目录，`src/main/application-tools.ts` 复用原业务 schema 解析参数和绑定本地状态。

读取范围新增工作区与归属历史、成绩版本及统计、学生成绩历史、成绩解释正文、座位和值日方案、教学资料文本、备课草稿与冻结版本、课堂进度、评分规则和阅卷详情/修订/尝试、成绩发布记录、成长事件/谈话/行动/结果/总结草稿、模型配置和账本。成长数据不再仅允许摘要。姓名、学号、班名及业务标识使用会话代号；联系方式、凭据、路径和二进制附件继续过滤。保留分数、业务事实、状态、业务版本和用量计数。自由文本仅能处理已知身份及明确格式，不能承诺识别所有未知敏感事实。

大型工具结果在脱敏后按结构路径和数组分页读取。返回 `total`、`offset` 和 `nextOffset`；大型对象先返回可读取字段，大型文字可连续读取。模型不得把第一页或字段目录称为全部内容。单轮最多 16 次模型往返，传输及历史大小上限继续适用；较大的跨模块任务分轮继续。

可从对话提出名册维护、成长记录/总结编辑和确认、评分规则、阅卷编辑/冻结/入分、课堂创建和控制、座位和值日准备/调整/确认、备课编辑/冻结、打印、Office 导出、备份、诊断和设备操作。座位和值日的内存草案准备/调整/取消、正式入分前的临时预览可自动执行；正式写入、打印导出、外设和展示窗口动作先停在待确认，页面展示本地真实对象、之前内容和拟执行参数，教师确认后才调用现有 Main/Worker 实现。目录条目不足以冻结或编辑草稿，须先读取完整正文。版本、工作区和操作令牌由本地持有；模型不能指定原始身份、顶层版本或令牌。原业务校验、人工复核、CAS、事务和回包不明时不重放的规则继续适用。

备份文件选择和恢复预览/确认已接入对话，详见[对话执行修复](conversation-actions.md)。资料文件选择、图片/答卷遮盖裁剪、密钥配置/供应商切换以及额外的模型生成外发仍使用相应业务页面。助手在功能目录中能发现并解释这些流程，通过导航进入；仅导航不等于已经完成操作。工具没有任意文件、系统命令、SQL或通用IPC权限。

新增对象或对象改名后，后续消息发送前会重新清洗已保存的多轮历史，避免旧轮次再次回传新识别出的身份。历史快照中的显式身份字段也会先登记再清洗正文。确认写入的回执将新对象登记到当前会话，不向模型反馈整份不相关名册。

定向验证覆盖真实成绩库详情、座位准备/随机编排/确认、成长版本冲突、参数发现、分页、伪造身份/令牌拒绝、正式写入确认及幂等回读、确认后历史重新脱敏。桌面验证在独立合成数据目录运行，模型通信为模拟接口；实际付费供应商验证与客户最终验收仍另行完成。
