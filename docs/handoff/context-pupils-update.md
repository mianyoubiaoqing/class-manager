## 上下文与恢复策略

- 总预算上限 300000 Token；包含消息、工具定义、参数、回执、推理上下文及 16384 Token 输出预留。达到有效窗口的 90% 时自动整理旧历史。
- 使用 UTF-8 字节与消息开销估算，按供应商实际 prompt_tokens 向上校准；不是精确 tokenizer。供应商真实窗口较小时取较小值。
- Kimi K2.6 默认 262144，Kimi K3 可采用应用 300000 上限。豆包 Endpoint 无法由名称推断窗口，默认 32768，可在模型设置填写实际窗口。配置容量不增加供应商实际能力。
- 保留最近完整历史组。assistant 的全部工具调用和对应回执作为原子组，不能截断配对；旧历史分段生成摘要，不允许摘要调用工具。
- 摘要纳入独立用量账本，会产生额外模型费用。摘要完成并核对工作区、配置和取消状态后才提交。历史摘要不能恢复确认令牌或授权写入。
- 摘要失败不自动重发同一付费摘要，改用有损本地检查点并提示教师部分细节需重新核对。取消不采用迟到摘要。
- 取消整轮累计参数错误上限。每个逻辑工具操作首次尝试后最多重试 5 次，换调用 ID 不重置预算；耗尽后解释原因并继续其他操作或追问。普通规划达到 16 次时解释暂停，允许继续聊天。
- 未注册的原生工具名称归入同一错误类别，编造新工具名或同时返回坏 JSON 不能重置该类别的重试计数；错误调用不会进入业务层。
- 已成功或回执不明的正式写入不自动重放。被明确校验拒绝的写入可重新规划，但修改后仍须新的教师确认。网络付费请求不因此盲目重发。

参考实现方法：Codex 的 model_context_window / model_auto_compact_token_limit；DeepSeek Harness 的完整工具边界、保留尾部、摘要提交和取消机制。本项目使用用户要求的 90% 阈值。

## 教师操作

本轮也调整控件与信息层次：统一下拉、日期、勾选、文本输入和焦点样式；支持现代浏览器的下拉弹层并保留原生键盘操作。点名默认只显示当前学生、进度和状态标签，全班名单与更正历史按需切换，名单可搜索。学生资料按教学、联系信息、修订历史分栏，切换保留未保存输入；正式保存时另行核对全部字段。

模型设置分为账号与模型、连接检查、用量记录，高级模型和兼容设置默认收起。对话顶部快捷查询收进菜单，减少重复说明。分栏支持方向键及 Home/End 导航，布局在窄窗口换行；遵从系统减少动态效果设置。

侧栏新增“上课点名”和“学生资料”。

点名：选班级、日期和课时名称，逐人选择到课、迟到、请假、缺席；未操作的人保留“未点名”，不会当作缺席。可填写备注，核对人数后点击确认保存。历史记录可更正，保留旧版和当时姓名、学号及成员快照；转班或改名不重写历史。保存回包不明时先读取历史核对，勿重复新建。

学生资料：选择学生，维护性别、生日、监护人、电话、地址、兴趣、学习优势、支持需求和教师备注。点击保存前核对确认；修订历史可查看旧值。Agent 可读取脱敏资料和点名历史，提出教学资料或点名修改并等待按钮确认；生日、联系方式及地址不回传模型。Agent 更新教学字段时本地合并，保留教师维护的私有字段。

## 后端与前端交接

管理 DesktopApi 148 项，新增 8 项：readStudentProfile、saveStudentProfile、studentProfileHistory、readAttendanceRoster、listAttendance、readAttendance、attendanceHistory、saveAttendance。类型与校验以 `src/shared/contracts.ts` 和 `src/shared/pupils.ts` 为准。

对话公开业务工具共 95 项：46 只读、7 草案、42 需确认。工具参数绑定到已读取对象版本和名册哈希；资料与点名写入使用 requestId 幂等和 revision CAS，禁止覆盖旧状态。界面使用中文业务预览，不向教师展示原始 JSON 或脱敏参数入口。

页面 `src/renderer/PupilPages.tsx`；持久化 `src/core/pupil-book.ts`；Main 工具适配 `src/main/application-tools.ts`；独立桌面验收 `scripts/pupils-ui-smoke.mjs`。

数据库升级至 Schema 12。旧库迁移前创建独立 before-v12 SQLite 副本，事务新增资料和点名表；备份包含新业务及修订。升级后的数据库不能直接交给旧版打开；需要降级时使用升级前副本。新程序测试使用独立数据目录，不修改用户现有安装或成绩测试数据。
