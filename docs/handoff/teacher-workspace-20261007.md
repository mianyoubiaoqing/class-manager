# 教师工作台简化验收记录

本轮参考客户任务卡片首页和本地竞品，调整实际源码及交付结构。测试使用隔离的合成数据，未操作客户数据库或请求真实模型。

## 实现与检查

启动默认进入班主任工作台，八张卡片直接打开已有任务。班务导航采用单层菜单，学生档案从名单进入详情弹窗，复杂考试选项折叠展示。首页人数、考试和点名信息读取已保存资料。

学生档案最初被通用弹窗样式限制到较窄宽度；已排除样式冲突。桌面回归验证宽屏展开、窄屏表格滚动、Esc 关闭和焦点恢复。首页在 1440、1280、900 和 390 像素宽度下没有全局横向溢出。

全仓自动测试 1185 项通过。类型检查、代码规范、格式检查及构建通过。桌面回归覆盖成绩导入、更正历史、解释编辑与读取交错、座位、值日、备份恢复、凭据设置及多次重启，未发现渲染异常。

共享资料流程验证两文件预览与保存、同名学生明确匹配、导入后点名、档案查询、第二次考试比较、成长依据选用、坏文件恢复及重启保留；未产生外部模型请求。

## 文档与源码

八份当前文档按教师使用、比赛材料和开发维护重写，Word 版本逐页渲染检查。历史验收说明保留在诊断记录和完整源码内。

班主任首页、资料导入、名单及档案弹窗集中到 src/renderer/features/homeroom，移除未被调用的旧页面。竞品 asset 内容不进入源码提交或交付包。

## 验证边界

本机合成数据回归不代表真实学校环境和真实模型质量已验收。未新增作业收缴、课间巡查或手机同步。免安装包是否最终通过解压、文件校验和独立运行，以本次交付目录中的 release-report.json 为准。
