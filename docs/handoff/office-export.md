## 教师操作

在“资料备课”选择已保存草案，再点击具体“冻结版”历史按钮。该版本只读，下面显示“导出此冻结版本”。选择“保存可编辑 Word 教案”或“保存可编辑 PPTX 课件”，再在 Windows 保存对话框中选择应用数据目录之外的本地普通目录。导出不需要 Key、不联网、不重新生成正文。保存成功后可显式点击“打开刚保存的文件”；关闭程序后，从保存目录打开。

参考答案和教师私有备注默认排除。选择包含答案后，答案会出现在 Word 正文或 PPTX 画布，投影前须核对。选择包含备注后，Word 会有明确标记的教师备注正文；PPTX 只放入演讲者备注，不放进投影片画布。分享 PPTX 文件仍会分享演讲者备注，不能将其当成保密渠道。切换冻结版本时这两个选项重置为关闭。

Word 为中文 A4 教案模板，PPTX 为 16:9 课件模板，字体 Microsoft YaHei（微软雅黑）。正文、列表和表格为原生可编辑对象；图片是独立可移动、更换的图片对象，不把整页转成截图。当前备课结构只有段落、列表、表格和资料图片，没有结构化数据图表输入；资料中的图表照片仍作为图片保留，不能称作可编辑数据图表。外部编辑不会自动回写数据库，也不改变冻结版或模型原稿。

## 边界和保存语义

- 每个导出只引用一个确切冻结版本；文件内嵌版本 ID、课案 ID、冻结修订号、原内容 SHA-256、模板 `chinese-lesson-v1` 和隐私选项。原内容哈希覆盖整个冻结正文，包括默认不导出的答案/备注；它是版本身份，不是文件字节哈希。另存或外部编辑后的文件字节会改变。
- 资料图片仅读取本次导出实际引用的已注册 PNG，校验资产哈希和尺寸；单张最多 32 MiB，总量最多 64 MiB，导出进程将最长边缩到 2048 像素后按原比例插入。文件输出最多 64 MiB；PPTX 最多 1000 物理页，超过上限整体拒绝，不截掉尾部。Word 页数由办公软件计算，回执不冒充知道准确页数。
- PPTX 长段落、长列表项与过长表格行会拆成后续原生对象，表头重复。无法完整放下的长表头先作为原生续行保存全文，后续用列编号保持映射。Word 对超长行生成有界原生续行，避免 WPS 在跨页大行中丢失重复表头。文字未缩写或重新编写，续行可能把词分在不同页，教师可在办公软件中调整。
- 原生保存对话框和额外“确认覆盖”均以取消为默认。先写同目录独占临时文件、完整写入并刷新，再检查目标指纹；新文件通过独占硬链接发布，已有文件通过原子重命名替换。目标在确认后变化、占用、无权限、取消或子进程超时/崩溃都会拒绝发布；不自动重试、不删除原文件。
- 新文件发布要求目标文件系统支持硬链接；本次验证为 Windows 本地 NTFS。FAT/exFAT、网络映射盘、共享、设备路径、目录链接、数据流和应用数据目录不在支持范围。磁盘无法写入时，请另选普通本地 NTFS 目录。
- 已发布后才到达的取消不能撤销保存。若保存后文件核验失败或被其他进程改写，仍返回“已保存”并提示核验受限，不授予“打开刚保存的文件”的凭据。打开凭据仅在本次会话有效，恢复工作区会撤销它；再次打开前重新校验当前工作区和文件指纹。
- 原子替换不等于对恶意外部进程的文件系统比较交换；无法保证攻击者在最终校验与发布之间换目录。突然断电的介质持久性取决于 Windows/磁盘。进程被强制终止于发布前可能留下 `.cmexport-tmp` 旁路文件；不扫描和删除用户目录，教师核对目标后可删除本次导出遗留临时文件。
- 本次目标办公软件为 WPS Office 12.1.0.28505。Microsoft Word/PowerPoint 未安装，不能声称它们现场编辑已验证；缺少微软雅黑或使用其他版本/替代字体时，应重新检查分页。生成文件本身不依赖 WPS、Office COM、LibreOffice、Node CLI 或对话专用运行时。

## 模块与接口

`createOfficeSnapshot` 由数据库 Worker 从不可变 `LessonVersion` 生成，只投影正文身份和实际引用图片；不含原文件、凭据、提供商报文或无关资产。Main 的 `OfficeExporter` 持有任务生命周期、选择文件和完成回执；`OfficeTaskRunner` 启动打包的 `office-process.cjs`，一次处理一个任务，限制 60 秒和 JS 堆 384 MiB，清除无关环境凭据并等待子进程关闭后释放槽位。该隔离不是操作系统权限沙箱，堆上限也不是原生库 RSS 上限。

`office-document.ts` 使用锁定依赖 `docx` 9.8.1 与 `pptxgenjs` 4.0.1 生成 OOXML；`office-layout.ts` 保守计算续页；`office-files.ts` 负责异步刷盘与原子发布。PptxGenJS 引入的 `image-size` 1.x 有无限循环漏洞，已限定覆盖到修复版本 2.0.4，安装审计为零漏洞，实际图片插入和打包回归通过。生成器仅插入已核验的内存图片，不接受远程 URL。

新增三个公开具名 IPC：`exportLessonOffice`、`cancelLessonOffice`、`openLessonOffice`；全部公开操作合计 70 个。内部 `readOfficeSnapshot` 不暴露给 Renderer。公开请求没有路径、文件字节、任意正文或执行参数。DB Schema 保持 6，导出产物携带版本元数据，不另建任意 Office 回写数据表。
