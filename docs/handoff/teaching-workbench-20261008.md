# 班级教学工作台与 WorkBuddy 接入验收记录

本轮落实客户提供的前端到教师备课子页，使用本机真实数据服务。验证使用隔离合成资料，没有修改客户数据库或导入原型演示数据。

## 实现范围

十二个教学入口与既有班级、学生、档案、考试、座位、值日共用数据；新增违纪、作业收交、请假、留痕、谈话、家访、家长会、群通知草稿、主题班会、活动照片、荣誉、待办、提醒和备忘。数据库版本 13，历史版本、请求去重、并发更正冲突及备份恢复均纳入校验。

WorkBuddy 使用本机 MCP stdio 连接器，无需额外安装 Node。查询可直接执行；教学记录、学生基本信息及在籍状态修改先形成方案，教师本地确认后执行。HTTP 仅监听 127.0.0.1 随机端口，要求令牌并拒绝网页 Origin；方案过期和恢复后的旧方案均不能执行。群通知没有实际发送能力。

## 已完成验证

全量单元与集成测试 1193 项通过，覆盖新增存储迁移、备份恢复、提醒去重、座位顺序和锁定、MCP 身份验证及确认。类型检查、Lint、格式检查及构建通过。新增 Windows 通知注册后，主进程与教学/MCP 的 73 项相关测试再次通过。

既有桌面回归通过，覆盖成绩导入和更正、座位和值日冲突恢复、备份恢复、诊断脱敏和十次重启。新教学界面完成十九类实际操作：空环境、名册去重导入、学生档案、违纪、作业、请假、留痕、谈话、逐人录分及分析、跨页档案关联、座位确认、联系台账和家访、家长会和通知草稿、活动照片、班会和荣誉、待办及备忘、Word/Excel/PNG 导出、MCP 本地审批、窄屏布局。

Computer Use 检查桌面名单、打开学生档案、Esc 关闭档案、打开智能对话和 MCP 设置小窗。档案中的考试和日常记录来自保存结果。检查后加宽教学弹窗并固定底部操作区，避免长表单操作按钮难以找到。

## 修正项

待办勾选及时反馈并在保存失败时回退；新增考试支持两位小数；无效照片在当前编辑小窗显示具体读取提示，读取时禁用重复操作；学生 Word 报告补齐考试成绩；MCP 保留全部待处理方案并限制已处理方案历史数量；更新旧版数据库迁移测试夹具和桌面接口名单。导出回归中发现测试脚本取错另存为参数，已修正，实际导出验证通过。

## 补充卡点修复

报告来自旧提交 7105dcd 的 Linux 演示构建。本轮在正式 Windows 代码中复核并修复五项：成绩文件按科目自动识别小数位；保存按钮旁汇总问题行并提供集中查看；空白或纯空格班级名称提示且不可保存；搜索无结果提供清空入口；考试名称默认“未命名考试”，名称或日期修改可一次核对并保存，科目和匹配修改明确提示先更新结果且尚未保存。

针对报告中的 88 名学生、65 份小数英语成绩进行了真实存储回归。无效三位小数仍会拒绝，原始成绩不会自动取整。Windows 统一导入界面回归通过，包括手动收窄精度后的阻塞原因、问题行筛选，以及改名后直接确认保存。

## 验收边界

免安装包在中文路径中解压启动、文件完整性、备份恢复和重启检查通过。使用包内 MCP 连接器完成本地确认，最小化后系统提醒触发 Windows 通知并启用声音选项。此项验证不代表实际听到声音，系统静音或勿扰仍会影响提示。退出程序后不后台通知。

使用测试 MCP 客户端验证真实连接器与桌面确认，不代表客户 WorkBuddy 账号已完成登录和接入。真实模型生成质量、平台额度和实际群发送不在本轮验收中。
