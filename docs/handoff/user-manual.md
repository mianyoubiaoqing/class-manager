# M0 用户操作手册

版本：0.1.0。日期：2026-09-29。适用范围：Windows 合成数据验证版，尚不用于真实学生业务。

## 1. 启动与退出

安装候选位于项目 `release` 目录。已打包程序可通过 `win-unpacked/Class Manager.exe` 打开，运行时保留该目录所有文件。客户端不需要安装 Node、Python、数据库服务器或 Office，也不需要启动 localhost。

本版尚未配置代码签名，目标电脑上的安装与安全策略需要首次部署时核对。出现安全提示时不要关闭系统防护，先向部署者确认文件来源、校验值和安装方案。

窗口右上角显示“本地就绪”后可操作。再次启动会聚焦已有窗口，不开第二个写入实例。正常关闭窗口即可退出；保存、恢复等进行中会提示稍后退出，避免中断操作。

## 2. 合成名册

1. 空名册点击“载入合成样例”，确认后创建两个虚构班级和 100 名合成学生。已有班级时不会再次覆盖载入。
2. 点击“创建班级”图标或左侧班级区加号，输入名称。左侧班级旁铅笔可重命名。
3. 点击“添加学生”，填写姓名、学生编号及班级。编号使用字母、数字、下划线或连字符，保存时统一为大写；同名学生可以存在，但编号不能重复。
4. 搜索框按姓名或编号筛选；通过班级、在籍状态和分页查看记录。
5. 每行铅笔编辑姓名、编号或班级。修改所属班级会保留原班级归属期间，并建立新记录。
6. 每行停用按钮经过确认后结束当前在籍记录，不删除学生。切换筛选为“停用”可恢复在籍；恢复后建立新的归属期间。

编辑学生窗口可查看班级归属记录。记录冲突时先取消编辑，点击页头刷新图标，再重新编辑。不要反复提交已经失效的表单。

窄窗口的表格可横向滚动。修改班级名称目前使用宽窗口左侧入口；窄窗口仍可创建班级和管理学生。

## 3. 备份与恢复

进入“数据与维护”：

1. 可点击“添加合成验证附件”，生成一份无真实资料的 TXT 测试附件。这是备份验证用文件，不是任意文档上传功能。
2. 点击“导出备份”，选择应用数据目录之外的位置，保存 `.cmbackup` 文件。取消保存不会修改数据。
3. 点击“选择备份恢复”，选取备份。程序先检查格式、数据库结构、哈希、附件及引用一致性。
4. 核对确认窗口中的时间和班级/学生/附件数量。点击“确认替换并恢复”后，当前数据会被替换，不会合并记录。
5. 恢复会保留原数据库和附件。恢复错了可点击“回退到恢复前”，再次核对并确认；回退本身也保留当时的数据副本。

建议重要修改前先导出备份。保存在同一磁盘的内部副本不能抵御磁盘故障，重要备份应另存独立介质。备份与数据库未加密，目前仅用于合成资料。

M0 备份上限为 32 MiB，数据库 8 MiB，单附件 1 MiB、合计 12 MiB，最多 32 个受管附件。不接受 ZIP、目录、链接或未知版本，也不会解包备份中提供的任意路径。坏备份不会替换当前库。

本机副本暂不自动删除，频繁恢复会增加磁盘占用。不要自行删除数据子目录或修改 `current.json`；需清理时先确认可恢复的外部备份，再由维护者处理。

## 4. 数据位置与升级

“数据与维护”显示当前数据目录。正常运行位于当前 Windows 用户的应用数据目录；开发测试可使用单独目录，以界面显示的位置为准，不依赖固定盘符或账户名。

本轮已打开的预览客户端使用项目内 `.local-data/workspace-data`，与默认安装版数据分开。该目录已从 Git 排除。将预览数据转到其他运行目录时，使用应用的备份恢复，不手动搬动单个数据库文件。

应用文件与业务数据分离。卸载配置默认保留数据；升级前仍应手工导出并验证备份。M0 只支持 Schema 1，遇到未知版本会停写，不会新建空库代替。不要把旧版程序强行用于新版数据库。

## 5. 故障排查

| 现象 | 可执行处理 |
| --- | --- |
| 编号重复或输入错误 | 检查编号、长度和所选班级，修正后再保存 |
| 记录已修改或数据已切换 | 关闭表单，刷新数据，再次核对后编辑 |
| 备份损坏或版本不支持 | 保留当前数据，换用已验证备份；不要修改哈希绕过检查 |
| 导出无法完成 | 关闭占用文件，选择有权限且不在应用数据目录内的位置，检查剩余空间 |
| 数据服务不可用或超时 | 退出重开，先核对是否已保存再决定重试；导出诊断并联系维护者 |
| 启动失败、库或附件缺失 | 保留整个数据目录和错误编号，不反复卸载、删库或移动子目录 |

## 6. DeepSeek 模型凭据与连接检查

进入主导航“模型设置”：

1. **凭据安全配置**：输入 DeepSeek API Key（以 `sk-` 开头），点击“保存并加密存储”。密钥通过 Windows DPAPI 系统级保护独立加密，不进入业务数据库，不随班级名册备份，界面仅回显掩码（如 `sk-...1234`），无法反查完整明文。
2. **清除凭据**：点击“清除已存凭据”并确认，系统将彻底删除本地加密文件，新任务无法读取旧凭据。
3. **文本模型检查**：点击“检查文本模型连通性”，向官方接口发送极小的合成 Ping 请求（使用 `deepseek-flash` 模型，显式关闭思考模式），检查认证有效性与文本生成通路。
4. **视觉模型检查**：点击“检查视觉模型连通性”，发送 1x1 微型合成透明图片，检查 Flash 多模态图像理解通路。文本检查成功不代表视觉通道可用，两项能力独立记录。
5. **用量与费用说明**：每次连接检查均产生极微量 Token（通常 < 100 Tokens），会在下方“用量与调用账本”中记录耗时、模型与 Token 消耗流水。

### 常见模型错误排查

| 错误码 | 原因说明 | 处置方式 |
| --- | --- | --- |
| `AUTH_FAILED` | API Key 无效或已失效 | 检查并在设置面板重新输入正确的 Key |
| `INSUFFICIENT_BALANCE` | DeepSeek 账户余额不足 | 登录 DeepSeek 平台充值后重试，客户端不自动重试 |
| `RATE_LIMIT` | 接口调用频率超出服务商限额 | 系统会自动进行 1 次有限退避重试，若仍失败请稍候再试 |
| `ENCRYPTION_UNAVAILABLE` | 系统级安全存储（DPAPI）不可用 | 检查 Windows 用户凭据服务，本客户端绝不降级为明文存储 |
| `NETWORK_ERROR` | 本机网络断开或无法连接 api.deepseek.com | 检查网络连接或防火墙设置 |


“导出诊断”只导出程序/系统版本、记录数量及本次会话错误编号，不包含学生姓名、编号、附件正文、完整数据路径或 Key。关闭程序后，本次会话错误列表不会自动保留，求助前先导出。

## 6. 支持边界

当前没有云模型或真实业务入口，不需要提供 API Key。本版不等于完整班级管理智能体。真实数据使用、后续功能及设备接入必须另行验收。

开发者仅负责首次部署和双方约定的 7 天维护；起止时间、求助渠道与响应范围待首次部署时明确。普通用户负责正常操作和备份，程序缺陷、数据迁移及系统兼容问题仍需技术人员处理。
