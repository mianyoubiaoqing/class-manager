## 业务对话和会话管理（当前）

1. 启动进入业务对话。点击发送或按Enter，Shift+Enter换行。可选班级、学生，未选择时助手可先查询对象。只读自动核对，正式变更按钮确认后立即继续下一步。
2. 侧栏“会话管理”可搜索、继续、新建、重命名和删除聊天。新建保留旧记录；删除需要确认，只删除聊天，不撤销业务结果。
3. 聊天、教学卡片、草稿和对象选择加密保存在本机，重启可继续。最多100段聊天，每段最近60条可见消息。正常关闭等待最后保存，失败可点击重试保存。
4. 无需查看JSON、脱敏上下文或内部参数。中文确认区展示“目前 / 确认后”，长名单可翻页。查看任务进展可同步任务，回包不明仍需核对原业务，避免重复提交。
5. 历史不恢复待确认按钮，正式操作须重新提议及确认。恢复工作区后旧聊天只读，开启新会话处理当前资料。
6. 发送使用当前模型，可能计费；每轮最多16次往返。资料先脱敏再交给模型，未知自由文本敏感事实仍需留意。验证采用模拟，真实账号理解效果另行验收。

## 业务对话入口（18 阶段历史）

1. 启动默认进入“业务对话”；主导航第一项也能随时返回。核对当前供应商和模型，可选班级、学生；也可以直接提出需求让助手先发现对象。没有模型时仍可使用四个本地快捷查询。
2. 输入消息，点击“发送”或按Enter；Shift+Enter换行。可以问候、追问并引用前文，切换业务页面再返回仍保留当前会话。
3. 发送即同意本轮使用当前模型，可能计费，每轮最多8次往返。只读工具自动执行；返回结果先清洗姓名、学号、业务ID、联系方式、密钥及路径，再交给模型。已知身份在输入中也自动遮蔽，未知自由文本的敏感事实仍请留意。无需逐条预览JSON或勾选外发。短学号按数字边界遮蔽，日期和带单位的分数保留；加“学号”可明确歧义数值。单字姓名保守遮蔽，可能隐藏同字普通词。成长查询只回传事实摘要、已确认条目及状态，不回传完整谈话、行动、结果或未确认草稿。
4. 助手可直接回答或追问，只读查询自动衔接。正式写入返回“提议·尚未执行”；创建/更名班级、学生在籍状态、倒计时、新增成长事实须核对真实对象、前后差异和全部内容，再勾选并点击“确认正式写入”。入分、总结入档、冻结、恢复、业务模型生成、课堂控制及导出打印进入原页面继续审核。
5. 未提交输入或未完成任务会阻止离页。放弃输入可点击“清空未提交输入”；放弃提议可取消当前任务。正式提交开始后不能撤回。
6. 错误、取消或回包不明不会自动重发、收费或写入。模型已答复但回包丢失时，自动回读或“查询原任务状态”会显示已有答案且不重复调用。先点击“查询原任务状态”，再核对原业务页面和供应商用量；不要把回包不明当作未执行。未接入外设明确无采集值/未送达。

对话正文和任务仅本次运行会话，重开后不恢复，也不进入备份/诊断；正式结果保存在原业务。后续消息会参考本会话的脱敏历史和工具结果；模型切换开始新上下文。“新对话”清空页面和Main会话，不删业务记录或用量。保留最近10轮/48条/100KiB；单次工具反馈48KiB，上限命中会停止并提示。真实模型理解效果和账号权限尚未验收。完整策略见[18说明](agent-conversation.md)。

## 1. 启动与退出

安装候选位于项目 `release` 目录。已打包程序可通过 `win-unpacked/Class Manager.exe` 打开，运行时保留该目录所有文件。客户端不需要安装 Node、Python、数据库服务器或 Office，也不需要启动 localhost。

本版尚未配置代码签名，目标电脑上的安装与安全策略需要首次部署时核对。出现安全提示时不要关闭系统防护，先向部署者确认文件来源、校验值和安装方案。

窗口右上角显示“本地就绪”后可操作。再次启动会聚焦已有窗口，不开第二个写入实例。正常关闭窗口即可退出；保存、恢复等进行中会提示稍后退出，避免中断操作。

## 2. 合成名册

1. 空名册点击“载入合成样例”，确认后创建两个虚构班级和 100 名合成学生。已有班级时不会再次覆盖载入。
2. 点击“创建班级”图标或左侧班级区加号，输入名称。左侧班级旁铅笔可重命名。
3. 点击“添加学生”，填写姓名、学生编号及班级。编号使用字母、数字、下划线或连字符，保存时统一为大写；同名学生可以存在，但编号不能重复。
4. 搜索框按姓名或编号筛选；通过班级、在籍状态和分页查看记录。
5. 每行铅笔编辑姓名、编号或班级。修改所属班级会保留原班级归属期间，并建立新记录。
6. 每行停用按钮经过确认后结束当前在籍记录，不删除学生。切换筛选为“停用”可恢复在籍；恢复后建立新的归属期间。

编辑学生窗口可查看班级归属记录。记录冲突时先取消编辑，点击页头刷新图标，再重新编辑。不要反复提交已经失效的表单。

窄窗口的表格可横向滚动。修改班级名称目前使用宽窗口左侧入口；窄窗口仍可创建班级和管理学生。

## 3. 备份与恢复

进入“数据与维护”：

1. 可点击“添加合成验证附件”，生成一份无真实资料的 TXT 测试附件。这是备份验证用文件，不是任意文档上传功能。
2. 点击“导出备份”，选择应用数据目录之外的位置，保存 `.cmbackup` 文件。取消保存不会修改数据。
3. 点击“选择备份恢复”，选取备份。程序先检查格式、数据库结构、哈希、附件及引用一致性。
4. 核对确认窗口中的时间和班级/学生/附件数量。点击“确认替换并恢复”后，当前数据会被替换，不会合并记录。
5. 恢复会保留原数据库和附件。恢复错了可点击“回退到恢复前”，再次核对并确认；回退本身也保留当时的数据副本。

建议重要修改前先导出备份。保存在同一磁盘的内部副本不能抵御磁盘故障，重要备份应另存独立介质。备份与数据库未加密，目前仅用于合成资料。

当前 Schema 11 候选备份上限为 224 MiB，数据库 64 MiB，单附件 32 MiB、合计 96 MiB，最多 1024 个受管附件；旧 v6–v10 保持相同原限额，旧 v1–v5 备份继续按原 128 MiB、单附件 1 MiB、合计 12 MiB、32 个附件的限制读取。上限是拒绝边界，不能保证同时装满各项。程序不接受 ZIP、目录、链接或未知版本，也不会解包备份中提供的任意路径。坏备份不会替换当前库。已分发的旧版安装包仍按其原有上限运行，源码变更不会自动更新已安装程序。

本机副本暂不自动删除，频繁恢复会增加磁盘占用。不要自行删除数据子目录或修改 `current.json`；需清理时先确认可恢复的外部备份，再由维护者处理。

## 4. 数据位置与升级

“数据与维护”显示当前数据目录。正常运行位于当前 Windows 用户的应用数据目录；开发测试可使用单独目录，以界面显示的位置为准，不依赖固定盘符或账户名。

本轮已打开的预览客户端使用项目内 `.local-data/workspace-data`，与默认安装版数据分开。该目录已从 Git 排除。将预览数据转到其他运行目录时，使用应用的备份恢复，不手动搬动单个数据库文件。

应用文件与业务数据分离。卸载配置默认保留数据；升级前仍应手工导出并验证备份。当前 16 候选将 Schema 1–10 数据升级为 Schema 11，升级前自动保留数据库副本；旧备份可预览并恢复。恢复会替换当前工作区，包括成绩、解释草案、座位、值日历史、资料、备课版本、课堂进度、倒计时、评分细则、答卷草案、尝试、冻结复核、修订历史、正式入分凭据、成长事件、总结草稿与正式总结，请先核对预览数量。用户安装的 07 冻结版仍为 Schema 5。未知版本停写；退回旧程序时使用升级前导出的旧版备份，不要手工修改版本号。

## 5. 故障排查

| 现象                   | 可执行处理                                                       |
| ---------------------- | ---------------------------------------------------------------- |
| 编号重复或输入错误     | 检查编号、长度和所选班级，修正后再保存                           |
| 记录已修改或数据已切换 | 关闭表单，刷新数据，再次核对后编辑                               |
| 备份损坏或版本不支持   | 保留当前数据，换用已验证备份；不要修改哈希绕过检查               |
| 导出无法完成           | 关闭占用文件，选择有权限且不在应用数据目录内的位置，检查剩余空间 |
| 数据服务不可用或超时   | 退出重开，先核对是否已保存再决定重试；导出诊断并联系维护者       |
| 启动失败、库或附件缺失 | 保留整个数据目录和错误编号，不反复卸载、删库或移动子目录         |

## 6. DeepSeek 模型凭据与连接检查

进入主导航“模型设置”：

1. **凭据安全配置**：输入 DeepSeek API Key（以 `sk-` 开头），点击“保存并加密存储”。提交时输入框立即清空，密钥通过 Windows DPAPI 系统级保护独立加密，不进入业务数据库，不随班级名册备份，界面仅回显掩码（如 `sk-...1234`），无法反查完整明文。
2. **清除凭据**：点击“清除已存凭据”并确认，系统将彻底删除本地加密文件，新任务无法读取旧凭据。
3. **更换 Key 步骤**：若需更换密钥，直接在输入框中粘贴新 Key 并点击“保存并加密存储”，系统将自动覆盖旧密钥文件并更新掩码与配置时间戳；也可先点击“清除已存凭据”再录入新 Key。
4. **文本模型检查**：点击“检查文本模型连通性”，向官方接口发送极小的合成 Ping 请求（提示词版本：`ping-v1`，使用 `deepseek-flash` 模型，`max_tokens: 5`，显式关闭思考模式），检查认证有效性与文本生成通路。
5. **视觉模型检查**：点击“检查视觉模型连通性”，发送 1x1 微型合成透明图片（提示词版本：`synthetic-1x1-v1`，使用 `deepseek-flash` Vision 模型，`max_tokens: 5`），检查 Flash 多模态图像理解通路。文本检查成功不代表视觉通道可用，两项能力独立记录。
6. **任务取消保护**：检查请求执行期间，用户可点击“取消检查”主动中断调用；系统具备任务序列保护，迟到响应或取消后返回的数据均被安全丢弃，不覆盖后续新任务。
7. **用量与费用说明**：每次连接检查均产生极微量 Token（通常 < 100 Tokens），会在下方“用量与调用账本”中记录响应 ID、耗时、模型与 Token 消耗流水。

### 账号归属与用量观测边界

- **服务账号归属**：正式使用时由学校或使用教师自行提供并承担 DeepSeek 服务账号及费用预算，客户端不预埋共享 Key，开发者个人账号不作为长期服务账号绑定。
- **用量观测边界**：客户端内的“用量账本”仅统计并观测**本机客户端内部**发起的模型调用（包含连通性检查与后续业务调用），不包含外部开发工具、调试或第三方调用的 Token 消耗；项目规划中提及的 10 亿 Token 为项目开发调试总预算，与单个学校或班级客户端运行账本相互独立。

### 常见模型错误排查

| 错误码                   | 原因说明                                | 处置方式                                                                 |
| ------------------------ | --------------------------------------- | ------------------------------------------------------------------------ |
| `AUTH_FAILED`            | API Key 无效或已失效                    | 检查并在设置面板重新输入正确的 Key，系统不无限重试                       |
| `INSUFFICIENT_BALANCE`   | DeepSeek 账户余额不足                   | 登录 DeepSeek 平台充值后重试，客户端不自动重试                           |
| `RATE_LIMIT`             | 接口调用频率超出服务商限额              | 连接检查有有限重试；成绩解释不自动重试，先核对草案列表及用量，再主动重试 |
| `ENCRYPTION_UNAVAILABLE` | 系统级安全存储（DPAPI）不可用           | 检查 Windows 用户凭据服务，本客户端绝不降级为明文存储                    |
| `NETWORK_ERROR`          | 本机网络断开或无法连接 api.deepseek.com | 检查网络连接或防火墙设置                                                 |

## 7. 成绩解释草案

当前开发候选已提供此页面，已完成一次真实服务商生成验证；样本仍为合成数据，不要把验证结果当作正式教育评价。用户原安装包尚未更新为当前开发候选。

1. 在“成绩管理”打开已保存的考试，找到“成绩解释”。新解释只能基于最新成绩版本；历史版本仍可查阅原草案。
2. 选择班级或单个学生、科目和指标，点击“预览出站指标”。均分等派生指标需要同时选择满分及有效人数；遗漏时系统明确提示，不会偷偷增加出站字段。
3. 核对“出站确认”中的本地数值和“实际出站数据”。勾选费用确认后才会调用 DeepSeek。显示的姓名、编号及本地科目名称不会包含在出站 JSON 中，但少量统计仍可能具有识别风险。
4. 生成结果自动保存为草案。本地事实、证据限制、未经核实的模型原稿及教师编辑分区显示。原稿引用的 F001 等编号对应本地事实表；引用校验通过不代表自由文本结论真实。
5. 在教师编辑区修改并点击“保存教师编辑”。未保存时切换页面及成绩版本会被禁用；可用“放弃本次编辑”恢复上次保存内容。退出程序前先保存，未保存的文字不是备份内容。
6. “丢弃草案”需要再次确认；确认期间修改内容会撤销确认。丢弃不改变成绩，记录仍保留且不可编辑，可勾选“包含已丢弃草案”查阅。
7. 成绩更正后旧草案标记“来源已过期”，其中数值仍是旧成绩版本。最新版本重新生成会建立新草案，不覆盖教师已修改的旧稿。

取消不等于撤销已提交的保存，也不保证服务商没有收费。生成失败或响应中断后页面会尝试重新读取草案列表；先核对是否已有新草案，再决定重试。特别是“草案已写入、用量账本写入失败”时，不能因为报错就立即再发一次请求。账本未知用量以服务商账单为准。

解释内容不会自动写入正式成长档案、改分或发送通知。没有题目级数据时，不能据此断言具体知识点、品德、心理状态或升学概率。

## 8. 座位编排

本节对应当前开发版，尚未更新客户安装包。

1. 打开“座位编排”，选择班级。设置行数、列数并点击“应用行列”，再点“新建座位草案”。已有历史方案也可以设置新草案布局，不会改动旧方案。
2. 在“布局”模式点选空格，标记或取消不可用位置。已有学生的位置不能直接封闭；先移走学生。过道可按不可用位置处理。
3. 点击“随机编排”。从“调位学生”选择学生，点锁形按钮可固定其位置；之后随机只调整未锁定成员。调整锁定学生前须先解锁。
4. 在“调位”模式选择学生，再点击目标格。目标已有未锁定学生时交换，目标为空时移动；未安排的学生只能进入空位。
5. 填写保存原因，点击“确认保存座位”，核对班级、人数及版本后保存。只有成员全部安排且无冲突的方案可以确认。
6. “从最新版本调整”建立独立草案；取消不删除已保存版本。“已确认座位版本”可查看历史姓名、编号和布局。转班或改名后历史不会被改写；重新编排需从当前名册新建。
7. 选择要打印的确认版本，点击“预览与打印所选版本”。独立预览窗口会固定该版本，不能打印未保存草案；标题、页码及原始行列范围可用于核对。
8. 从预览窗口顶部“打印”菜单选择“打印所示确认版本”，在系统对话框选择打印机；也可选择“导出所示版本 PDF”。宽布局会分片为多页，按每页行列范围查看，纸张为 A4 横向。
9. 取消打印或导出会显示明确提示；“已提交打印队列”不代表已经出纸。打印途中关闭预览可能使结果不明，先检查系统队列，不要直接重复打印。关闭预览后返回座位页面。

草案仅在本次会话中保留，每次成功操作后有效期为 15 分钟；退出前请确认保存。响应中断时先核对历史，不要直接重复新建。页面提供“使用原请求重试”；若取消失败，可用“关闭草案并核对历史”恢复页面。取消不能撤销已经成功保存的版本。班级超过默认容量时，先扩大新草案的行数或列数。

当前不支持身高、视力、成绩或学生关系推断，不承诺多次随机构成公平轮换。座位操作不消耗模型 Token。

预览会临时保存本机打印文件，正常关闭后删除，重启时会重试清理中断残留。若提示缓存未完全清理，请重开程序后导出诊断并联系维护人员，不要自行删除业务数据库。正式使用前须在客户打印机上核对纸张、驱动及实际出纸；当前自动验证包含真实 PDF，但不包含客户现场打印机。

## 9. 当期值日轮换

本节对应开发版合成验证，不代表客户安装包已更新。值日及打印无需 API Key、不调用模型。

1. 打开“值日轮换”，选择班级，点击“新建一期值日”。填写计划名称和组数，核对参与成员。分组按所选成员顺序依次分配，不是固定值日小组。
2. 选择开始、结束日期及星期选项，点击“添加日期”。可以多次添加不同范围，并逐日移除不需要的日期。程序不会推断节假日，未点“添加日期”的范围不算已选日期。
3. 填写各岗位名称、开始/结束时间及人数。时间格式为 `HH:mm`，结束时间可为 `24:00`；跨午夜岗位应拆分到两个日期。点击“生成值日草案”。
4. 核对缺口、空组，以及“分组与次数”中的当期成员和各组值日天数。岗位人数不足时保留空位，不能保存确认。组天数和成员岗位次数只是计数，不代表不同岗位劳动量相等。
5. 从“安排日期”选择某天，在岗位下拉框选择成员可临时换人。不可用成员、同一时段重复占岗会被拒绝；清空岗位会形成缺口。修改“当日不可用”后，该成员当天原岗位会变为空位；恢复可用不会自动补位。
6. “调整分组与参与名单”可以改组名、组顺序及成员分组，也可将成员设为“不参与本期”或增加本班有效成员。所有当前参与者须且仅须属于一组，不能空组。应用前会提示重建未冻结日期岗位、清除这些日期临时替换的影响；核对返回草案后再保存。组顺序改变后，须显式点击“重新轮换未冻结日期”才能按新顺序轮换。
7. “当日小组”及“重排当天岗位”只重建所选未冻结日期。当前或过去日期可以标记完成，但新一期须先保存一次，未来日期不能提前完成。完成确认后该日安排不能再修改；过去日期的成员、组名及安排也不会因当期换人被改写。
8. 填写保存原因，点击“确认保存值日”，再次核对后保存。若明确提示跨计划冲突，可直接调整名单后再确认；同一成员不能在两个计划的重叠时段值日。
9. 在“值日计划”和“确认版本”选择已确认记录。历史显示当时的姓名、编号、分组和安排，不替换成现在的名册。“调整本期最新版本”总是从该计划最新版本建立草案，不会覆盖所选旧版。
10. 选择确认版本，点击“预览与打印所选值日版本”。表格先列当期分组，再列各日岗位、当日组员快照和不可用名单；临时替换另行标记。每页有确认版本、日期或名单区段、重复表头和页码，使用 A4 横向。
11. 预览窗口的“打印”菜单可调用系统打印或导出 PDF。超过 100 页时，每次只加载一批；菜单中的“上一批／下一批”切换页段。“打印当前批次／导出当前批次 PDF”只处理当前所示页段，其余批次需要分别操作。PDF 默认文件名包含页码范围，务必按总页数核对所有批次齐全。
12. 取消系统打印或 PDF 保存不会改动值日版本；关闭预览后回到页面。任务仍在进行时关闭，结果可能不明，应先检查文件和打印队列再重试。已经导出的批次不会因后续取消而被删除；提交打印队列不等于实际出纸。

草案只在本次会话中保留，每次成功调整后有效期为 15 分钟。保存响应中断时保留“使用原请求重试”，不要重复新建；调整响应中断时停止编辑，可取消草案。取消失败后可用“关闭草案并核对历史”。关闭或取消不删除已保存版本，退出前应先核对确认历史。

日期保护以中国时区日历为准，并保留已经观察到的日期下界；改系统时间或恢复旧备份不能重新开放已过去的安排。若日期被误调到未来，请停止操作并联系维护人员，不要手工改库。

## 10. 资料备课

本节对应独立开发候选中的合成资料验证，用户已安装的 07 冻结版尚不包含备课页面。已授权的单次真实文字/图像备课生成、教师保存冻结与无凭据重开已验证，正式教学仍须教师核对。

1. 打开“资料备课”，点击“选择资料文件”。支持 TXT、DOCX、PDF、PNG、JPG，每份最多 10 MiB；PDF 最多 20 页、图片最多 2000 万像素。先查看解析内容、警告和原页图像，再“确认保存资料”。此步骤只在本地处理，不调用模型。
2. 在“对照片段”查看行号、段落或页码；可保存原文件副本，用阅读器核对。扫描页保存为图像，不表示已完成文字识别。DOCX 的复杂排版等可能只部分解析；请核对警告，明确确认可读范围。
3. 勾选允许发送的片段，可跨多份资料选择。最多 8 份资料、80 个片段、80000 个文字字符；一次模型请求最多 8 张图像。填写课题、学科、年级、课时及教学要求，点击“准备并核对外发范围”。原件、未选内容和本地教师备注不会自动发送。
4. 核对范围与费用提示，勾选确认后“确认付费生成草案”。准备不产生费用，生成使用本地配置的 DeepSeek Key。失败、取消或重启不会自动再付费；如结果不明，先刷新目录核对。取消不能撤销已经提交的保存。
5. 在草案中编辑标题、目标、重点、难点、环节、提问和课件。支持段落、列表和原生表格；所选图像可插入课件。资料依据可点击查看来源，额外建议明确标为补充，仍须教师复核。参考答案与教师私有备注分别编辑。
6. 点击“保存教师修改”。未保存时不能切换草案或生成；正在保存回读、确认生成或冻结时暂时锁定编辑。输入结构或环节总时长不符合要求时会拒绝保存，应核对内容后再操作。
7. 填写原因并“冻结备课版本”，形成同版教案和课件的不可变记录。历史版本可查看；继续修改应“基于此冻结版创建修订草案”，本地修订不调用模型。丢弃草案保留记录但不再可编辑。

退出前保存教师修改。重开不会自动继续生成；已保存资料、教师稿和冻结历史仍可离线查看。09 已提供下述 Word/PPTX 导出；含 10 的新构建提供课堂展示。07 冻结安装版不含这些新功能。

## 11. 可编辑 Word 与 PPTX 导出

1. 在“资料备课”选择已保存草案，点击所需“冻结版”历史按钮，核对版本标题。导出只使用该只读冻结版本，不重新调用模型，不需要 Key。
2. 在“导出此冻结版本”选择“保存可编辑 Word 教案”或“保存可编辑 PPTX 课件”。参考答案和教师私有备注默认不包含。明确勾选答案后，答案将出现在课件画布；备注在 Word 为正文，在 PPTX 为演讲者备注。分享含备注的文件也会分享备注。
3. 在保存对话框选择应用数据目录之外的普通本地 NTFS 目录。取消不会保存；已有同名文件还须额外明确确认覆盖。任务进行中可点击取消，不自动重试。
4. 保存成功后可点击“打开刚保存的文件”。若提示文件核验受限，保存已完成，但此按钮不可用；可在保存目录核对文件。退出应用后仍可从目录打开。文件被外部改写或恢复工作区后，原打开回执会失效。
5. Word 是中文 A4 教案，PPTX 是 16:9 课件，使用微软雅黑；文字、列表和表格可以在办公软件中编辑，资料图片是独立图片对象。外部修改不自动回写客户端。投影或分享前检查答案、备注、字体和分页。

当前实际编辑验收软件为 WPS Office 12.1.0.28505；未现场验证 Microsoft Word/PowerPoint。没有微软雅黑或换用其他软件时须重新检查排版。输出最多 64 MiB，课件最多 1000 页；超过限制整体拒绝。生成文件不需要安装 Office。遇到占用或无权限请关闭占用文件、另选可写本地目录后手动重试；FAT/exFAT 和网络共享不在支持范围。完整限制见 [Office 导出说明](office-export.md)。

## 12. 课堂辅助与倒计时

1. 打开“课堂与倒计时”，选择授课班级、备课主题和具体冻结版本，勾选允许展示的课件页。核对版本及范围后勾选确认，再点击“确认此版范围并创建课堂”。新课堂处于暂停状态。
2. “课堂进度”可选择已保存课堂。它始终使用创建时的冻结版，之后修改备课草稿或生成新版本不会替换当前课。目录每批显示 50 条，可以切换批次。
3. 点击“打开全屏课堂展示”打开独立展示窗。展示窗可切换全屏，长内容可滚动查看；操作课件页、环节和计时仍在教师控制页进行。私有备注、名册、成绩和成长档案不传入展示窗。
4. “教师提问提示”仅供教师查看；需要向学生展示时，明确勾选显示当前环节问题或当前页参考答案。换页会隐藏问题及答案，重新打开展示也会隐藏此前的选择；需要时重新勾选。
5. 使用“开始或恢复计时”“保存进度并暂停”控制当前环节。切换到其他环节时暂停并重置计时；同环节换页保留时间。关闭展示窗不会暂停计时，一次只能运行一堂课堂的计时，最长 24 小时。
6. 退出前建议保存并暂停。正常退出会完成最后保存；若保存失败，窗口会提供保留窗口检查问题或使用上次保存进度退出的选择。异常退出后恢复最近持久保存的进度，保持暂停并提示中断，关闭期间不累加时间。自动保存通常每 5 秒进行一次，备份等繁忙操作期间可延后；授课进度不代表学生已经掌握知识。
7. 在“高考倒计时”填写名称、目标日期和目标时区，例如 `Asia/Shanghai`，点击保存。程序不预填某年考试日期，不推断当地安排；按所选时区的日历日期差显示天数。目标当天显示“目标日期已到”，过去显示“目标日期已过”。首页与展示窗会刷新，重新显示窗口时读取当前状态。

课堂及倒计时离线可用，不调用模型。备份包含两类记录；恢复会关闭展示窗并暂停课堂，需要重新选择恢复后的进度。更换版本须新建课堂，不能编辑当前课堂指向的冻结版。当前仅教师主导展示，不提供学生端互动或自主授课。

## 13. 答卷建议与复核

本节适用于 11 的独立 Schema 8 合成验证候选。在线两页六题合成小样本已通过普通题型识别和评分比较；当前不用于真实学生答卷，不能据此推断任意真实笔迹准确率。详细限制见 [阅卷说明](grading.md)。

1. 打开“答卷建议与复核”，选择已有考试、科目、学生。名册身份由教师明确选择，模型不推断归属。创建或选择不可变评分细则版本；逐题满分须合计为该科目满分，选择题尤其要核对多选部分给分规则。
2. 导入 JPG/PNG/PDF 合成材料，核对解析状态后保存材料并加入答卷。每页选择“学生答卷”“题目材料”或“标准答案 / 细则材料”，上移/下移核对顺序，填写预计答卷页数。题目材料不能代替学生答卷。PDF 至多 20 页、单图至多 2000 万像素、导入单文件至多 10 MiB；超限分拆，不静默截断。
3. 读取原图，可拖选或填写百分比裁剪与身份遮盖区域，设置顺时针旋转。黑色覆盖层本身不是外发图；后续实际预览使用重新生成、实际遮盖像素的 JPEG。检查姓名、编号、二维码及正文身份信息；原件只保留本地。
4. 核对合成材料、考试学生、角色、页序及细则后保存答卷输入。选择本批页面和题目（一次最多 8 页），准备实际外发预览；查看每页处理图及完整评分规则，明确确认后才生成一次。预览 15 分钟到期，来源、版本、凭据变化或取消后须重新准备。
5. 模型读取作答后客观题按本地细则计分，短文本只是建议。模糊、缺页、遗漏或不支持题型显示待人工，不能自动视为零分；手写公式、推导等不自动处理。对照原图及处理图定位逐题依据，修正作答、分数及理由，给不支持题人工补评并明确勾选本题审核。编辑后须重新勾选审核。
6. 所有题目完整、分数合法、每题已审核、来源仍有效及答卷页数齐全后才可“确认冻结复核”。冻结只形成复核版本。12 候选提供单独的正式入分差异及明确确认流程，见下一节。冻结后通过“从此冻结复核创建修订草案”修订，保留父版本。历史中的原图依据、裁剪旋转及细则来自确切修订。
7. 页面显示来源变化时，先核对当前来源并明确重新绑定，变化将清除原建议和审核，随后重新生成或人工核对。不要把旧审核沿用到新图或新细则。切换模块前保存修改；未保存编辑有离开保护。
8. 取消、超时、离线或无效返回保留已保存输入和尝试，不显示已阅完。取消不保证服务商停止计费，用量缺少为未知；程序不自动重放付费任务。回执不明时先“重新读取答卷与尝试”核对，重复真实调用可能再次收费。未配置 Key 时仍可查看已有记录并人工复核，备份包含阅卷资料及不可变历史，不包含 Key。

## 14. 复核结果正式入分

本节适用于 12 独立 Schema 9 候选，不会自动更新用户已安装的 07 冻结版。

1. 在“答卷建议与复核”选择完整冻结复核，点击“准备正式入分差异”，核对原分、新分、学生、科目和考试；展开“核对入分依据”确认细则、答卷修订及成绩父版。
2. 填写入分说明，勾选正式写入确认；已有有效分（含零分）、缺考或未选考时，还须明确同意替换。本次仅更新该学生该科目，其他成绩保留。
3. 点击“确认正式入分”。成功后到“成绩管理”查看新版本统计及“成绩来源与排除记录”，旧成绩可选回查看并显示历史提示。
4. 响应中断时先“查询入分结果”；查到表示已提交，重复操作不会再次改分。查不到可重新准备并核对，不需要重新调用模型。预览过期、工作区恢复或来源冲突后必须重新读取，不能强行覆盖。
5. 更正已经入分的结果时，从成绩管理最新版本按原表格更正流程操作；或从冻结复核创建修订草案，重新绑定最新成绩及适用细则，逐题复核、冻结并明确发布。原复核不能重复发布成第二次变更，旧依据不会被删除。

这里只使用合成材料验证。正式入分本身完全离线、不调用模型；完整产品和用户安装验收仍待 15。

## 15. 成长档案与阶段总结

1. 打开“成长档案”，选择合成学生。填写日期、事件或谈话类型、跟进状态、完整本地记录、来源、行动/结果及记录说明，点击“保存事件记录”。“更正事件”新增修订；“查看事件修订”保留全部字段旧值。“已完成记录”只表示教师记录的跟进状态。
2. 若希望选入阶段总结，单独填写最小事实摘要。完整谈话、行动及结果不会自动外发；最小摘要会原样发送，须去除姓名、编号、联系信息等，并核对摘要中的日期。修改输入后先保存或取消事件编辑再换学生/模块。
3. 选择阶段起止日期和所需事件修订；关联考试并勾选科目可引用确切成绩版本和该学生成绩。没有事实时会提示资料不足；旧版或阶段外来源不能用于新的总结。
4. 可离线填写并“保存人工总结草稿”。在线路径先核对合成与脱敏条件，点击“预览在线总结的实际外发事实”，逐项核对实际 F 编号/类别/文本，再另行确认本次可能付费生成。程序不自动重试。
5. 生成只建立未审核草稿。核对事实、建议及限制，编辑“教师复核正文”并保存；填写入档说明，分别确认正文和确切来源，才可“确认总结正式入档”。草稿、事实和正式条目分开展示，不能把草稿当作正式结论。
6. 响应中断先“刷新档案与入档状态”或读取原草稿。已查到正式条目时重复确认返回原条目，不重复入档；不要再次付费生成来核对保存结果。取消失败会给出错误编号，取消成功仍须查询是否在取消前保存。
7. 事件、成绩或成员变化后显示来源重核提示，历史正文保持原样。用“更正正式总结”重新选择最新来源、保存独立人工草稿、复核确认形成后继条目，原条目保留。总结不能选自身输出作为事实来源。
8. 无模型或模型失败仍能维护本地事件与人工草稿。课堂展示窗没有档案读取权限。备份包含事件、草稿、正式条目及必要历史；恢复前核对三项数量，Key 不进入业务备份。

操作与验证记录见 [成长档案](growth.md)。当前仅合成验证，不用于真实学生画像或心理判断。

## 16. 外设接口

1. 打开“外设接口”，两项默认均未接入。点击一次音量测量只返回不可测量，没有现场数值/告警；音量不能判断纪律或声音来源。
2. 选择合成学生、填写说明并核对目标；分别勾选仅合成名册和教师确认，再请求呼叫。未接入结果为不可执行，不代表受理或送达。
3. 查询原呼叫结果保持原操作ID。取消/超时/回包中断不能证明未发送；先查询，不能自动重发。清空输入后才能换模块。当前会话结果不持久，重开查询不到不是未发送证明。
4. 真实外设尚未接入，客户是否接受此接口交付仍待确认。后续硬件、校准及通道身份/成本另行落实。

## 17. 多供应商模型设置

1. 打开“模型设置”，选择要编辑的Kimi、豆包或DeepSeek。页面上方显示当前业务使用的供应商；仅编辑另一个供应商不会自动切换。
2. 保存文本和图像型号。豆包须填写本账号已开通的Model或Endpoint ID；图像型号留空会禁用图像外发。Kimi预设和支持范围见[官方依据及实现](../planning/model-providers.md)。
3. 在当前电脑本地输入该供应商Key并加密保存，再点击“使用此供应商”。不得通过聊天或截图发送完整Key。切换及更换凭据会作废旧准备和在途任务。
4. 需要检查时先点击“预览文本检查外发”或“预览图像检查外发”，核对供应商、地址和实际JSON，再勾选可能付费确认并发送一次。图像检查只使用合成1×1图片。预设不表示账号权限已验证。
5. 检查取消、超时、错误或回包不明后先读取该供应商用量，并在其控制台核对实际账单；本地没有收到usage显示未知。没有自动重试或跨供应商回退。
6. 删除某家Key不删除该家用量或既往业务原稿，不影响其他供应商。业务备份不含账号配置、Key及本地用量；换电脑或重装后自行在设置中配置凭据。

当前只完成合成替身验证，用户真实账号未配置/验收。详见[16验收](model-providers-acceptance.md)。统一对话入口由后续17实施。

## 18. 支持与说明

“导出诊断”只导出程序/系统版本、记录数量及本次会话错误编号，不包含学生姓名、编号、附件正文、完整数据路径或 Key。关闭程序后，本次会话错误列表不会自动保留，求助前先导出。

当前业务数据仅使用合成数据验证。正式数据使用、后续高级功能及外部设备接入必须按项目里程碑逐步验收。

开发者仅负责首次部署和双方约定的 7 天维护；起止时间、求助渠道与响应范围待首次部署时明确。普通用户负责正常操作和备份，程序缺陷、数据迁移及系统兼容问题仍需技术人员处理。
