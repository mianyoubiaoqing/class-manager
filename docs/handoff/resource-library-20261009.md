## 本版变化

- 班主任管理使用原教师工作台，仪表盘为唯一首页。名单、点名、历史成绩、座位、值日和成长档案保留，共用学生身份。
- 教师备课使用客户提供的高中教学资源库布局，保留本地备课、资源平台、课堂与倒计时、答卷建议与复核。
- 十科学科模板分别调整。客户原目录中复用的版本标为通用目录，需对照教材核对；模板空白须由教师补充，不作为真实教材正文。
- 章节编辑和附件使用数据库版本 14。本地原文件复制进附件库，随备份恢复；网页不获得任意路径读取权限。
- DOCX 使用真实 Word 文档生成流程，打印预览使用当前编辑内容。章节切换和离开页面提示未保存内容。

`scripts/resource-library-ui-smoke.mjs` 验证十科模板、版本提示、章节查找、未保存保护、原生文件选择、文件夹读取、附件绑定、真实 DOCX、原生打印预览、重启、备份恢复和窄窗口布局。外部打开的系统边界使用模拟，不在测试中启动第三方账户或软件。

`scripts/shared-class-data-smoke.mjs` 验证名单与成绩联合导入、预览与原子保存、学生身份匹配、点名、第二次考试复用身份、重启和异常输入。

`scripts/teaching-ui-smoke.mjs` 验证迁移后的班主任记录、资料入口、备课工具、响应式布局和隔离环境中的 WorkBuddy MCP 注册与确认流程。

结果 JSON 与截图位于 `output/playwright/resource-library`、`output/playwright/shared-class-data` 和 `output/playwright/teaching`。免安装打包器另外验证实际 ZIP 解压、启动、备份、重启和共享资料流程；最终交付指针仅在打包验收成功后更新。
