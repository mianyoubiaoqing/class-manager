## 已复现的问题与修复

修复前快照：`f421316b846aa1530c9f4f7666dd3413c45acfdb`。这是本轮开始时包含既有未提交功能的工作区快照，不改变当前分支或用户索引。审计比较对象为该快照与本轮最终候选快照；历史未提交改动不算入本轮修复。

`output/ui-feedback-repro.mjs` 在真实 Electron 界面复现三个失败条件，结果见 `output/ui-feedback-20261005/repro.json`：

- 对话选择器容器是 `display:block / gap:normal`，对应 JSX 类名在新样式入口中没有规则。补充实际类名的布局、间距和窄窗口适配。
- 学生表单标签是 `display:inline`，前两个输入框挤在同一行，第三个字段换到下一行。新样式只覆盖 `.dialog` 而未覆盖实际原生 `dialog` 内的表单；补充原生弹窗尺寸、滚动、字段布局与编号说明。
- 修改模型设置后，侧栏按钮直接变成 `disabled`。改成可点击的导航守卫，在未保存或任务进行中时明确说明原因，提供返回当前操作页的按钮；保存/清空/取消后可正常切换。不会因一次侧栏点击丢弃草稿或重复执行任务。

本机合成输入中的学生编号可正常输入和保留；视频本身可以确认排版问题，尚未取得输入丢失的可重复证据。
