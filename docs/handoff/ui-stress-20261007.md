原“你都有哪些能力？”悬浮大卡片已删除，工具设置移到顶部“···”。新回复在阅读位置靠近底部时跟随滚动；用户向上阅读时不强制跳回。班级名称编辑移到名册页，未随侧栏精简丢失。

## 压力和异常场景

- 达到100段会话上限后，第101段创建失败，原记录不被替换。
- 60条长消息正常显示，超大存档请求被拒绝，保留上一次保存的版本。
- 200个并发快照读取返回同一工作区且无渲染错误。
- 30次快速切换核对独立草稿；三次原生关闭重开保留关闭前最后输入。
- 历史列表按50条分批显示，支持搜索、继续、重命名、删除取消和确认；恢复前记录只供查看。
- 360、640、800、1024、1280、1440像素窗口，以及1440像素窗口下125%和150%页面缩放，历史项没有文字与操作重叠或页面横向溢出。页面缩放不等同于所有显示器的原生DPI验证。
- 三家供应商模拟流式响应中的工具参数错误可修正；正式写入需再次确认；取消不执行。HTTP错误停止在一次请求，响应格式错误在首次请求加五次重试后暂停。
- 自动保存失败保留最新待保存内容；显式重试可保存。丢失调用回包可读取已保存结果，避免重复调用和重复显示。
- 本地文件夹选择、显式读取、递归扫描、入口移除、平台入口和全部子页面使用真实桌面链路验证。
