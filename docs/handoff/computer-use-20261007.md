# Computer Use 全流程验收记录

日期：2026-10-07。Windows x64，Class Manager 0.1.0。本轮已完成全部本地模块的主流程实操，上课与考试流程贯通；发现的下述卡点已修复。真实在线供应商、第三方平台账号与实际外设未验收，不作零缺陷承诺。

## 环境与方法

业务操作通过 computer-use 技能的 Windows Computer Use 完成：逐步观察窗口，鼠标点击、键盘输入、滚动，使用系统文件选择与保存窗口。采用独立 Electron 应用及数据目录 `output/computer-use/audit-NZJOak`；没有操作客户旧版本窗口或真实业务数据库。全部班级、学生、成绩、课文和答卷为合成资料。

在线功能使用隔离的模拟响应与合成凭据，模型请求由验收进程截获，不向真实供应商发送。应用真实 SQLite、附件读取、备份恢复、Word/PPTX 导出和教师确认流程正常运行。启动隔离环境和模拟服务由工具脚本准备，业务实操没有用接口或数据库写入代替点击。完成后仅只读核对数据库和导出文件。

另有自动化 Electron 流程、回归及压力检查，单独列为补充证据，不将其混同为 Computer Use 实操。旧验收记录仍保留在 `computer-use-acceptance.md`。

## 上课流程

创建班级 → 导入 6 人 → 点名并保存 → 选择本地资料 → 写课题、学科、年级、课时 → 核对外发 → 模拟生成教案 → 教师编辑和冻结 → 原生保存 DOCX/PPTX → 开始课堂 → 4 页展示、倒计时与学生窗口 → 结束并保存。

导出的 DOCX、PPTX 均通过 ZIP CRC 与文档结构检查，课件有 4 个幻灯片。此检查不等于本机 Office 或投影设备兼容性验收。

## 考试流程

创建考试与语文、数学科目 → 导入名单已匹配的成绩 → 核对缺失与错误 → 确认第 1 版 → 语文 88→90 更正第 2 版 → 创建数学细则与答卷 → 教师复核冻结 → 核对数学 95→100 → 正式入分第 3 版 → 查询回执与不可变历史。

完成后只读数据库：1 班、6 学生、6 在籍、1 考试、3 成绩版本、1 课堂、1 冻结教案、1 点名、1 座位方案、1 值日方案、1 正式成长总结、1 冻结答卷复核、1 正式入分记录。详细记录在隔离目录 `postconditions.json`。
