# M0 本机验证记录

日期：2026-09-29。版本：0.1.0。结论：**M0 本机实现与验证完成，可继续工程开发；尚非客户目标环境的完整发布验收。**

## 环境与范围

- Windows 11 专业版 x64，系统版本 10.0.26200；检查进程不是提权管理员。
- 开发 Node 24.14.0，打包 Electron 44.4.5，实测内置 Node 24.21.0；具体依赖由 `package-lock.json` 锁定。
- 仅使用合成数据和独立临时目录；未读取用户 API Key，未调用云模型或真实业务系统。
- 已实现班级/学生名册、归属历史、持久化、备份恢复与回退、诊断及桌面隔离。八项业务功能属于后续 M1。

## 核心异常覆盖

33 项测试包含持久化重开、重名/编号冲突、陈旧编辑、转班历史、停用/恢复在籍、控制字符、系统时间回拨、示例不覆盖数据、备份格式/版本/编码/哈希/路径字段/附件异常、额外 SQL 触发器拒绝、未知 Schema 保留原文件、数据库/附件缺失、预览 token 失效、恢复入口发布前后进程退出、工作线程无响应超时、IPC 来源判断、受保护导出目录及错误脱敏。

进程退出测试使用独立子进程 `process.exit(77)`，不是物理断电测试。数据库异常构造仅在临时合成数据目录进行。

## 尚未验收与已知限制

1. 客户目标电脑与干净 Windows 系统上的实际安装、升级、卸载及普通用户独立操作；当前是在装有开发工具的本机验证打包 EXE。
2. 60 分钟混合压力测试、真实磁盘满/权限/文件占用、物理断电、杀毒软件拦截及长期运行。
3. 当前数据库损坏或附件缺失导致启动受阻时，会保留数据并停止操作；该状态下还没有独立恢复向导，需维护者协助。正常启动后的备份恢复与回退已验证。
4. 原始数据和备份未加密；历史集合与中断暂存目录没有自动清理策略。保留副本不是跨磁盘灾备。
5. 本地 `file:` 页面配合精确来源白名单；尚未改用规划推荐的自定义协议。扩大窗口/页面能力时必须重新审查来源策略。
6. `node:sqlite` 在开发运行时发出实验性接口警告；Lucide 构建存在 `use client` 指令警告。版本已锁定，当前构建与打包测试通过，后续升级需重新验证。
7. 安装器使用默认 Electron 图标，未配置代码签名；不要要求用户关闭安全保护。
8. DeepSeek、正式成绩、座位、值日、成长档案、备课/Office 导出、课堂辅助、倒计时、图像阅卷及设备能力尚未实现。Linux/macOS 未验收。

本记录只支持 M0 工程状态结论，不支持真实教学成效、准确率、性能上限或完整初版交付声明。
