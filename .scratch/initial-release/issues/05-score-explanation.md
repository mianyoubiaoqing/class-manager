# 05 成绩解释草案

**Status:** draft / 待评审
**Blocked by:** 03 DeepSeek 本地配置与连接检查；04 成绩导入与确定性统计
**What to build:** 教师选择合成考试指标，生成并编辑解释和跟进草案，能核对每项结论的数据依据。

范围：发送已计算的最少必要指标，保存草稿及数据版本，不自动创建正式成长条目或通知。

- [ ] 数值来自本地计算，模型不得修改统计结果或根据总分虚构知识点掌握。
- [ ] 明确显示依据、模型补充和不确定性，证据不足时能返回无法判断。
- [ ] 教师可编辑、保存和丢弃草稿，不影响原成绩。
- [ ] 成绩更正后旧解释显示过期，重新生成由用户触发。
- [ ] 模型错误、超时、无效输出不阻断本地统计，也不覆盖已保存解释。

测试：固定指标、来源引用、事实不一致的返回、过期检测、取消和离线。

文档：解释不是正式评价或措施执行，教师检查及后续关联方式。
