# 01 Windows 安装与合成名册

**Status:** implemented / 本机验证；目标机安装待验收
**Blocked by:** None
**What to build:** 普通用户在 Windows 启动桌面客户端，创建虚构班级与学生，保存退出后再次看到完整名册。

范围：最小窗口、受限桌面操作、持久化与版本迁移入口、安装包冒烟。工程默认 Electron，不同时建立 Tauri 实现。当前不用真实学生资料。

- [x] 可以新建、修改和停用合成学生，重名不合并，学生编号冲突有明确错误。
- [x] 成员关系保留所属班级和期间，改名/停用不物理删除历史关联。
- [x] 本机保存重开、重复启动、中文及空格数据路径有测试。
- [x] Renderer 无任意文件、系统命令或数据库能力，来源校验及隔离设置有测试。
- [x] 打包后使用内置资源，不依赖开发服务器。
- [x] 未知 Schema 停写并保留原文件，不重建空库；尚无旧生产版本迁移。
- [ ] 客户目标机、普通权限、无开发工具条件下实际安装与卸载验收。

测试：规则与操作接口测试；真实桌面保存重开 E2E；安装包冒烟；写入中断与迁移失败。

文档：记录真实环境、构建命令、数据位置、安装入口、合成数据标识及未完成能力。其他七项功能不得以占位按钮宣称完成。
