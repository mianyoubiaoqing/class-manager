**What to build:** 教师输入课题并上传合成资料，选择可读范围，生成、编辑和保存同一版本的教案与课件内容。

范围：受限 TXT/DOCX/PDF/JPG/PNG 导入、材料版本与来源、结构化生成。复用材料处理接口供阅卷使用，不建设完整教材知识库。

- [x] 文件、页数、像素及解析资源受限，不执行文档内命令、宏、链接或脚本。
- [x] 原文件与解析/识别内容可对照，扫描页采用图像路径；解析失败不冒充完整读取。
- [x] 用户确认范围后才发送允许内容；本阶段仅用合成材料。
- [x] 教案与课件由受校验结构保存，来源引用真实，模型补充不伪称教材原文。
- [x] 可以编辑并冻结备课版本，私有备注与学生展示内容分开。
- [x] 超时、取消、坏结构和应用重启不覆盖已保存版本或自动重复付费。
