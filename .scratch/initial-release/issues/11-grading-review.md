# 11 图像答卷建议与复核

**Status:** passed / 本地、独立打包、真实图像金标准及最终双轴自审通过
**Blocked by:** 03 DeepSeek 本地配置与连接检查；04 成绩导入与确定性统计
**What to build:** 教师把合成答卷图片/PDF绑定考试科目与学生，设置评分细则，生成逐题建议，对照原图修正和确认。

范围：原生多模态为初版实现，独立 OCR 接口可保留未启用状态；普通题型，不含手写公式。材料处理与备课复用同一受限接口。

- [x] 必须明确材料角色、学生、考试科目、页序和细则版本，不靠模型猜测归属。
- [x] 原图可对照，选择题/判断/简单填空/短文本均有合成样本与人工评分依据。
- [x] 模糊、缺页、不支持题型标为待人工，不能漏题后计总分或自动记零。
- [x] 校验题号、覆盖、分值上限及结构，JSON 可解析不直接判成功。
- [x] 教师可逐题修正和补评；只有内容完整合法才确认冻结，修改须重新审核。
- [x] 取消、超时、无效返回保留已确认输入；重复尝试有记录，失败不显示已阅完。

测试：真实图像小样本与替身异常分开；错题号、越界、模糊、多页、人工补评、版本变化。
