# 07 当期值日分组轮换

**Status:** draft / 待评审
**Blocked by:** 01 Windows 安装与合成名册
**What to build:** 教师选择日期、岗位与参与成员，形成当期临时组并组间轮换，人工调整后保存确认及打印。

范围：每期独立分组，周期内成员稳定；明确安排日期，暂不自动推断校历或节假日。

- [ ] 生成结果覆盖指定日期与岗位，人数/组数不足时明确拒绝或要求修正配置。
- [ ] 轮换可复现，组间次数差异可检查，成员不被重复或漏分。
- [ ] 人工换人与安排调整接受同一套冲突检查，空组不能确认。
- [ ] 岗位安排落实到成员，人员不足显示缺口；临时替换只作用于指定日期岗位，同一成员不能同时重复占岗。
- [ ] 新一期允许重分组，修改形成修订，不改已完成日期或过去计划。
- [ ] 本地保存重开可查看当期与历史，无模型和设备依赖。
- [ ] 指定确认版本可打印，长名单与跨页表头可读，取消打印不产生错误状态。

测试：不能整除的轮换、单组、空组、岗位冲突、临时替换、历史不变、重开和打印预览。

文档：临时组不是固定组、轮换规则、日期选择及历史纠错方式。
