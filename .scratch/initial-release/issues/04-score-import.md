# 04 成绩导入与确定性统计

**Status:** draft / 待评审
**Blocked by:** 01 Windows 安装与合成名册
**What to build:** 教师导入合成 XLSX/CSV，预览匹配及错误，确认后查看可复核统计与历次成绩。

范围：考试科目、满分、计分科目组、标准模板、导入事务、成绩版本和本地统计；不依赖在线模型。

- [ ] 有效零分、缺考、未录入、未选考严格区分，无效分数阻断受影响导入。
- [ ] 重名/编号冲突、重复行、错误表头和格式问题定位明确，未确认不写入。
- [ ] 总分、排名、均分、分布及跨次比较遵循成绩规格；数据不足时不展示误导性结论。
- [ ] 确认导入事务化，已有成绩替换前展示差异，重复提交不重复入库。
- [ ] 更正形成新版本，旧统计可追溯，其他模块能识别原引用已过期。
- [ ] 导入大小/行数等资源保护有实测默认值，超限不静默截断；不执行表格公式或外链。

测试：人工金标准、混合成绩状态、精度与舍入、排名并列、重复点击、事务中断及断网。

文档：标准模板、每项指标口径、导入错误修复、考试版本与不适用的比较方式。
