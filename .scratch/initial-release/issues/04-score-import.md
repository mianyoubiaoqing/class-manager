# 04 成绩导入与确定性统计

**Status:** passed / 2026-09-30，合成数据技术验收与双轴自审通过
**Blocked by:** 01 Windows 安装与合成名册
**What to build:** 教师导入合成 XLSX/CSV，预览匹配及错误，确认后查看可复核统计与历次成绩。

范围：考试科目、满分、计分科目组、标准模板、导入事务、成绩版本和本地统计；不依赖在线模型。

- [x] 有效零分、缺考、未录入、未选考严格区分，无效分数阻断受影响导入。
- [x] 重名/编号冲突、重复行、错误表头和格式问题定位明确，未确认不写入。
- [x] 总分、排名、均分、分布及跨次比较遵循成绩规格；数据不足时不展示误导性结论。
- [x] 确认导入事务化，已有成绩替换前展示差异，重复提交不重复入库。
- [x] 更正形成新版本，旧统计可追溯，其他模块能识别原引用已过期。
- [x] 导入大小/行数等资源保护有实测默认值，超限不静默截断；不执行表格公式或外链。

测试：人工金标准、混合成绩状态、精度与舍入、排名并列、重复点击、事务中断及断网。

文档：标准模板、每项指标口径、导入错误修复、考试版本与不适用的比较方式。

实施次序：确定性成绩校验/统计 → XLSX/CSV 有界预览 → Schema 升级及备份往返 → 确认事务/版本/幂等 → 具名 IPC 与界面 → 完整自审。阶段测试不等于本单验收；全部验收项完成前不开始 05。

第一阶段：新增 `src/shared/scores.ts` 与 `src/core/scores.ts`，实现四种成绩状态、定点数校验、明确名册范围的单科指标及计分组总分、可选竞赛排名。17 项公开行为测试通过，包含人工金标准、缺失/零分、舍入、并列及越界拒绝。具体口径见 `docs/handoff/score-statistics.md`。尚未接入文件解析、持久化、IPC 或界面，以上验收清单保持未完成。

第二阶段：已增加有界 XLSX/UTF-8 CSV 模板与无副作用预览，包含编号/姓名匹配、重复行、显式科目映射、排除原因、ZIP/XML 预检及异常结构回归。31 项文件测试通过；全仓 121 项测试及格式、类型、Lint、构建通过。详见 `docs/handoff/score-import.md`。持久化、确认事务、版本、IPC 与界面尚未完成，工单仍在实施中。

第三阶段：新增 Schema 2 的考试/成绩版本结构、完整成绩语义校验、v1 事务迁移和升级前副本，备份 v2 支持旧 v1 预览与恢复。23 项存储测试通过（含进程退出恢复及 10000 人×20 科完整备份往返），全仓 144 项检查通过。双轴自审问题已修复并复审通过，详见 `docs/handoff/score-storage.md`。未实现教师确认写入、幂等、替换差异、历史查询和界面，本单保持实施中。

第四阶段：`Workspace.scores` 已实现后台预览令牌、确认事务、持久幂等、替换差异、更正版本与历史得分率，恢复框显示考试/成绩版本数量。新增 29 项行为测试，并补孤立考试备份拒绝；全仓 174 项检查通过，两路只读审计与补强复核通过。详见 `docs/handoff/score-confirmation.md`。尚未接入成绩操作 IPC 与完整教师界面，本单仍未整体验收。
