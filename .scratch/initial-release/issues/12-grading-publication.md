# 12 复核结果正式入分

**Status:** draft / 待评审
**Blocked by:** 11 图像答卷建议与复核
**What to build:** 教师将已确认阅卷结果录入考试成绩，查看新统计，并能追溯细则、答卷及复核版本。

范围：逐份发布，成绩模块执行事务和版本检查；不要求批量原子发布。

- [ ] 未确认、缺题或源版本变化的建议不能入分，前端按钮禁用之外应用侧也须校验。
- [ ] 已有成绩替换前展示差异并明确确认，预期版本过期时拒绝静默覆盖。
- [ ] 以复核 ID 幂等发布，重复点击/重试返回同一结果，不生成第二次成绩变更。
- [ ] 新成绩版本和操作记录同事务提交，失败回滚；其他学生成绩不丢失。
- [ ] 成绩分析更新，引用旧版本的解释和总结可识别过期，历史依据保留。
- [ ] 中断后能确定已提交或未提交，不通过再次付费阅卷解决发布状态不明。

测试：重复请求、事务中断、多窗口冲突、成绩替换、缺题阻断、来源追溯。

文档：确认与入分区别、重复提交、版本冲突、回溯及更正流程。
