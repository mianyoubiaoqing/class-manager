# 13 成长记录与阶段总结

**Status:** draft / 待评审
**Blocked by:** 03 DeepSeek 本地配置与连接检查；04 成绩导入与确定性统计
**What to build:** 教师维护合成学生的日常事件与谈话跟进，关联成绩，起草阶段总结并经确认入档。

范围：教师本地视图，无家长或学生端，无实际通知。

- [ ] 可以离线记录与更正事件、跟进状态和日期，保留必要修改记录。
- [ ] 成绩引用指向确切版本和学生，不通过复制当前分数丢失来源。
- [ ] 选择阶段及事实生成总结，信息不足不编造；不进行心理诊断或人格定性。
- [ ] AI 草稿独立保存，经教师编辑确认才创建正式总结条目，重复确认不重复入档。
- [ ] 来源更正提示重核，不静默改写历史总结；草稿来源不循环引用自身结果。
- [ ] 模型失败不阻断人工记录，课堂窗口无法读取档案内容。

测试：无事实、少事实、版本更新、重复确认、成员变化、离线与投屏权限。

文档：事实/草稿/正式条目区别、跟进状态不代表通知已送达、隐私及来源核对。
