# 02 备份恢复与诊断

**Status:** implemented / 本机验证；环境故障演练待补充
**Blocked by:** 01 Windows 安装与合成名册
**What to build:** 用户通过界面备份合成名册及受管附件，在验证备份后恢复，失败时仍能保留原数据。

范围：一致快照、备份清单、恢复状态和脱敏诊断。用一份合成受管附件验证文件一致性，为后续材料模块复用。

- [x] 备份包含数据库与受管附件，记录格式版本和哈希，不包含 Key；M0 尚无需备份的业务设置。
- [x] 串行协调写入与附件变化，恢复校验内容及引用完整性。
- [x] 严格备份格式拒绝额外路径字段、重复/缺失附件、错误版本/哈希及超限；不支持 ZIP 或链接条目。
- [x] 恢复保留旧集合；入口切换前后进程退出测试重新打开完整数据，并可通过界面回退。
- [x] 用户取消不视作失败；导出采用临时文件完成后发布。
- [x] 诊断不含姓名、编号、附件正文、密钥或完整路径。
- [ ] 目标机磁盘满、ACL 权限、文件占用和实际断电条件下的环境演练。

测试：备份恢复往返、活动写入、恢复中断、恶意归档与旧版本兼容；由 UI 完成一次完整恢复。

文档：用户备份与恢复步骤、开发者快照/恢复协议、失败处置。01 与本工单完成后才具备 M0 候选。

证据：`docs/handoff/m0-verification.md`。当前库损坏导致启动受阻时，恢复仍需维护者协助，不能宣称自动修复任意损坏。
