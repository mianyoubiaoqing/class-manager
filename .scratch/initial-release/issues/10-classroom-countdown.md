# 10 课堂辅助与倒计时

**Status:** passed / 2026-10-01，整单验证及 Standards/Spec 自审通过
**Blocked by:** 08 资料驱动的备课版本
**What to build:** 教师打开已保存备课版本进行全屏展示、切换环节、计时和提问提示，保存进度；另可配置高考倒计时目标。

范围：教师主导、离线材料展示，不含学生端互动、无人授课或音视频生成。

- [x] 展示窗口仅获得允许展示的数据与有限操作，默认不包含私有备注、成绩或档案。
- [x] 环节切换、暂停恢复和进度保存可重开，材料草稿更新不自动替换当前课。
- [x] 开始展示前确认版本及范围，答案按明确选择显示。
- [x] 目标日期及时区可设置，跨日、系统时间变化和已到期不出现错误负数或错年。
- [x] 计时不用帧数累计，隐藏/恢复窗口不会产生明显累计漂移；离线可用。

测试：课堂窗口权限、断网、重开、跨日/时区、系统时钟变化与展示截图。

文档：展示与私有内容区别、进度恢复、计时及日期设置，不把进度等同掌握情况。

最终验证：44 个文件/742 项及格式、类型、Lint、构建通过；开发/打包课堂、两套长内容与原有完整桌面各 10 次重开通过。Schema/备份协议 7，管理桥接 79 项，独立展示 3 项；没有付费请求。逐项证据与最终自审见 `docs/handoff/classroom-acceptance.md`、`classroom-audit.md`。07 冻结版、用户安装器不覆盖，完整发布留 15。
