# 14 外设未接入契约

**Status:** draft / 待评审
**Blocked by:** 01 Windows 安装与合成名册
**What to build:** 用户查看音量监测及呼叫接口状态，未连接时得到明确不可用结果；开发者可用测试替身验证契约。

范围：接口级交付，客户是否接受此例外仍待确认，不接实际设备或发送真实学生通知。

- [ ] 监测状态区分未接入、就绪和故障；未接入没有伪造音量、分贝或噪音告警。
- [ ] 呼叫请求明确学生目标、操作标识和审核前提；未接入返回不可执行而非已送达。
- [ ] 未来状态区分请求受理与实际送达，不能把受理当送达。
- [ ] 模拟数据仅在测试环境或明确标注的测试模式使用，不显示为现场状态。
- [ ] 两类 Adapter 有输入校验、失败与取消契约，未来硬件实现不要求改写业务模块。

测试：契约测试、未接入/故障、重复呼叫操作、受理与送达区分、发布构建不冒充接入。

文档：预留接口、未实现范围、后续硬件协议/校准/隐私/成本确认清单。
