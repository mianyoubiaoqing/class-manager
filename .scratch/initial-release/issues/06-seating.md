# 06 座位编排与打印

**Status:** draft / 待评审
**Blocked by:** 01 Windows 安装与合成名册
**What to build:** 教师设置座位布局及不可用位置，锁定部分学生，随机安排其余学生，手动调整后确认、保存及打印。

范围：基础随机编排，明确不含身高、成绩或关系推断的复杂策略。

- [ ] 不可用座位不得分配；锁定冲突、容量不足和无效成员必须提示。
- [ ] 已确认方案中每名应安排成员恰好一次、每座位最多一人，重排保持锁定。
- [ ] 手动移动/交换符合相同校验；取消草稿不改旧确认版本。
- [ ] 方案引用布局及成员快照，后续改布局或转班不重写历史。
- [ ] 打印来自指定确认版本，无截断或重叠，打印取消有明确状态。

测试：固定随机种子、覆盖与唯一性、多种布局、冲突、保存重开及打印预览。

文档：锁定与随机语义、布局版本、打印步骤、当前不支持的复杂条件。
