# 03 DeepSeek 本地配置与连接检查

**Status:** implemented / 已实现待审计
**Blocked by:** 01 Windows 安装与合成名册
**What to build:** 用户在本地设置 Key，主动发起小型合成文本和图像检查，分别看到能力结果及可理解的错误。

范围：唯一 DeepSeek Adapter、模型能力配置、凭据保护、可取消任务及用量账本。只在实施时通过本地设置配置 Key，不从聊天或仓库寻找凭据。

- [x] 输入提交后清空，后续仅返回配置状态或掩码，不能读回完整 Key。
- [x] 系统安全存储不可用时明确失败，不转明文；删除凭据后新任务不能继续读取。
- [x] 文本成功不等于图像成功，验证所用模型与实际返回标识分别记录。
- [x] 无效结构、认证/余额/参数问题不无限重试；限流/网络故障采用有限重试。
- [x] 取消、迟到响应和重启中断不覆盖新任务，不自动重放付费请求。
- [x] 连接检查标注可能费用；usage 未返回记未知，应用调用与开发工具预算分开。

测试：用替身覆盖异常与密钥不泄漏；获得本地配置后各执行一条真实合成文本/图像请求。无配置时标受阻，禁止假通过。

文档：账号归属、错误类别、用量观测边界、提示词/参数版本和更换 Key 步骤。
